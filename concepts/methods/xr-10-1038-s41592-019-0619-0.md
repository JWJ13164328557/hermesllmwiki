# Fast, sensitive and accurate integration of single-cell data with Harmony

---

## 1. Scientific Context

### Existing Consensus (Before This Paper)

By 2019, scRNA-seq integration was an active and competitive field with multiple published methods, but no clear winner in terms of accuracy, speed, and flexibility. Key prior consensus:

- **Batch correction was essential**: scRNA-seq datasets from different technologies, laboratories, or timepoints could not be jointly analyzed without principled batch correction
- **CCA-based integration** in Seurat v2 ([[xr-10-1038-nbt-4096|Butler 2018]]) and **MNN-based correction** ([[xr-10-1038-nbt-4096|Haghverdi 2018]]) were the leading approaches, but both had significant limitations:
  - CCA required pairwise alignment, making multi-batch integration order-dependent
  - MNN was computationally expensive, scaling poorly to large datasets
- **LIGER** (Welch 2019, [[xr-10-1016-j-cell-2019-05-006]]) had introduced integrative non-negative matrix factorization (iNMF), but was also computationally intensive
- **scVI** (Lopez 2018) offered a deep learning approach with probabilistic modeling, but required GPU resources for larger datasets
- All existing methods struggled with **multiple covariates** (batch + condition + donor) — they could typically correct for one factor at a time

### Existing Models

- **CCA + MNN anchoring** (Seurat v2-3): Identifies shared correlation structures via CCA, then uses MNN pairs across datasets as anchors for alignment — pairwise by design
- **Mutual Nearest Neighbors (MNN)**: Computes correction vectors from MNN pairs — requires $O(n^2)$ nearest-neighbor search, expensive at scale
- **LIGER (iNMF)**: Factorizes each dataset into shared and dataset-specific factors using non-negative matrix factorization — iterative, computationally heavy
- **scVI**: Latent variable model with a VAE architecture — flexible but GPU-dependent and sensitive to hyperparameters
- **BBKNN**: Batch-balanced kNN for graph-based clustering — fast but loses the continuous embedding structure needed for visualization and trajectory analysis

### Knowledge Gaps

- No method could integrate **~10^6 cells on a personal computer** — all existing methods required either cluster/cloud computing or were limited to ~10^5 cells
- No method simultaneously accounted for **multiple covariates** (batch, condition, donor, technology) in a single alignment step
- No systematic benchmarking across diverse biological contexts (immune cells, endocrine cells, developmental biology, spatial data)
- The relationship between integration accuracy and computational efficiency was unexplored — did more complex models actually produce better integration?
- No integration method had been demonstrated for **cross-modality alignment** (scRNA-seq + spatial transcriptomics)

### Why This Paper Matters

This paper introduced **Harmony**, an iterative fuzzy clustering algorithm that simultaneously corrects for multiple covariates while requiring dramatically fewer computational resources than contemporary methods. Harmony demonstrated for the first time that integration of ~10^6 cells was possible on a personal computer, making large-scale atlas integration accessible to any lab. Its six diverse demonstrations — PBMC with large experimental differences, five pancreatic islet studies, mouse embryogenesis, and the novel cross-modality integration of scRNA-seq with spatial transcriptomics — established it as one of the two dominant integration methods alongside Seurat CCA. Harmony's speed, simplicity, and multi-covariate capability made it the preferred choice for atlas-scale projects and complex experimental designs.

## 2. Research Questions

### Primary Question

Can an iterative fuzzy clustering algorithm integrate scRNA-seq datasets while simultaneously correcting for multiple covariates, and do so faster and more accurately than existing methods?

### Secondary Questions

1. Does Harmony successfully integrate PBMC datasets with large experimental differences (different technologies, protocols, laboratories)?
2. Can Harmony simultaneously correct for batch effects while preserving biological condition differences (e.g., stimulation states)?
3. Does Harmony integrate five independent pancreatic islet studies into a coherent cell-type landscape?
4. Can Harmony handle developmental biology data — integrating mouse embryogenesis datasets across timepoints and technologies?
5. Is Harmony capable of cross-modality integration — aligning scRNA-seq with spatial transcriptomics (MERFISH) data?
6. How does Harmony compare to CCA, MNN, scVI, and LIGER in terms of both integration accuracy and computational resource requirements?

### Explicit Hypotheses

- Fuzzy (soft) clustering is more robust than hard clustering for integration because it allows cells at cluster boundaries to contribute to multiple cluster centroids
- An iterative expectation-maximization (EM)-style algorithm will converge to a shared embedding where cells group by cell type regardless of their dataset of origin
- Clustering in a low-dimensional PCA space (rather than the full gene space) will dramatically reduce computational cost while preserving integration quality
- Multi-covariate correction can be achieved by including all covariates in the linear model used to adjust cluster centroids

### Implicit Hypotheses

- Integration quality and computational efficiency are not inherently in tension — a simpler algorithm can outperform more complex models if the core statistical insight is correct
- The diversity of biological demonstrations (immune, endocrine, developmental, spatial) tests the generality of the fuzzy clustering assumption — that shared cell types exist as clusters across diverse biological contexts
- Cross-modality integration (scRNA-seq + spatial) is possible because both modalities measure cell-type-defining gene expression, and cell types form similar cluster structures in both spaces

### Why Fuzzy Clustering?

- **Soft assignments prevent hard errors**: Hard clustering forces each cell into exactly one cluster, misclassifying cells at cluster boundaries and propagating errors across iterations. Fuzzy clustering allows boundary cells to influence multiple centroids, making the algorithm more robust to ambiguous cell states
- **Natural fit for continuum data**: Cell states often form continuous trajectories (differentiation, activation) rather than discrete clusters — fuzzy clustering better captures this biology
- **EM convergence is well-understood**: The iterative reassignment approach has rigorous convergence guarantees from the EM algorithm literature

### Why Four Diverse Demonstrations?

- **PBMC**: Tests the hardest integration scenario — datasets with large experimental differences — and serves as a standard benchmarking system
- **Pancreatic islets (5 studies)**: Tests multi-dataset integration where preserving subtle cell-type differences (α vs. β cells, rare δ and PP cells) is critical
- **Mouse embryogenesis**: Tests whether Harmony preserves continuous developmental trajectories while removing batch effects — a key challenge missed by clustering-centric benchmarks
- **Spatial transcriptomics (cross-modality)**: Demonstrates that Harmony's framework extends beyond scRNA-seq, opening a new application area for integration methods

## 4. Method Analysis

### Core Algorithm: Iterative Fuzzy Clustering Integration (Harmony)

**Problem formulation**: Given $D$ scRNA-seq datasets with cells embedded in a shared low-dimensional space (e.g., PCA), correct for dataset-specific (and other covariate-specific) effects such that cells cluster by biological identity rather than by dataset of origin.

**Algorithm overview**:

#### Step 1: Shared PCA Embedding

All cells from all datasets are embedded in a shared low-dimensional PCA space (typically $d = 20-30$ dimensions), computed from the union of all cells. The PCA space captures the dominant sources of variation — both biological (cell-type differences) and technical (dataset-specific shifts).

- **Innovation**: By working entirely in low-dimensional PCA space (not gene space), Harmony achieves dramatic computational speedups — all operations scale as $O(N \cdot d \cdot K)$ where $N$ is total cell count, $d$ is PCA dimensions (~20-30), and $K$ is number of clusters.

#### Step 2: Soft (Fuzzy) k-Means Clustering

Harmony performs soft k-means clustering on the PCA embedding, assigning each cell $i$ a probability $R_{ik}$ of belonging to cluster $k$:

$$R_{ik} = \frac{\exp(-\beta \cdot \|z_i - \mu_k\|^2)}{\sum_{j=1}^{K} \exp(-\beta \cdot \|z_i - \mu_j\|^2)}$$

where $z_i$ is the PCA embedding of cell $i$, $\mu_k$ is the centroid of cluster $k$, and $\beta$ controls the fuzziness (inverse temperature).

- **Innovation**: Fuzzy assignments are the key conceptual advance over prior hard-clustering integration methods. Cells at cluster boundaries (e.g., transitional states, rare populations) contribute fractionally to multiple centroids, avoiding the error propagation that plagues hard assignments.

#### Step 3: Dataset-Specific Centroid Correction

For each cluster $k$, Harmony fits a linear model to the cluster centroids:

$$\mu_k = \alpha_k + X\beta_k + \epsilon_k$$

where $X$ is a design matrix encoding all covariates (dataset, condition, donor, technology). The corrected centroid $\hat{\mu}_k$ is:

$$\hat{\mu}_k = \mu_k - X\hat{\beta}_k$$

This removes dataset-specific (and other covariate-specific) shifts from each cluster centroid.

- **Innovation**: The linear correction is computationally trivial ($O(K \cdot d \cdot p)$ where $p$ is number of covariates) yet effectively removes systematic offsets. By including multiple covariates in the linear model, Harmony simultaneously corrects for batch, condition, and technical factors — a capability absent from all prior methods.

#### Step 4: Cell Reassignment

Cells are reassigned to the corrected centroids using the same soft clustering:

$$R_{ik} \propto \exp(-\beta \cdot \|z_i - \hat{\mu}_k\|^2)$$

#### Step 5: Iteration to Convergence

Steps 2-4 are repeated until convergence (typically 5-10 iterations). At convergence, each cell's PCA embedding is transformed to a **Harmony-corrected embedding**:

$$z_i^{corrected} = z_i - \sum_{k=1}^{K} R_{ik} \cdot X\hat{\beta}_k$$

This is the final integrated embedding — cells from different datasets now group by cell type.

- **Innovation**: The convergence behavior is smooth and monotonic, inheriting the mathematical guarantees of the EM algorithm family. The number of iterations is small because each iteration makes a bounded correction.

#### Step 6: Multi-Covariate Extension

Unlike prior methods (which correct for one factor at a time in sequential pairwise fashion), Harmony's design matrix $X$ can include **any number of covariates** — dataset ID, condition, donor, technology, timepoint — and corrects for all of them simultaneously in step 3.

- **Innovation**: This is arguably Harmony's most practically important feature. Real experiments almost always have multiple confounding factors (different donors in different batches, different treatments in different technologies). Harmony handles these directly, without sequential workarounds.

### Key Algorithmic Contributions

| Innovation | Significance |
|---|---|
| **Fuzzy (soft) clustering** | Robust to boundary cells; avoids hard-assignment error propagation |
| **PCA-space operation** | Enables ~10^6 cell integration on personal computers |
| **Linear covariate correction** | Computationally trivial, handles multiple factors simultaneously |
| **EM convergence framework** | Mathematically principled, fast convergence (5-10 iterations) |
| **Direct output embedding** | Produces a corrected PCA embedding usable for any downstream analysis |
| **Model simplicity** | No hyperparameter tuning beyond cluster count $K$ and fuzziness $\beta$ |
| **Cross-modality capability** | Framework agnostic to data type; demonstrated on spatial transcriptomics |

| Aspect | Harmony | CCA (Seurat v2) | MNN | LIGER (iNMF) | scVI |
|--------|---------|-----------------|-----|-------------|------|
| **Approach** | Fuzzy clustering + linear correction | Canonical correlation + MNN anchors | Mutual nearest neighbors | Integrative NMF | Variational autoencoder |
| **Clustering** | Soft (fuzzy) | Hard (MNN pairs) | Hard (MNN pairs) | Hard (factor assignments) | Probabilistic (latent) |
| **Multi-covariate** | Yes (simultaneous, via design matrix) | No (pairwise) | No (pairwise) | No (pairwise) | Yes (via covariates) |

| **Iterations** | 5-10 (fast) | 1 (pairwise) | 1 (pairwise) | 10-30 (slow) | 100-250 (slow, GPU) |

### Limitations of the Algorithm

- **PCA input dependency**: Harmony operates entirely on a PCA embedding — if PCA fails to capture biological variation (e.g., due to extreme batch effects), Harmony cannot recover it
- **Linear correction assumption**: The linear model for centroid correction assumes dataset effects are additive and linear — may fail for nonlinear batch effects (e.g., different gene detection sensitivities creating nonlinear expression distortions)
- **Cluster number $K$**: Performance depends on choosing an appropriate number of clusters; $K$ too small merges distinct cell types, $K$ too large fragments shared populations
- **No cross-modality feature mapping**: Cross-modality integration (scRNA-seq + spatial) requires that the same genes are measured in both modalities — a strong requirement rarely met in practice
- **Preservation of biology**: Harmony corrects for covariates but provides no explicit guarantee that condition-specific biology is preserved — users must validate post hoc
- **Initialization sensitivity**: The algorithm starts from a single PCA; different random initializations of cluster centroids can lead to slightly different results
- **No uncertainty quantification**: Harmony outputs a deterministic corrected embedding with no measure of confidence or uncertainty

## 7. Critical Evaluation

### Strengths

- **Exceptional scalability**: The ability to integrate ~10^6 cells on a personal computer was unprecedented — prior methods required cluster/cloud computing for datasets two orders of magnitude smaller. This democratized large-scale single-cell integration.
- **Multi-covariate correction**: Simultaneously correcting for batch, condition, donor, and technology in a single linear model is both statistically elegant and practically essential. No other method at the time offered this capability.
- **Algorithmic simplicity**: The entire algorithm can be described in a few equations — soft k-means + linear correction + iteration. This simplicity makes it easy to implement, debug, and extend.
- **Comprehensive benchmarking**: Six diverse demonstrations (PBMC, islets, embryogenesis, spatial, scalability, multi-covariate) provide convincing evidence of generality
- **Cross-modality extension**: Integrating scRNA-seq with spatial transcriptomics opened a new application domain for integration methods, influencing subsequent methods like Symphony, RCTD, and Cell2Location
- **Fast convergence**: 5-10 iterations to convergence means Harmony runs in seconds to minutes for most datasets
- **Minimal hyperparameters**: Only cluster count $K$ and fuzziness $\beta$ need to be set; both have reasonable defaults and intuitive interpretations
- **Direct integration with standard workflows**: The corrected PCA embedding can be fed directly into UMAP, clustering, trajectory inference, and differential expression — no special downstream tools required
- **Strong software engineering**: The Harmony R package is well-documented, actively maintained, and has a Python port (harmonypy)

### Weaknesses

- **PCA-dependent**: If the initial PCA fails to separate biological from technical variation (e.g., when batch effects dominate all principal components), Harmony will have no biological signal to work with
- **Linear correction only**: Dataset effects are assumed additive and linear in PCA space; nonlinear distortions (e.g., from different gene capture efficiencies creating scale differences) may not be fully corrected
- **Cluster number sensitivity**: $K$ must be specified and can substantially affect results; Harmony provides a heuristic for choosing $K$ but no rigorous selection criterion
- **No explicit biological preservation guarantee**: Unlike scVI (which can include condition as a covariate in the generative model), Harmony's biological preservation is implicit — it relies on the assumption that removing covariate effects from centroids leaves biological variation intact
- **Single embedding output**: Harmony produces one corrected embedding; there is no explicit decomposition into biological and technical components (cf. LIGER's shared + dataset-specific factors)
- **Limited cross-modality validation**: The spatial transcriptomics demonstration uses MERFISH (a targeted, gene-rich platform); performance with lower-plex spatial technologies (Visium, Slide-seq) was not tested
- **No negative controls**: What happens when Harmony is applied to biologically unrelated datasets (e.g., brain + liver)? Can it incorrectly "integrate" data that should remain separate?

### Missing Controls

- No systematic evaluation of Harmony's sensitivity to the number of clusters $K$ — how does performance degrade with suboptimal $K$?
- No demonstration that Harmony fails to integrate biologically unrelated datasets (negative control for over-integration)
- No comparison of Harmony's cross-modality performance against methods specifically designed for spatial integration (e.g., Seurat v3 transfer, RCTD)
- No assessment of Harmony's performance when batch effects are nonlinear (e.g., datasets with very different gene detection sensitivities)
- No formal test for whether biological variation (e.g., stimulation response) is quantitatively preserved after integration

## 8. Research Insight

### What Changed After This Paper

- **Scalable integration became accessible**: Harmony proved that large-scale integration did not require expensive computing infrastructure, enabling any lab to integrate atlas-scale datasets
- **Multi-covariate correction became expected**: After Harmony, the ability to simultaneously correct for multiple covariates (batch + condition + donor) became a standard requirement for integration methods — subsequent tools (fastMNN, scVI, scANVI) added similar capabilities
- **Fuzzy clustering gained credibility in single-cell**: Prior to Harmony, soft clustering was considered niche; Harmony demonstrated its practical advantages for robust integration, influencing later methods
- **Spatial transcriptomics integration emerged as a major application**: Harmony's MERFISH demonstration catalyzed the development of a whole subfield of spatial-scRNA-seq integration methods (Symphony, Cell2Location, RCTD, Tangram)
- **Harmony-Seurat competition drove innovation**: The Harmony-versus-Seurat comparison became the central axis of integration benchmarking (e.g., scIB, IBRAP), pushing both ecosystems to improve — Seurat v4 added SCTransform and WNN, Harmony inspired Symphony (atlas-scale reference mapping)
- **Benchmarking culture matured**: Harmony's six-demonstration approach set a new standard for comprehensive integration method evaluation, influencing the design of systematic benchmarks like scIB

### How It Connects to Current Knowledge

- **Symphony as successor**: The Harmony team extended the framework to reference-based mapping in **Symphony** (Kang 2021), enabling query-to-reference integration without re-running clustering on the full reference — directly analogous to Seurat's anchor-based mapping
- **Complementary to Seurat**: Harmony and Seurat CCA represent the two dominant integration paradigms — Harmony excels at multi-covariate, large-scale integration with minimal tuning; Seurat excels at reference-based analysis and cross-modality integration via anchors
- **scVI ecosystem convergence**: Modern scvi-tools methods (scVI, scANVI) now incorporate multi-covariate correction and soft cluster assignments, incorporating design elements that Harmony pioneered
- **Spatial integration ecosystem**: The Harmony → Symphony → RCTD/Cell2Location lineage represents one of the most productive research trajectories in spatial transcriptomics
- **Atlas-scale projects**: Harmony's scalability made it the default integration method for early cell atlas projects (Human Cell Atlas, Lung Atlas, Kidney Precision Medicine Project), establishing integration as a standard preprocessing step

## 9. Future Research Opportunities

- **Nonlinear Harmony**: Replace the linear centroid correction with a nonlinear correction (e.g., kernel regression or neural network) to handle batch effects that are not additive in PCA space
- **Automatic cluster number selection**: Develop a data-driven criterion for choosing $K$ — e.g., based on cross-validation, stability analysis, or information criteria
- **Harmony for multi-omics**: Extend Harmony to simultaneously integrate multiple modalities (RNA + ATAC + proteins) measured in the same cells, using a joint PCA or multi-omics embedding as input
- **Uncertainty-aware Harmony**: Produce posterior distributions over cell embeddings rather than point estimates, enabling downstream analyses that account for integration uncertainty
- **Streaming/online Harmony**: Develop an online version that can incrementally integrate new datasets into an existing reference without re-running the full algorithm — critical for living atlases
- **Harmony for spatially-resolved multi-omics**: Simultaneously integrate spatial transcriptomics, spatial proteomics, and spatial metabolomics data using Harmony's multi-covariate framework
- **Biologically-informed centroid correction**: Replace the linear model with a model that incorporates known biological relationships (e.g., gene regulatory networks, signaling pathways) to improve preservation of biological variation
- **Deep Harmony**: Use a neural network to learn the corrected embedding end-to-end, potentially capturing complex nonlinear batch effects while maintaining Harmony's computational efficiency
- **Harmony for cross-species integration**: Extend to integrate data from different species using ortholog-based feature mapping — analogous to CCA's cross-species capability but with Harmony's scalability
- **Clinical Harmony**: Develop extensions that explicitly model disease states as covariates, enabling differential analysis of healthy vs. disease cell states across integrated cohorts
