# 植物细胞周期调控




## 概述

真核细胞分裂由 **cyclins（细胞周期蛋白）** 与 **CDKs（细胞周期蛋白依赖性激酶）** 共同调控。

## 开花植物的复杂性

- Cyclin-CDK 配对数目庞大（数十个 cyclin 基因）
- 功能高度冗余 → 功能分析困难
- 这种复杂性是**衍生特征**（种子植物特有）

## 陆生植物祖先状态：地钱极简系统

[[marchantia-polymorpha]] 保留了精简且非冗余的核心细胞周期基因集：

| 细胞周期阶段 | 主导 Cyclin | 功能 |
|-------------|------------|------|
| G1期 | [[mpcycd1]] | 驱动细胞周期重新进入，促进增殖与去分化 |
| S期 | [[mpcyca]] | DNA 复制期 |
| G2/M期 | [[mpcycb1]] | 有丝分裂进入 |

### 极简系统的特征

1. **单一cyclin主导**: 每个时期仅一种cyclin占主导
2. **时期转换重叠有限**: 边界清晰
3. **蛋白周转+亚细胞定位**: 共同维持时期特异性
4. **功能非冗余**: 单个cyclin功能明确

## 研究方法

- [[cell-cycle-scrna-seq]] — 单细胞RNA-seq捕获时期特异性表达
- 荧光报告基因活体成像 — 蛋白周转与定位分析
- 过表达/功能验证

## 意义

- 证实真核生物细胞周期调控的保守特征
- 为理解多细胞增殖与进化提供清晰框架
- 为工程化改造植物生长提供原型
