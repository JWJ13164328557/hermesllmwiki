深度定制 让研究突破预期

近年来，单细胞转录组技术正在推动植物研究从“组织平均表达”走向“细胞类型精度”。在拟南芥、水稻、玉米等模式或主粮作物中，scRNA-seq 已被广泛用于解析根尖发育、叶片分化、花药成熟、胁迫响应和特化代谢分区，为植物发育生物学和分子育种提供了新的研究范式。然而，植物单细胞技术仍面临天然门槛：细胞壁影响原生质体释放，不同细胞类型酶解敏感性不同，容易造成细胞捕获偏倚；同时，木本植物富含多酚、多糖、单宁等次生代谢物，会干扰细胞活性、建库效率和测序质量。对于茶树、果树、林木等非模式物种，问题更加突出——参考基因组质量不足、细胞类型标记基因缺乏、遗传转化体系不稳定，都限制了单细胞图谱的构建和机制验证。
在这样的背景下，snRNA-seq（单细胞核转录组）成为突破植物复杂组织的重要方案。相比依赖完整原生质体的 scRNA-seq，snRNA-seq 可绕开部分细胞壁和原生质体制备难题，更适合茸毛、纤维、木质化组织等难解离材料。
奥智生物合作客户—福建农林大学孙威江团队以三倍体白茶品种福鼎大毫茶为对象，结合高质量染色体级基因组和单细胞核转录组，构建叶片茸毛发育图谱，为非模式木本植物的复杂性状解析提供了一个代表性的技术路线[1]。下面我们就来看看这篇文章的详细分析结果吧。

● 文章题目：基因组与单细胞核转录组联合解析白茶品种“福鼎大毫茶”叶片茸毛发育机制● 原文标题：Exploring the developmental mechanisms of tea plant trichomes using genomics and single-cell transcriptome Sequencing● 合作单位：福建农林大学● 期刊：Hortic. Res.● 影响因子：8.5

文章摘要

茶树叶片茸毛，trichome（茸毛/表皮毛），是白茶外观品质、香气物质、氨基酸积累和抗虫抗旱能力的重要基础。福鼎大毫茶，Camellia sinensis Fuding Dahaocha，简称 FDDH，是我国白茶生产中的重要品种，具有：叶片茸毛密集、发芽早、产量高、抗逆性强等特征，适合白茶加工。因此，解析 FDDH 茸毛发育机制，不仅有助于理解茶树叶片表皮细胞分化规律，也可为白茶品质改良和抗逆育种提供候选基因资源。

单细胞测序样本

本研究包含叶片细胞组（CL）和茸毛细胞核组（CT），其中 CL 包含两个测序样本，CT 包含一个测序样本；样品制备过程中来源于 3 株独立植株以增强结果稳定性。

文章数据分析思路

主要分析结果

1. 单细胞核转录组构建茶树叶片细胞图谱并识别茸毛细胞标志基因

由于白茶缺乏参考基因组，因此作者首先通过 PacBio 长读长测序和 Hi-C 染色质互作数据进行基因组组装，最终获得组装质量较高、总组装大小8.3Gb的白茶参考基因组。获得参考基因组后，作者开始进行单细胞转录组实验。
由于茶树叶片富含次生代谢物，细胞壁坚硬，且茸毛细胞难以通过传统原生质体酶解释放，因此作者采用双策略：叶片组织制备原生质体悬液，茸毛组织进行提核，然后分别进单细胞转录组测序。
整合 CL（叶片）和 CT（茸毛）数据后，数据注释出4大类细胞（图1 A），分别是 VB（vascular bundle cells，维管束细胞）；LM（leaf mesophyll cells，叶肉细胞）；EP（epidermis cells，表皮细胞）；TR（trichome cells，茸毛细胞）。
作者通过 qRT-PCR 验证 marker genes 表达模式。结果显示 qRT-PCR 与单细胞结果一致，支持细胞注释可靠（图1 B）。作者还筛选每个 cluster 表达最高的 top 5 genes，最终识别出 35 个茸毛细胞特异 marker genes（图1 C）。
图1：白茶叶片和茸毛的单细胞图谱构建

2. 茸毛细胞呈现G2期富集，提示其发育与核内复制和细胞周期重塑相关

完成图谱构建后，作者首先进行了细胞周期分析从而去关注茸毛细胞的发育机制,主要发现：
CT 组整体细胞周期评分高于 CL 组。说明茸毛相关细胞具有更活跃的分化和发育状态（图2 A）。
CT 组 G2 期细胞比例为 36.3%，CL 组 G2 期细胞比例为 28.1%，茸毛细胞 cluster 中 G2 期比例高达 37.5%。这说明 G2 期富集是茶树茸毛发育的重要特征（图2 B C）。
GO 富集分析显示，G2 期显著上调基因富集于结构分子活性、RNA 结合、前体代谢物和能量生成。说明 G2 期细胞处于活跃的蛋白合成、形态建成和能量代谢状态（图2 D）。
植物茸毛细胞常常经历 endoreduplication（核内复制），即 DNA 复制但不进行正常细胞分裂，从而形成较大的单细胞结构。作者认为，G2 期细胞增加可能代表表皮细胞正在从有丝分裂周期转向茸毛细胞特有的核内复制和细胞形态建成程序。
图2：细胞周期分析还原茸毛细胞的分裂特征

3. 拟时序轨迹揭示表皮细胞向茸毛细胞分化的动态过程

细胞周期分析提供了茸毛细胞自身分裂的特征，下一步作者开始关注茸毛细胞的实际细胞分化过程，因此作者进行了拟时分析，发现：
茶树茸毛主要来源于叶片下表皮。作者发现 cluster 1、6、14 同时具有表皮和茸毛 marker genes 的表达特征，并且 CL/CT 来源比例接近（图3 A B），因此将其定义为：TC（transitional cell，过渡细胞）其余细胞进一步定义为：rEP（reselected epidermal cell，重新筛选的表皮细胞）；rTR（reselected trichome cell，重新筛选的茸毛细胞）。
对 TC、rEP 和 rTR 进行 monocle2 拟时分析。结果显示轨迹存在一个分支点，并形成 3 个状态：State 1：以 rEP 表皮细胞为主；State 2：过渡状态；State 3：以 CT 来源和 rTR 茸毛细胞为主，是茸毛发育终点。这说明表皮细胞经过关键分化节点后，最终形成茸毛细胞（图3 A B）。
作者根据拟时上的差异表达基因构建热图，并划分为 3 个表达模块：Module 1：在拟时序末端 State 3 上调，主要与细胞形态建成相关；Module 2 和 Module 3：在早期和中期上调，主要与刺激响应和发育潜能相关。这说明茸毛发育由早期命运决定逐渐过渡到后期形态建成（图3 C）。
作者进一步筛选拟时序变化最显著的 top 100 genes（图3 D），发现多个茸毛相关基因在发育过程中上调，包括：GL2、CsGL3、GL3、CsMYB1。这些基因在拟时序后期逐渐升高，说明它们可能参与茶树茸毛细胞命运确立和形态发育。
图3：拟时分析探究茸毛细胞发育轨迹

4. CsGL3、CsCUT1 和 CsMYB4 共同调控茸毛启动、分枝和细胞命运选择

通过monocle2的拟时差异分析找到了潜在的茸毛分化调控基因，作者接下来就围绕这些在发育轨迹后期高表达的基因展开了讨论：
CsGL3 是 GL3 同源基因，属于 bHLH 转录因子。作者将 CsGL3 在拟南芥中过表达后发现：叶片茸毛密度显著增加，茎部茸毛密度显著增加；说明 CsGL3 是茸毛发育的正调控因子（图4 A）。
在拟时序分析中，作者发现从 State 1 到 State 2 的分支中，一些基因富集于：叶绿体形成和光合作用。由于茸毛细胞通常不含叶绿体，而保卫细胞 guard cells，GD，具有叶绿体并参与气孔功能，因此作者进一步对 rTR cluster 重新聚类，识别出：TR（茸毛细胞）；GD（guard cells，保卫细胞）；EP（表皮细胞）。结果提示：表皮细胞在发育过程中存在向茸毛细胞和保卫细胞分化的命运分支（图4 B C）
作者在细胞命运分化相关 TFs，transcription factors（转录因子）中筛选到 CsMYB4。其表达模式显示：在表皮细胞向保卫细胞方向分化过程中逐渐升高；在表皮细胞向茸毛方向分化后期下降。过表达 CsMYB4 的拟南芥表现为：叶片茸毛密度下降约 88%；产生近似“少毛/无毛”表型。因此 CsMYB4 被定义为茸毛形成的负调控因子，同时可能参与促进保卫细胞方向分化（图4 D）。
图4：围绕茸毛细胞转录因子调控机制的实验结果

文章小结

本文以白茶主栽品种三倍体为研究对象，构建了“基因组资源构建—细胞图谱解析—发育轨迹推断—关键基因验证”的完整研究链条。研究首先完成了首个染色体水平的三倍体茶树基因组组装，明确其45条染色体及三套同源染色体结构；随后利用单核RNA测序突破木本植物叶片原生质体制备困难、茸毛细胞难以捕获等技术瓶颈，建立了茶树叶片茸毛发育的单细胞图谱，并解析表皮细胞向茸毛细胞和保卫细胞分化的动态过程。总体而言，该研究不仅为解析“表皮细胞—细胞周期—转录因子—茸毛形态建成”的茶树茸毛发育调控网络提供了关键证据，也为白茶品质形成、抗逆性改良及多倍体茶树分子育种奠定了重要基因组和单细胞资源基础。
