# Garryanalyzer: A morphometric workflow and open-source ImageJ plug-in for quantitative morphological analysis of Pacific Northwest 

PREMISE: Accurate species identification is crucial for ecological restoration and can be especially challenging for understudied non-model species. 

METHODS: We measured leaf morphological traits sampled from herbarium collections in their native ranges using the digital morphometric tools MorphoLeaf and Tomato Analyzer. We then used Lasso logistic analysis to generate a predictive model and tested it on leaves from Portland, Oregon. To streamline this species detection process, we developed Garryanalyzer, an ImageJ plug-in that automatically measures leaf traits and outputs species predictions.

DISCUSSION: Many existing morphometric software are not open source, which makes them unable to be customized to specific study systems. Garryanalyzer is built upon the widely used open-source ImageJ platform. This study also demonstrates a viable workflow for developing similar tools for other ecologically important non-model plant species.
