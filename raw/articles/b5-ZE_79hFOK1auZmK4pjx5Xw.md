# 文献精读 | 大规模大豆小肽-受体配对筛选系统

今天学习中国科学院遗传与发育生物学研究所李磊老师在Nature Plants发表的文章Large-scale pairing identifies a soybean phytocytokine-receptor module conferring disease resistance。这篇文章建立鉴定小肽-受体配对的筛选系统，用它筛选出大豆中ProPEP914-P98R小肽-受体对模块，并揭示其功能和机制。
背景：
植物基因组编码很多小肽（small secreted peptides，SSPs）来调控植物从发育到免疫响应的各方面。很多的SSPs被膜上激酶受体（receptor kinases，RKs）识别。其中，富含亮氨酸重复序列的受体激酶（leucine-rich repeat receptor kinases，LRR-RKs）是最大的家族之一。LRR-RKs X、XI、XII亚家族主要受体识别外源激发子和内源配体，XI亚家族主要识别内源小肽配体。
科学问题：已经表征的小肽-受体大都来自于一小部分模式植物。对作物中的小肽-受体了解有限，难以转移到作物中。
核心：建立鉴定小肽-受体配对的筛选系统，并用它筛选出大豆中ProPEP914 -P98R小肽受体对模块。
结论1：构建小肽-受体筛选系统
为了鉴定大豆中小肽受体，作者利用Clustal Omega将拟南芥中LRR-RK、X、XI、XII的亚家族成员和大豆蛋白组进行多重序列比对，获得了157个大豆同源受体序列（图1-1）。
图1-1
下一步，作者利用已经发表的植物SSP预测工具，结合手动筛选策略，整理出了一系列分泌小肽。作者合成了一个包含25个不同家族的55个小肽（图1-2）。由于有两个小肽在烟草中没有特异性，因此不进行后续研究。
图1-2
ROS爆发被选为小肽激活受体表达的指标（图1-3）。为了让ROS反映配体的结合而不是激酶的变化，作者把候选受体的激酶结构域换成了大豆PEPR1的激酶结构域。为了提高筛选效率，作者把4-6个嵌合受体共注射，找出有效的组合，再单独验证。作者共筛选7,700组合，鉴定出63对激活ROS的小肽-受体。
图1-3
基于Aequorin的钙离子内流检测实验表明，60对小肽-受体引起钙离子内流（图1-4）。
图1-4
结论2：GmPEP914和GmPEP890 作为植物细胞因子调节免疫系统
GmPEP914和GmPEP890最初通过质谱分析大豆叶片提取物被鉴定出来，会诱导ROS。这两个小肽也被作者的系统筛选出来了，作者随后验证了它们的功能。
GmPEP914和GmPEP890在大豆悬浮细胞中引起介质碱化。这是植物细胞因子诱导的防御反应的标志。RT–qPCR结果表明，GmProPEP914和GmProPEP890的表达会被flg22上调，也会被Psg（ Pseudomonas syringae pv. glycinea ）或Fusarium oxysporum的侵染激活（图2-1），暗示它们可能在PTI信号通路中发挥作用。
图2-1
接菌实验则表明，GmPEP914小肽的外源施加能抑制P. sojae和Psg 的生长（图2-2）。
图2-2
作者构建了propep914/890的双突大豆突变体，突变体丧失对Psg的抗性（图2-3）。同时，作者构建了GmProPEP890 过表达大豆株系，较WT 过表达株系对Psg的抗性更强（图2-3）。

结论3：小肽GmPEP914和GmPEP890介导的免疫依赖于GmP98R1和GmP98R2 受体
在作者的筛选系统中，小肽GmPEP914、GmPEP890和Glyma.12G007000、Glyma.12G007300在烟草中共表达诱导ROS爆发。这两个受体被命名为GmP98R1和GmP98R2作者构建了GmP98R1和GmP98R2的双突突变体p98r1r2-L1和p98r1r2-L2，发现它们在小肽GmPEP914和GmPEP890的处理下无法诱导ROS爆发，对Psg的抗性丧失（图3-1）。
图3-1
为了验证GmPEP914活性依赖于GmP98R1和GmP98R2，作者分析了用GmPEP914处理和不处理的Wm82和p98r1r2突变体的转录组。GmPEP914处理的Wm82较未处理的Wm82有2,738个表达差异基因（differentially expressed genes，DEGs），其中2,207个DEGs上调，GO分析表明这些上调基因大部分和响应外源诱导子和响应免疫有关（图3-2）。但是在用GmPEP914处理的p98r1r2突变体中，则无法诱导这些EDGs（图3-2）。说明小肽GmPEP914介导的免疫依赖于GmP98R1和GmP98R2 受体。
图3-2
BAK1是很多LRR-RKs的共受体。作者用AlphaFold-Multimer预测了GmP98R1受体、GmBAK1共受体、GmPEP914小肽的互作，预测结构表明小肽的C端介导三者复合体的形成（图3-3）。GmPEP914的最后一位氨基酸Y8可能和GmP98R1的侧链氨基酸R329和R331形成强烈的强阳离子-π相互作用界面。
图3-3
如果突变掉这三个关键氨基酸，会影响GmPEP914或GmP98R1的活性（图3-4）。
图3-4
等温滴定量热法 等实验证明 GmPEP914、GmPEP890和 GmP98R1、 GmP98R2 有纳摩尔的结合力（图3-5）。
图3-5
Co-IP实验和amiRNA-BAK1 表达抑制ROS爆发的实验（图3-6），说明了GmBAK1 对于GmPEP914诱导的免疫信号的必要性。

结论4：PEP914-P98R 模块存在于豆目和葫芦目
为了研究PEP914是否可以在豆科以外的植物中响应，作者在来自4个目（茄目、十字花目、葫芦目、豆目）的11个物种中测试了PEP914能否诱导ROS产生，仅来自葫芦目和豆目的物种响应PEP914（图4-1）。
图4-1
为了鉴定植物界中P98R同源序列，作者利用Clustal Omega从350个物种中挖掘GmP98R序列，共获得来自11个物种的同源序列（图4-2）。通过系统发育分析，获得两个谱系：仅含有葫芦目、豆目、包含GmP98R1和GmP98R2的Clade I，含有山毛榉目、蔷薇目、茄目、豆目、十字花目、含有的AtMIK2和MIK2Ld的Clade II（图4-2）。值得注意的是，MIK2识别小肽SCOOP。
图4-2
重复序列保守性作图分析表明MIK2和P98R的保守模式不同，MIK2有两个保守结合口袋，而P98R只有一个保守结合口袋I（图4-3）。
图4-3
为了研究该受体的功能保守性，作者克隆并在烟草中瞬时表达了它们的同源基因，来自黄瓜的CsP98Ra (Csativus_13267) 和 CsP98Rb (Csativus_7865),来自苜蓿的MtP98Ra (Mtruncatula_47775) 和MtP98Rb (Mtruncatula_40971)。CsP98Ra、MtP98Ra 、MtP98Rb均能响应PEP914 和PEP890，诱发ROS爆发（图4-4）。说明来自Clade I的受体保留了识别小肽的能力。

图4-4
共线性分析进一步说明了ProPEP914 和P98R于豆目基因组高度关联，和葫芦目距离更远（图4-5）。

总结：
（1）建立了小肽-受体筛选系统。
（2）筛选出大豆中ProPEP914 -P98R小肽受体对模块，并揭示其功能和机制。
（3）通过系统发育分析等证明其在豆目与葫芦目中具有保守性。
