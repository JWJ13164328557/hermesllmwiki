# 蓝光 (Blue Light) 与远红光 (Far-Red Light) 信号通路

> 基于知识库 121 篇相关文献 + PubMed 核心综述的系统整理

---

## 一、光受体总览

| 光受体 | 感知光质 | 定位 | 光转换 | 核心功能 |
|--------|---------|------|--------|---------|
| **PHYA** | 远红光/红光 | 细胞核+胞质 | Pr⇄Pfr (远红光→Pfr) | 远红光信号, FR-HIR |
| **PHYB** | 红光/远红光 | 细胞核(光下) | Pr⇄Pfr (红光→Pfr, FR→Pr) | **避荫反应核心** |
| **CRY1** | 蓝光/UV-A | 细胞核+胞质 | FAD光还原 | **蓝光光形态建成, 下胚轴抑制** |
| **CRY2** | 蓝光/UV-A | 细胞核 | FAD光还原 | 光周期开花, 蓝光响应 |
| **PHOT1/2** | 蓝光 | 质膜 | FMN光激活 | 向光性, 气孔开放, 叶绿体运动 |
| **ZTL/FKF1/LKP2** | 蓝光 | 细胞质 | LOV结构域 | 昼夜节律, 蛋白降解 |

## 二、蓝光信号通路 (CRY-HY5 通路)

### 2.1 核心通路图

```
蓝光 (380-500nm)
    │
    ├── CRY1/CRY2 (隐花色素)
    │     │
    │     ├── FAD光还原 → CRY寡聚化 → 活性构象
    │     │
    │     ├── CRY-COP1/SPA 互作 → COP1 E3连接酶活性抑制
    │     │     │
    │     │     ├── HY5/HYH 积累 (不被泛素化降解)
    │     │     │     │
    │     │     │     ├── 直接结合靶基因启动子 (G-box: CACGTG)
    │     │     │     │   → 光形态建成基因激活
    │     │     │     │   → 叶绿体发育基因
    │     │     │     │   → 花青素合成基因
    │     │     │     │
    │     │     │     ├── HY5-MSI1-PRC2 互作 → H3K27me3沉积
    │     │     │     │   → 抑制下胚轴伸长基因 (生长素通路)
    │     │     │     │   → 参考: Plant Cell 2026 (PMID:41518001)
    │     │     │     │
    │     │     │     └── 与 PIF 拮抗: HY5↑ → PIF靶基因↓
    │     │     │
    │     │     ├── BBX 家族蛋白稳定 → 光形态建成正调控
    │     │     └── CO 积累 → FT 激活 → 光周期开花
    │     │
    │     ├── CRY2-CIB1 互作 → FT 转录激活 (开花)
    │     └── CRY-BIC1 负反馈调节
    │
    ├── PHOT1/PHOT2 (向光素)
    │     ├── 蓝光→自磷酸化→NPH3/RPT2 → 生长素不对称分布
    │     └── 气孔开放: PHOT→BLUS1→H⁺-ATPase激活
    │
    └── ZTL/FKF1 (ZEITLUPE家族)
          └── 蓝光→ZTL-TOC1/PRR5 降解 → 昼夜节律调控
```

### 2.2 关键分子机制

#### CRY 光活化

- 暗处: CRY以单体形式存在, FAD为氧化态 (inactive)
- 蓝光照射: FAD→FADH° (阴离子半醌自由基) → CRY构象变化 → 寡聚化
- CRY PHR结构域结合 FAD; CCE结构域介导蛋白互作和信号传递
- 负调控: BIC1/BIC2 抑制 CRY2 光小体形成

#### COP1/SPA E3连接酶 — 光形态建成的分子开关

```
暗处/远红光下:
  COP1+SPA → E3泛素连接酶活性
    → HY5/HYH/LAF1/HFR1 泛素化 → 26S蛋白酶体降解
    → 光形态建成基因被抑制
    → PIF稳定 → 暗形态建成

蓝光下:
  CRY1/2 → 与SPA1互作 → COP1-SPA复合体解离
    → HY5等转录因子积累
    → 光形态建成基因激活
    → PIF被磷酸化降解
```

#### HY5 — 蓝光信号核心转录因子

| 功能 | 机制 | 参考文献 |
|------|------|---------|
| 光形态建成 | 结合G-box启动子→激活光响应基因 | CRY综述 |
| 下胚轴抑制 | 与MSI1-PRC2→H3K27me3→抑制生长素合成/信号基因 | Plant Cell 2026 |
| 花青素合成 | 激活PAP1/MYB75等MBW复合体 | — |
| 叶绿体发育 | 激活LHCB/RBCS等光合基因 | — |
| 与PIF拮抗 | HY5和PIF竞争靶基因启动子 | PNAS 2024 |
| 下胚轴vs次生生长分叉 | 蓝光→CRY→HY5→下胚轴抑制; 但次生生长通过不同机制 | PNAS (PMID:39585973) |

### 2.3 知识库关键文献

| 文献 | 期刊 | 核心发现 |
|------|------|---------|
| HY5蓝光信号时空分叉调控木材发育 | PNAS 2024 | CRY→HY5→下胚轴抑制 vs 次生生长不同响应 |
| MSI1-HY5-PRC2表观抑制 | Plant Cell 2026 | HY5→PRC2→H3K27me3→IAA通路 |
| TCP21-phyB-HY5光形态建成 | Plant J 2026 | TCP21整合phyB和HY5通路 |
| 昼夜质子梯度 | Cell 2026 | CCA1→表皮/伴胞pH反相→器官生长 |

## 三、远红光/避荫信号通路 (PHYB-PIF 通路)

### 3.1 核心通路图

```
遮荫 (低R:FR, 远红光富集)
    │
    ├── PHYB (光敏色素B)
    │     │
    │     │  高R:FR (日光): PHYB(Pr)→PHYB(Pfr) (活性形式)
    │     │      → Pfr入核 → 磷酸化PIF→PIF降解
    │     │      → 光形态建成, 抑制伸长
    │     │
    │     │  低R:FR (遮荫): PHYB(Pfr)→PHYB(Pr) (非活性)
    │     │      → PIF3/4/5/7 积累 (不被降解)
    │     │      │
    │     │      ├── PIF4/PIF7 → 直接激活生长素合成基因 (YUCCA8/9)
    │     │      │     → IAA↑ → PIN3极性定位 → 生长素侧向运输
    │     │      │     → 表皮/皮层细胞伸长
    │     │      │
    │     │      ├── PIF4/PIF5 → 激活 GA20ox → GA↑
    │     │      │     → DELLA蛋白降解 (GID1-GA)
    │     │      │     → 解除DELLA对PIF的抑制 → 正反馈
    │     │      │
    │     │      ├── PIF7 → 直接激活 EXPANSIN/XTH (细胞壁松弛)
    │     │      │     → 快速伸长响应 (30min)
    │     │      │
    │     │      └── PIF4/PIF5 → 激活生长促进基因 (PRE/HLH家族)
    │     │            → 与PAR1/PAR2 (非DNA结合HLH) 拮抗
    │     │
    │     ├── PHYB-PIF 调控 HY5 表达
    │     │   → 遮荫下PIF积累 → 间接抑制HY5
    │     │
    │     └── PHYB 调控开花时间
    │         → PHYB→CO降解 (长日条件) vs PHYA→CO稳定
    │
    ├── PHYA (光敏色素A)
    │     └── 极低R:FR (深层遮荫) → PHYA持续激活
    │           → 抑制过度伸长 (安全阀机制)
    │
    └── 避荫综合症 (SAS) 表型
          ├── 下胚轴/节间伸长 ↑↑
          ├── 叶面积减小
          ├── 叶柄伸长, 叶片上举 (hyponasty)
          ├── 提前开花
          └── 分枝减少
```

### 3.2 关键分子机制

#### PHYB 光转换

- **Pr (非活性)**: λmax=660nm (红光吸收); 细胞质定位
- **Pfr (活性)**: λmax=730nm (远红光吸收); 核定位
- 日光 (R:FR>1): Pr→Pfr (PHYB激活) → 入核 → PIF磷酸化降解
- 遮荫 (R:FR<0.5): Pfr→Pr (PHYB失活) → PIF积累
- **PHYB 是 R:FR 的分子比率计**

#### PIF 转录因子家族

| PIF | 主要功能 | 调控 |
|-----|---------|------|
| **PIF3** | PHYB直接互作, 光形态建成早期 | 红光→PIF3快速磷酸化降解 |
| **PIF4** | 热形态建成+避荫核心, 生长促进 | 高温稳定; 遮荫稳定 |
| **PIF5** | 与PIF4冗余, 避荫伸长 | 遮荫稳定 |
| **PIF7** | 快速避荫响应 (30min), 去磷酸化激活 | 遮荫→快速去磷酸化 |
| **PIF1/PIL5** | 种子萌发光调控 | 光下降解 |

#### PIF-激素轴 (避荫的核心输出)

```
遮荫 (低R:FR)
  → PIF4/5/7 积累
    ├── 生长素 (IAA):
    │   PIF→YUCCA8/9 (IAA合成) ↑
    │   PIF→PIN3/PIN7 (IAA转运) ↑
    │   → 子叶→下胚轴的IAA流增强
    │
    ├── 赤霉素 (GA):
    │   PIF→GA20ox ↑ + GA2ox ↓
    │   → GA↑ → DELLA降解 → PIF再激活 (正反馈环)
    │
    ├── 油菜素内酯 (BR):
    │   PIF→BES1/BZR1 协同激活靶基因
    │
    └── 乙烯:
        遮荫→乙烯↑ → ERF→PIF协同
```

#### 负调控机制

| 因子 | 机制 |
|------|------|
| **HFR1** | 非DNA结合HLH, 与PIF4/PIF5形成无活性异源二聚体 |
| **PAR1/PAR2** | 非DNA结合HLH, 抑制PIF4转录活性 |
| **ATHB2/HAT** | HD-ZIP, 避荫正调控, 被PIF激活, 反馈放大 |
| **HY5** | 与PIF竞争靶基因结合位点 (拮抗) |
| **DELLA** | 直接与PIF互作, 阻止PIF与DNA结合 |

| 文献 | 期刊 | 核心发现 |
|------|------|---------|
| HY5蓝光木材发育 | PNAS 2024 | CRY-HY5 vs PHYB-PIF 在次生生长中的分叉 |

## 四、蓝光 vs 远红光 — 信号通路对比

| 维度 | 蓝光通路 (CRY-HY5) | 远红光/遮荫通路 (PHYB-PIF) |
|------|-------------------|--------------------------|
| **光受体** | CRY1/CRY2 (隐花色素) | PHYB (光敏色素B) |
| **光转换** | FAD 光还原 (不可逆) | Pr⇄Pfr (可逆, 依赖R:FR) |
| **核心E3连接酶** | COP1-SPA (被CRY抑制) | COP1-SPA + CUL4 (调控不同底物) |
| **核心TF** | **HY5/HYH** (光下积累) | **PIF3/4/5/7** (遮荫下积累) |
| **下胚轴/节间** | **抑制伸长** (蓝光→HY5→PRC2→IAA↓) | **促进伸长** (FR→PIF→YUCCA/IAA↑+GA↑) |
| **花青素** | 促进 (HY5→PAP1/MYB75) | 抑制 |
| **叶绿体发育** | 促进 | — |
| **开花** | CRY2-CIB1→FT (长日促进) | PHYB-CO降解 (长日抑制) |
| **气孔** | PHOT1/2→气孔开放 | — |
| **昼夜节律** | CRY→输入通路; ZTL→PRR/TOC1降解 | PHYB→输入通路 |
| **交叉点** | CRY-SPA互作 (抑制COP1) | PHYB-PIF互作 (促进PIF降解) |
| **在遮荫中的角色** | 蓝光衰减→CRY活性↓→HY5↓→脱抑制 | FR富集→PHYB失活→PIF↑→促进伸长 |
| **共同作用** | 遮荫 = 蓝光衰减 + R:FR降低 = **双重脱抑制** | |

## 五、蓝光与远红光在大豆节间伸长中的整合模型

```
        遮荫环境 (密植大豆冠层)
              │
    ┌─────────┴─────────┐
    │                    │
 蓝光衰减              R:FR 降低
 (蓝光↓)              (远红光↑)
    │                    │
  CRY1/2 活性↓        PHYB Pfr→Pr (失活)
    │                    │
  COP1-SPA 活性恢复     PIF3/4/5/7 积累
    │                    │
  HY5/HYH 降解↑         ┌────┼────┐
    │                    │    │    │
  脱抑制:              IAA↑  GA↑ 细胞壁
  - PRC2↓              (YUCCA) (GA20ox) 松弛
  - IAA通路基因↑         │    │    │
  - 细胞壁松弛基因↑       │    │    │
    │                    │    │    │
    └────────┬───────────┘    │    │
             │                │    │
        协同促进节间伸长       │    │
             │                │    │
    ┌────────┴────────────────┴────┴───┐
    │  细胞类型特异响应:                │
    │  表皮: 蓝光→HY5→抑制伸长         │
    │  皮层: IAA梯度→细胞扩张           │
    │  维管束: PHYB-PIF→次生壁调控      │
    │  髓: GA→细胞伸长                  │
    └──────────────────────────────────┘
```

## 六、关键未解决问题

1. **蓝光和远红光信号在细胞类型水平的空间差异**: 不同组织层(表皮/皮层/维管束)的 CRY vs PHYB 表达和信号强度是否不同?
2. **双重信号整合的分子节点**: 蓝光衰减 + FR富集如何被整合? 是通过HY5-PIF拮抗还是有未知的整合因子?
3. **节间 vs 下胚轴的特异性**: 大豆节间对光质的响应是否与拟南芥下胚轴机制相同? 次生生长(节间成熟)中的光信号机制?
4. **表观遗传记忆**: 光质变化是否在染色质水平留下"记忆"影响后续发育?
5. **自然变异**: 大豆品种间光质敏感性的遗传基础是什么?
