# 大豆节间光质响应空间转录组研究方案

> 研究范式: **空间 (组织层)** × **发育梯度 (节位)** × **光质 (WL/LBL/LRFR)**
> 取材设计: V3-V4期, 光质处理7-14天后, 终点取样

---

## 一、研究背景与立项依据

### 1.1 核心问题

大豆株型由节间伸长决定，密植下**避荫综合症 (SAS)** 导致倒伏减产。**低蓝光 (LBL)** 和**低R:FR (LRFR)** 分别模拟冠层遮荫的两个特征——蓝光衰减和远红光富集，通过 cryptochrome→HY5 和 phytochrome B→PIF 通路差异化调控节间伸长[1-3]。

**关键空白**: 在细胞类型分辨率上，光质如何在不同发育阶段的节间中空间差异化调控基因表达和细胞行为，几乎完全未知。

### 1.2 知识库核心支撑

| 文献 | 方法 | 可借鉴之处 |
|------|------|-----------|
| 大豆Cell时空图谱[4] | scATAC+scRNA 10组织 | 大豆细胞类型参考标记基因 |
| 小麦穗空间[5] | Stereo-seq 单细胞分辨率 | 节间同源器官的空间图谱方法 |
| 昼夜质子梯度[6] | pH传感器+遗传学 | CCA1→表皮/伴胞反相pH振荡 |
| HY5-MSI1-PRC2[7] | ChIP+RNA-seq | HY5→H3K27me3→IAA通路 |
| 番茄愈伤光再生[8] | 空间转录组 | 光诱导特定细胞类型响应 |
| PlantCellChat[9] | R包 | 植物CCC空间推断工具 |
| NtTAC1-PIN3[10] | snRNA+空间代谢 | 生长素梯度→株型调控 |
| 玉米锈病免疫[11] | sc+空间+VIGS | 细胞类型特异防御模块 |

---

## 二、核心假设

> **不同光质 (WL/LBL/LRFR) 通过细胞类型特异的转录重编程，沿大豆节间发育梯度 (1st→3rd) 空间差异化地调控细胞伸长程序与次生壁建成平衡——CRY-HY5通路主要在表皮/皮层介导LBL响应，PHYB-PIF通路主要在维管束介导LRFR响应，GA/IAA空间梯度的重置是连接光感知与伸长执行的核心输出。**

**辅助假设**:

| # | 假设 |
|---|------|
| H1 | 大豆节间含≥15种细胞亚型，沿纵轴(1st→3rd)呈分生→成熟发育梯度 |
| H2 | LBL和LRFR通过不同细胞类型促进伸长——LBL→表皮/皮层，LRFR→维管束/髓 |
| H3 | 光信号通过表皮→皮层→维管束的细胞间通讯空间级联传递 |
| H4 | GmHY5(CRY通路)和GmPIFs(PHYB通路)分别在LBL和LRFR下被差异化调控 |
| H5 | GA合成/代谢基因(GA20ox/GA2ox)沿纵轴和径向的空间表达模式被光质量塑 |
| H6 | 次生壁建成(NAC/MYB模块)在第一节间被光质独立于伸长差异调控 |

## 三、实验设计

### 3.1 材料与处理

```
物种: 大豆 Williams 82 (有参考基因组 + Cell时空图谱[4])
时期: V3-V4期 (第三节间开始快速伸长)
处理: 光质处理 7-14天 (达到稳定表型差异)
  ├── WL  白光对照 (R:B ≈ 1:1, R:FR ≈ 1.2)
  ├── LBL 低蓝光 (R:B ≈ 10:1, 蓝光减少90%)
  └── LRFR 低R:FR (R:FR ≈ 0.3, 模拟遮荫)
生物学重复: n≥3

取样:
  第一节间 (基部, 已停止伸长, 成熟组织)
  第二节间 (中部, 伸长减缓, 过渡态)
  第三节间 (顶部, 快速伸长, 分生活跃)
```

### 3.2 实验组设计

```
        空间维度 (横切面组织层)
        ┌──────────────────────────────┐
        │ 表皮│皮层│韧皮部│形成层│木质部│髓 │
        ├──────────────────────────────┤
发育   1st│ WL  │  WL  │  WL  │  WL  │  WL  │
维度   (基部成熟)
(节位) 2nd│ LBL │ LBL │ LBL │ LBL │ LBL │
       (中部过渡)
       3rd│LRFR │LRFR │LRFR │LRFR │LRFR │
       (顶端伸长)
        └──────────────────────────────┘

核心样本: 3节位 × 3光质 × 3重复 = 27个横切面
补充: 每个节位1个纵切面 × 3光质 = 9个纵切面 (捕获纵轴发育梯度)
```

### 3.3 空间转录组流程

```
冷冻切片 (10μm) 
  ├── 横切面: 每个节位中部
  └── 纵切面: 沿节间纵轴
       ↓
Stereo-seq (华大, 500nm spot) 或 Visium HD (10x, 2μm)
       ↓
同时保留相邻切片用于:
  ├── PAS染色 (解剖结构确认)
  ├── 甲苯胺蓝染色 (细胞壁木质化程度)
  └── 免疫组化/IHC (关键蛋白空间定位验证)
```

### 3.4 辅助实验

| 实验 | 目的 | 样本 |
|------|------|------|
| 激素定量 (LC-MS/MS) | IAA/GA/ABA/JA/BR 沿节间梯度 | 3节位×3光质 |
| 细胞壁组分分析 | 纤维素/半纤维素/木质素含量 | 1st vs 3rd, WL vs LRFR |
| 组织学切片 | 细胞大小/层数/髓腔面积量化 | 3节位×3光质 |
| qRT-PCR | 空间DE结果的独立验证 | 候选基因 |

```
Spatial Transcriptomics Raw Data
│
├── 1. 空间预处理
│   ├── 组织分割 (基于H&E/PAS染色图像)

│   └── 空间域聚类 (SpaGCN / BayesSpace / STAGATE)
│
├── 2. 细胞类型注释 — Aim 1

│   ├── 空间反卷积 (RCTD / SPOTlight)
│   │   每个spot → 细胞类型比例矩阵
│   └── 纵切面: spatialDE鉴定纵轴梯度基因
│
├── 3. 空间差异表达 — Aim 2
│   ├── 同节位内: 每个空间域单独做 WL vs LBL vs LRFR
│   │   工具: SPARK-X / spatialDE / Giotto
│   ├── 节间比较: 1st vs 2nd vs 3rd (WL基线)
│   ├── 交互分析: 节位 × 光质 (哪些基因的DE依赖节位?)
│   └── 光受体通路富集 (CRY-HY5 vs PHYB-PIF 靶基因)
│
├── 4. 细胞间通讯 — Aim 3
│   ├── PlantCellChat: 每个样本独立运行[9]
│   ├── 比较: WL vs LBL vs LRFR 的CCC网络差异
│   ├── 空间配体-受体共定位评分
│   └── 重点关注: 生长素转运(PIN/LAX/ARF), 
│       小肽信号(CLE/CEP/EPFL), 糖转运(SWEET)
│
├── 5. 基因调控网络 — Aim 4
│   ├── SCENIC+ (空间GRN推断)
│   ├── hdWGCNA (高分辨率共表达网络)
│   ├── 光信号+激素通路整合 (HY5/PIF/ARF/DELLA)
│   └── CRE motif富集 (参考大豆Cell CRE数据库[4])
│
└── 6. 跨节间比较整合
    ├── 纵向梯度基因的节位×光质交互
    ├── 次生壁模块 (NAC/MYB) 的空间分布
    └── 细胞类型比例的节位-光质变化
```

## 五、Aim 1: 大豆节间空间细胞图谱

**科学问题**: 大豆节间(1st/2nd/3rd)的空间细胞类型组成是什么？沿纵轴的发育梯度如何？

**方法**:
- WL 0h横切面+纵切面
- SpaGCN/BayesSpace 空间域聚类
- 已知marker注释 + de novo聚类
- 纵切面 spatialDE 鉴定纵轴梯度基因
- 参考大豆Cell时空图谱[4]验证注释

**关键细胞类型预测**:

| 细胞类型 | 标记基因(拟南芥同源) | 大豆候选 |
|----------|---------------------|---------|
| 表皮细胞 | ATML1, PDF2, CER6 | GmML1, GmCER6 |
| 皮层薄壁 | SCR, SHR, CO2 | GmSCR, GmSHR |
| 内皮层 | CASP1, MYB36 | GmCASP1 |
| 韧皮部伴胞 | SUC2, AHA3 | GmSUC2 |
| 韧皮部筛管 | SEOR1, APL | GmAPL |
| 形成层 | WOX4, PXY/TDR | GmWOX4, GmPXY |
| 木质部导管 | VND6, VND7 | GmVND6/7 |
| 木质部纤维 | NST1, MYB46, MYB83 | GmNST1 |
| 髓薄壁 | WOX4, UGT | GmWOX4 |

**预期产出**:
- 大豆节间空间细胞参照图谱 (>15种细胞亚型)
- 沿纵轴的发育轨迹 (分生→伸长→成熟)
- 纵轴梯度基因集 (>500基因)

## 六、Aim 2: 光质对节间空间转录组的重塑

**科学问题**:
- Q2.1: 不同光质改变了哪些细胞类型的基因表达程序？
- Q2.2: 光质响应是否依赖于发育阶段(节位)？
- Q2.3: LBL和LRFR的响应通路有何异同？

**核心分析**:

### 2.1 空间差异表达

对每个节位内每个空间域，进行 WL vs LBL vs LRFR 的差异分析:
```
空间域(表皮) × WL vs LBL → LBL表皮DEGs
空间域(表皮) × WL vs LRFR → LRFR表皮DEGs
空间域(维管束) × WL vs LBL → LBL维管束DEGs
...
```

### 2.2 通路富集对比

| 比较 | 预期富集通路 | 参考 |
|------|-------------|------|
| LBL vs WL | CRY-HY5靶基因↓, 细胞壁松弛↑, IAA响应↑ | HY5-MSI1[7] |
| LRFR vs WL | PIF靶基因↑, GA合成↑, 生长素转运↑ | HY5木材[2] |
| LBL vs LRFR | 蓝光特异: HY5通路; FR特异: PIF/YUCCA通路 | — |

### 2.3 节位×光质交互

鉴定在第三节间特异的LBL/LRFR响应基因 (发育阶段依赖性):
```
gene ~ 节位 + 光质 + 节位:光质
交互显著基因 → 光质效应依赖于发育阶段
```

### 2.4 光受体通路基因的空间表达

绘制光受体/信号元件本身的空间分布:
- GmCRY1/2: LBL感知 — 预期在表皮富集
- GmPHYB: LRFR感知 — 预期在维管束富集  
- GmHY5: CRY通路核心 — 核定位, 表皮/皮层
- GmPIF3/4/7: PHYB通路核心 — 核定位, 维管束/髓

**预期产出**:
- 完整的空间-光质差异基因集
- LBL vs LRFR 空间响应差异通路
- 节位依赖的光响应基因群

## 七、Aim 3: 光信号的细胞间通讯网络

**科学问题**:
- Q3.1: 光信号感知后，如何在组织水平通过细胞间通讯传递？
- Q3.2: 不同光质下，哪些CCC通路发生显著变化？

**方法**: PlantCellChat[9] 对每个样本独立运行

**重点关注信号通路**:

| CCC通路 | 配体 | 受体 | 预期变化 | 参考 |
|---------|------|------|---------|------|
| 生长素转运 | IAA | TIR1/AFB→ARF | LRFR: 表皮→皮层 IAA流增强 | NtTAC1-PIN3[10] |
| CLE肽信号 | CLE41/44 | PXY/TDR | 光质→形成层活性调控 | — |
| EPFL肽 | EPFL4/6 | ERECTA | 表皮→内部信号, LBL特异 | 茎尖SCN[12] |
| 糖转运 | Sucrose | SWEET/STP | 韧皮部→皮层, LBL下减弱? | — |
| pH信号 | H⁺ | AHA | CCA1调控, 表皮↔伴胞反相 | Cell昼夜[6] |

**预期产出**:
- 光质特异CCC网络图谱
- 生长素极性运输的空间证据
- CCC网络差异与节间伸长量的定量关联

## 八、Aim 4: 基因调控网络与核心因子鉴定

**科学问题**:
- Q4.1: 哪些转录因子是光质调控节间发育的核心节点？
- Q4.2: 光信号如何耦联激素(GAIAA)和次生壁(NAC/MYB)通路？

**核心分析**:

### 4.1 SCENIC+ 空间GRN

对每个样本运行 SCENIC+，鉴定:
- 每个细胞类型的核心 Regulon
- LBL vs LRFR下被差异调控的 Regulon
- 空间共表达的TF-靶基因模块

### 4.2 hdWGCNA共表达网络

- 跨所有样本构建共表达网络
- 鉴定与光质/节位显著关联的模块
- 提取模块 hub 基因

### 4.3 多维整合

```
光质处理
  ↓
光受体激活 (CRY/PHYB) — 空间定位已知
  ↓
核心TF (HY5/PIF/ARF) — SCENIC+鉴定
  ↓
下游通路:
  ├── 细胞伸长: EXPA, XTH, 细胞壁松弛
  ├── 激素代谢: GA20ox/GA2ox, YUCCA, PIN
  └── 次生壁: NAC, MYB46/83, CesA
```

**预期核心TF候选**:

| TF | 通路 | 预期空间表达 | 光质响应 |
|----|------|-------------|---------|
| GmHY5 | CRY蓝光 | 表皮/皮层核定位 | LBL下表达↓ |
| GmPIF3a/b | PHYB远红光 | 维管束/髓核定位 | LRFR下稳定↑ |
| GmARF6/8 | 生长素响应 | 表皮/皮层 | LRFR下激活 |
| GmPRE1 | HLH伸长正调控 | 伸长区特异 | LRFR下↑ |
| GmNST1 | NAC次生壁主控 | 1st节间木质部 | LRFR下差异 |

## 九、Aim 5: 关键因子的功能验证

| 基因 | 假说 | 方法 | 预期表型 |
|------|------|------|---------|
| GmHY5 | LBL→HY5↓→节间伸长 | 毛根转化OE | HY5-OE 对LBL不敏感 |
| GmPIF3 | LRFR→PIF3↑→节间伸长 | CRISPR敲除 | pif3 对LRFR不敏感 |
| GmPRE1 | 细胞伸长执行因子 | OE/RNAi | PRE1-OE 节间增长 |
| GmARF6 | IAA信号执行 | RNAi | 生长素响应减弱 |
| GmNST1 | 次生壁主控 | OE | 1st节间早熟木质化 |

**验证管线**: 毛根转化 (2-3周快速筛选) → CRISPR稳定转化 (1-2个核心基因)

## 十、创新点

1. **首次构建大豆节间空间细胞参照图谱** — 填补作物茎秆发育的空间参照空白
2. **在空间维度上区分LBL和LRFR的差异调控通路** — 不同光受体→不同细胞类型→不同下游
3. **揭示光信号的空间传递机制** — 从表皮感知→内部组织执行的CCC级联
4. **整合空间转录组+激素+次生代谢的多维调控网络**

## 十一、潜在风险

| 风险 | 对策 |
|------|------|
| 节间木质化, RNA降解 | V3-V4期幼嫩材料; EDTA脱钙; RIN>6可行 |
| Stereo-seq成本高 | 横切面 Stereo-seq + 纵切面 Visium; n=2重复 |
| 空间分辨率识别细胞亚型不足 | 补充snRNA-seq提高分辨率 |
