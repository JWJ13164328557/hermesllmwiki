# 大豆节间光质响应时空转录组研究方案

> 研究范式: **空间 (X-Y)** × **发育梯度 (节位)** × **时间 (处理后)** = 三维时空解析
> 基于 88 篇植物单细胞/空间组学文献的知识库设计

---

## 一、研究背景与立项依据

### 1.1 大豆株型与光环境

大豆 (Glycine max L.) 是全球最重要的油料和蛋白质作物。株型直接控制大豆产量潜力，**节间伸长**决定植株高度、分枝角度和冠层结构[1]。密植条件下，大豆通过**避荫综合症 (SAS)** 促进节间过度伸长导致倒伏减产，由光受体感知 R:FR 降低和蓝光衰减触发[2]。

**低蓝光 (LBL)** 和**低 R:FR (LRFR)** 分别模拟冠层遮荫的两个特征，通过不同光受体通路 (cryptochrome→HY5, phytochrome B→PIF) 差异化调控伸长[3-4]。然而在组织/细胞类型分辨率上，光质如何沿节间发育梯度**随时间动态**空间差异化调控细胞行为，几乎完全未知。

### 1.2 为什么时间维度不可或缺？

光信号本质上是**动态过程**——从光受体激活(秒-分)→转录重编程(时)→细胞伸长(天)，各阶段发生在不同细胞类型中。忽略时间维度将混淆"原因"与"结果"，无法区分**驱动因子**与**伴随现象**。

关键证据来自知识库: Cell昼夜节律研究[9]显示 CCA1 驱动表皮/伴胞 pH 振荡具有明确的**相位差**; 玉米锈病免疫[8]揭示了 24h vs 48h 的**时序免疫模块切换**; 烟草抗虫[16]通过时间序列 scRNA-seq+空间代谢组捕获了**早期防御→晚期代谢**的时序转变。

```
时间维度揭示的关键生物学问题:
├── 时序因果: 哪些细胞类型最早响应光质变化? (驱动因子)
├── 时序传递: 信号如何在数小时内从感知位点传播到效应位点?
├── 时序模块: 早期转录重编程→中期激素重分布→晚期细胞壁重塑
└── 昼夜门控: 光质响应是否被生物钟门控? (ZT时间依赖性)
```

## 二、核心假设

> **光质信号沿空间维度(组织层)×发育维度(节位)×时间维度(处理后时程)三维差异化调控大豆节间发育——早期(1-6h)通过光受体在表皮/维管束激活转录级联, 中期(12-24h)通过细胞通讯传递到效应细胞并重置激素梯度, 晚期(48h-7d)驱动细胞伸长和次生壁重塑, 且这一时序程序受昼夜节律门控。**

**可检验假设群**:

| # | 假设 | 维度 |
|---|------|------|
| H1 | 大豆节间含≥15种细胞亚型, 沿纵轴呈分生→成熟梯度 | 空间+发育 |
| H2 | LBL/LRFR 激活**不同时序**的细胞类型特异响应模块 | 空间+时间 |
| H3 | 表皮是最早的光响应中枢(1-6h) → 信号在12-24h传播到内部组织 | 空间+时间 |
| H4 | GA/IAA 空间梯度在光质处理后12-24h发生显著重置 | 空间+时间 |
| H5 | 昼夜节律门控光质响应 — CCA1/LHY 表达相位决定光响应窗口 | 时间 |
| H6 | GmHY5/GmPIFs 是整合光信号的时间节点TF | 空间+时间 |

### 3.2 时间点的生物学依据

| 时间点 | 捕获的生物学过程 | 依据 |
|--------|----------------|------|
| **0h** | 基线空间图谱, 节间间差异 | Aim 1 |
| **1-6h** | 早期转录响应, TF激活, 光受体信号 | 玉米锈病 24h[8], 昼夜门控[9] |
| **12-24h** | 激素重分布, 细胞通讯激活, 靶基因表达 | 烟草抗虫时序[16], HY5-PRC2[11] |
| **48-72h** | 细胞伸长启动, 细胞壁酶基因上调 | 干旱衰老[17] |
| **7d** | 稳定态表型, 次生壁建成, 细胞组成变化 | 避荫综合症[2] |

### 3.3 ZT时间标准化

生物钟对光信号响应有门控效应[9]。所有处理在 **ZT0 (开灯时)** 开始; 设置 **ZT0 vs ZT12 对比组** (第3节间, WL vs LRFR, 24h) 以区分光质直接效应与昼夜节律效应。

## 五、研究目标与具体内容

### Aim 1: 大豆节间空间细胞图谱与发育梯度

**目标**: 建立 WL 0h 条件下第1/2/3节间的空间转录组基线图谱。

**区别于纯空间分析**: 加入**纵切面**捕获沿纵轴的连续发育梯度。

**方法**:
- 横切面 (3节位) + 纵切面 (整条节间)
- Stereo-seq (500nm spot) / Visium HD (2μm)
- SpaGCN 空间聚类 → 手动标注解剖结构
- 参考大豆Cell时空图谱[6]标记基因
- spatialDE 鉴定纵轴梯度基因
- RNA velocity 推断发育方向

**预期**:
- A1.1: ≥6大类15+细胞亚型, 含纵向连续发育梯度
- A1.2: 基部→顶端: 次生壁模块递减, 细胞分裂模块递增
- A1.3: RNA velocity 方向与解剖位置一致

---

### Aim 2: 光质响应的时空动态重塑

**目标**: 鉴定 LBL/LRFR 处理下不同时间点、不同节位的空间基因表达变化。

**分析方法**:

**2.1 时序空间差异表达 (核心分析)**:
- 每个空间域 × 每个时间点: WL vs LBL, WL vs LRFR
- **时序聚类**: 将所有光响应基因按时程表达模式分为:
  - *Early-Transient* (1-6h峰值→消退): TF/信号转导
  - *Early-Sustained* (1-6h→持续): 核心调控因子
  - *Mid-Activated* (12-24h峰值): 激素代谢/转运
  - *Late-Activated* (48h-7d持续上升): 细胞壁酶/次生代谢

**2.2 空间响应时序动画**:
- 将每个时间点的空间DE热图叠加, 生成光质响应在组织层面的"传播动画"
- 鉴定响应传播方向: 表皮→皮层→维管束, 还是维管束→表皮?

**2.3 细胞类型比例时序变化**:
- 每个时间点 × 每个节位的细胞类型反卷积比例
- 追踪髓腔扩大/次生壁加厚的时间-空间-位点三维动态

**2.4 节间-时间交互作用**:
- 第三节间是否比第一节间更快响应? (发育阶段依赖性)
- 交互项基因: `节位 × 时间` 显著的基因集

**预期**:
- A2.1: LBL 表皮 Early-Transient 富集 CRY-HY5 靶基因
- A2.2: LRFR 维管束 Mid-Activated 富集 PIF-YUCCA 模块
- A2.3: 表皮 6h 响应 → 皮层/维管束 24h 响应 → 传播延迟 12-18h
- A2.4: 第三节间响应幅度 > 第一节间 (2-3倍)
- A2.5: 7d 出现细胞组成显著变化 (髓腔/木质部面积)

---

### Aim 3: 时空细胞间通讯网络

**目标**: 解析光质处理前后, 细胞间通讯网络在**时间维度的动态重构**。

**创新分析**:

**3.1 时序细胞通讯 (PlantCellChat + 时间维度)**:
```python

for tp in [0h, 6h, 24h, 72h, 7d]:
    pcc = PlantCellChat(st_data_tp)
    pcc.infer_ccc()
    # 比较相邻时间点通讯变化
    if tp != 0h:
        delta = compare_ccc(tp, prev_tp)
        # 鉴定: 新增通讯/消失通讯/增强通讯
```

**3.2 信号传播轨迹**:
- 鉴定在时间序列上连续变化的 CCC 通路 (线性或非线性)
- 追踪生长素(PIN→ARF)和赤霉素信号的**空间-时间传播波**
- 小肽信号 (CLE/CEP/EPFL) 的时序激活模式

**3.3 昼夜节律门控分析**:
- ZT0 vs ZT12 处理对比 — 鉴定节律依赖的 CCC 通路
- CCA1/LHY/PRR 靶基因的空间表达与日周期关系

**预期**:
- A3.1: 6h 表皮→皮层 CCC 增强 (早期信号传递)
- A3.2: 24h 韧皮部→木质部母细胞 CCC 增强 (营养重分配)
- A3.3: 生长素流(PIN3/LAX2)沿径向的传播波速 ~5-10μm/h
- A3.4: ZT0 处理比 ZT12 处理诱导的 CCC 变化幅度大 ~40%

---

### Aim 4: 时空基因调控网络

**目标**: 构建整合空间-时间-发育的三维基因调控网络。

**核心分析**:

**4.1 时序 SCENIC+**:
- 每个时间点 × 每个空间域独立运行 SCENIC+
- 鉴定随时间的 Regulon 激活/抑制动态
- 区分"瞬时调控" (TF活性快速波动) vs "持续调控" (TF活性稳定变化)

**4.2 时序 WGCNA**:
- 跨所有时间点构建共表达网络 → 鉴定时序模块
- 模块-光质-时间-节位关联分析
- 核心: 哪个模块的时序表达模式最能解释节间长度差异?

**4.3 多组学因子分析 (MOFA+)**:
- 整合: 空间转录组 + (可选)snATAC-seq + 激素定量数据
- 分解为潜在因子, 每个因子的空间-时间-光质-节位载荷
- 鉴定"光质因子""节位因子""时间因子"及其对应的基因模块

**4.4 CRE 时序分析**:
- 参考大豆Cell CRE 数据库[6]
- 鉴定 Early-Transient vs Late-Activated 基因启动子的motif差异
- 预测时序调控的逻辑门 (AND/OR gate)

**预期**:
- A4.1: GmPIF3 Regulon 在 LRFR 6h 激活, 持续至 72h
- A4.2: GmHY5 Regulon 在 LBL下持续被抑制
- A4.3: GA20ox/GA2ox 模块在 24h 发生显著空间位移
- A4.4: NAC-MYB 次生壁模块在 7d 时的空间定位
- A4.5: MOFA 鉴定 3-5 个关键因子解释 >60% 变异

---

### Aim 5: 关键时空调控因子的功能验证

**目标**: 实验验证 Aim 4 鉴定的核心 TF 在时空调控中的功能。

**验证策略** (利用时间维度进行因果推断):

| 基因 | 假说 | 验证方法 | 预期表型 |
|------|------|---------|---------|
| GmPIF3 | LRFR→PIF3→节间伸长 | CRISPR敲除; 时间序列RNA-seq | pif3 突变体对 LRFR 不敏感, 7d 节间缩短 |
| GmHY5 | LBL→HY5抑制→伸长 | 过表达(OE) | HY5-OE 下 LBL 节间伸长受抑 |
| GmPRE1 | 细胞伸长执行因子 | OE/RNAi | PRE1-OE 节间延长; RNAi 缩短 |
| GmARF6 | 生长素响应执行者 | RNAi+激素测定 | ARF6-RNAi 下 IAA梯度消失 |
| GmCCA1 | 昼夜门控光响应 | CRISPR+ZT0/ZT12处理 | cca1突变体光响应时序紊乱 |

**快速验证管线**:
```
毛根转化 (2-3周)
  → OE/RNAi 候选基因
  → 光质处理 (WL/LBL/LRFR, 5时间点)
  → 表型: 节间长度+直径+细胞大小
  → RNA-seq: 靶基因时序表达
  → 选择核心基因 → 稳定转化 (大豆CRISPR, 6-12月)
```

## 六、预期研究贡献

### 理论贡献
1. **首次构建作物节间发育的三维(空间×发育×时间)细胞图谱**
2. **建立光信号空间传播的时序动力学模型** — 从感知到效应的"多米诺骨牌"
3. **揭示昼夜节律对光质响应的门控机制** — 一天中的"响应窗口"

### 方法学贡献
1. 建立"时空 CCC"分析框架 — 将 PlantCellChat 扩展到时间维度
2. 时序 SCENIC+ 应用于植物空间转录组
3. "毛根快速筛选→CRISPR"的大豆时空功能基因组学验证体系

### 应用价值
1. 为大豆耐密植育种提供**时空特异的靶基因组合** (Early/Late模块分别靶向)
2. 指导光质调控株型的精准农业 — 何时补光最有效?

## 七、潜在问题与对策

| 风险 | 对策 |
|------|------|
| 5时间点×3节位×3光质 = 45组, 成本极高 | 空间转录组: 核心时间点(0h/24h/7d)做空间; 全部5时间点做snRNA-seq补充 |
| 时间点间隔选择错误, 错过关键窗口 | 预实验: WL vs LRFR 第3节间 密集采样(1h/3h/6h/12h/24h)先用qPCR确定关键窗口 |
| 昼夜节律效应混淆光质效应 | ZT固定采样; ZT0 vs ZT12对照实验 |
| 24h后的差异可能来自发育进程而非光质 | 设WL同时间点对照, 差异分析以WL为baseline |
