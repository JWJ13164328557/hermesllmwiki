# 大豆节间光质响应空间转录组研究方案

> 基于 88 篇植物单细胞/空间组学文献的知识库设计

---

## 一、研究背景与立项依据

### 1.1 大豆株型与光环境

大豆 (Glycine max L.) 是全球最重要的油料和蛋白质作物。株型是决定大豆产量潜力的核心农艺性状，其中**节间伸长**直接控制植株高度、分枝角度和冠层结构，进而影响光能截获效率和机械化收获适应性[1]。密植条件下，大豆通过**避荫综合症 (SAS, Shade Avoidance Syndrome)** 促进节间过度伸长，导致倒伏和减产，这一过程由光受体感知的红光:远红光 (R:FR) 比例降低和蓝光减少所触发[2]。

光质 (light quality) 是调控植物形态建成的关键环境信号。**低蓝光 (LBL)** 和**低 R:FR (LRFR)** 分别模拟冠层遮荫的两个特征——蓝光衰减和远红光富集，两者通过不同的光受体通路 (cryptochrome → HY5, phytochrome B → PIF) 差异化地调控下胚轴和节间伸长[3-4]。然而，在组织/细胞类型分辨率上，光质如何沿节间发育梯度空间差异化地调控细胞行为，几乎完全未知。

### 1.2 空间转录组技术的突破

植物单细胞与空间转录组学已从模式植物拟南芥扩展到主要作物[5]。空间转录组技术 (Stereo-seq, Visium) 实现了在组织原位同时捕获空间坐标和全转录组信息，为解析复杂器官的细胞异质性提供了革命性工具。近期标志性工作包括：

| 研究 | 方法 | 关键发现 |
|------|------|---------|
| 大豆时空多组学图谱 (Cell, 2025) | scATAC+scRNA 10组织 | 建立豆科CRE和GRN参考[6] |
| 小麦穗空间转录组 (Mol Plant, 2026) | Stereo-seq单细胞分辨率 | 9种细胞类型、穗轴营养供给中枢[7] |
| 玉米锈病空间免疫 (Adv Sci, 2026) | sc+空间+VIGS | 8种细胞类型、ZmXET1功能验证[8] |
| 拟南芥昼夜质子梯度 (Cell, 2026) | pH传感器+遗传学 | CCA1驱动表皮/伴胞pH反相振荡[9] |
| 番茄愈伤光再生 (PNAS, 2023) | 空间转录组 | 光诱导绿组织细胞→茎再生[10] |
| HY5-MSI1-PRC2表观抑制 (Plant Cell, 2026) | ChIP+RNA-seq | H3K27me3-生长素通路耦联光形态建成[11] |

**关键空白**：尚无任何研究在空间分辨率上解析光质如何调控作物茎秆节间发育。大豆节间作为兼具纵向(不同节位成熟度)和径向(不同组织层)异质性的理想系统，是回答这一问题的绝佳模型。

### 1.3 核心科学问题

> **不同光质 (WL/LBL/LRFR) 如何在空间上差异化地重塑大豆节间 (1st/2nd/3rd) 的细胞类型组成、基因表达程序和细胞间通讯网络，从而协调节间伸长与次生壁建成的平衡？**

---

## 二、核心假设

**Central Hypothesis**: 光质通过细胞类型特异的光受体-转录因子-激素信号模块，在空间上差异化地调控大豆节间的纵向(不同节位)和径向(不同组织层)发育程序，其中表皮和维管束是光信号感知与传递的空间中枢，而GA/IAA信号梯度是执行节间差异伸长的核心输出通路。

**可检验的辅助假设**:

- H1: 大豆节间包含至少6大类15+种细胞亚型，沿纵轴呈现从分生到成熟的发育梯度
- H2: LBL和LRFR通过不同的光受体通路(PHYB→PIF vs CRY→HY5)分别在空间上激活表皮和维管束的细胞伸长程序
- H3: 韧皮部伴胞-表皮细胞的空间通讯介导了光信号从感知位点到响应位点的传递
- H4: GmHY5/GmPIFs 是整合光信号与GA/IAA信号的空间节点转录因子
- H5: 次生壁建成基因(NAC/MYB开关)在第一节间被光质独立于伸长的信号差异化调控

---

## 三、研究目标与具体内容

### Aim 1: 构建大豆节间空间细胞图谱 — 解析纵向发育梯度

**目标**: 建立大豆第1/2/3节间的空间转录组参照图谱，定义细胞类型组成及其沿纵轴的发育梯度变化。

**实验设计**:

```
┌─────────────────────────────────────────────────────────┐
│ 大豆 V3-V4 期 (Williams 82)                            │
│ ↓                                                       │
│ 取第1节间(基部,成熟), 第2节间(中部,过渡), 第3节间(顶部,伸长)  │
│ ↓                                                       │
│ 冷冻切片 (10μm 横切面 + 纵切面)                          │
│ ↓                                                       │
│ Stereo-seq / Visium HD                                  │
│ ↓                                                       │
│ 空间预处理 → 聚类 → 注释 → 轨迹推断                      │
└─────────────────────────────────────────────────────────┘
```

**分析方法**:

- **空间域聚类**: SpaGCN/BayesSpace — 识别解剖学结构对应的基因表达域
- **细胞类型注释**: 参考大豆Cell时空图谱[6]的细胞类型标记基因; 同时进行无监督 de novo 聚类
- **空间梯度分析**: spatialDE/SPARK-X — 鉴定沿纵轴(基部→顶端)的连续表达梯度基因
- **伪时间/RNA velocity**: Monocle3/RDV — 重建纵向细胞发育轨迹
- **细胞组成定量**: RCTD/SPOTlight — 每个空间spot的细胞类型比例反卷积

**预期结果**:

- A1.1: 大豆节间空间细胞图谱 — 6大类细胞(表皮/皮层/韧皮部/形成层/木质部/髓) + 亚型 ≥15种
- A1.2: 第一节间特异富集的次生壁建成模块(NAC SECONDARY WALL THICKENING PROMOTING FACTOR, MYB46/83)
- A1.3: 第三节间特异富集的细胞分裂/伸长模块(CYCD3, EXPA, XTH)
- A1.4: 纵向发育梯度 — 沿基部→顶端的连续表达变化基因集(>500个基因)
- A1.5: RNA velocity 伪时间轴与解剖位置的高度一致性

**创新点**: 首次在大豆中构建节间空间参照图谱, 填补作物茎秆发育的空间细胞类型参照空白。

---

### Aim 2: 解析光质对节间空间细胞图谱的重塑

**目标**: 鉴定WL/LBL/LRFR处理下不同节间的空间基因表达变化，解析光质差异调控的细胞类型和空间域。

**实验设计**:

```
┌──────────────────────────────────────────────────────┐
│ WL (对照) │ LBL (低蓝光) │ LRFR (低R:FR)             │
│     ↓           ↓              ↓                     │
│  处理 24h + 7d, 取 1st/2nd/3rd 节间                  │
│     ↓                                                │
│  空间转录组 (同Aim 1)                                 │
│     ↓                                                │
│  比较分析: WL vs LBL, WL vs LRFR, LBL vs LRFR       │
└──────────────────────────────────────────────────────┘
```

**分析方法**:

- **空间差异表达 (spatial DE)**: 在每个空间域内比较光质间的差异基因
- **细胞类型比例变化**: 通过反卷积定量细胞组成变化 (如: LRFR下髓腔是否扩大？)
- **空间响应热图**: 将光响应基因的空间分布映射到组织切片上, 鉴定光响应"热点"区域
- **光受体通路富集**: 对差异基因进行PHYB/PIF vs CRY/HY5通路特异性富集分析
- **激素信号空间分布**: 基于基因表达推断IAA/GA/BR/JA在组织水平上的空间梯度

**预期结果**:

- A2.1: LBL 和 LRFR 通过**不同细胞类型**促进伸长 — LBL→表皮/皮层, LRFR→维管束/髓
- A2.2: 光响应空间热图定位 — 维管束鞘和表皮是光信号的"枢纽"细胞类型
- A2.3: LBL特异上调CRY-HY5通路靶基因; LRFR特异上调PIF靶基因和YUCCA生长素合成基因
- A2.4: GA20ox/GA2ox 沿纵轴的空间梯度被光质量塑 — LRFR下GA信号向顶端偏移
- A2.5: 第三节间(伸长区)对光质最敏感, 第一节间(成熟区)响应最弱 → 发育阶段决定光可塑性

**创新点**: 首次在空间维度上将光质信号与作物茎秆发育的细胞类型特异性响应建立直接联系。

---

### Aim 3: 光信号的空间细胞间通讯网络

**目标**: 利用 PlantCellChat 和空间共定位分析, 解析光信号如何在组织水平的细胞通讯网络中传递。

**分析方法**:

- **PlantCellChat**: 使用大豆配体-受体数据库, 推断细胞间通讯[12]
- **空间配体-受体共定位**: 配体和受体在同一空间spot上的共表达评分
- **通讯差异比较**: WL vs LBL vs LRFR 的通讯网络差异
- **空间信号流推断**: 从表皮(光感知) → 皮层 → 维管束(信号执行)的信号传播路径
- **移动信号分子鉴定**: 重点关注小肽(CLE/CEP/EPFL)、激素转运蛋白(PIN/LAX)、糖转运蛋白(SWEET/STP)

**预期结果**:

- A3.1: 表皮→皮层的生长素极性运输信号在LRFR下增强(NtPIN3同源基因上调[13])
- A3.2: 韧皮部→表皮的糖信号和代谢物交流在LBL下减弱
- A3.3: 形成层→木质部母细胞的CLE/TDIF-PXY信号被光质差异调控
- A3.4: CCA1/LHY 节律基因的表达沿径向组织层呈现相位梯度 (参考Cell质子梯度[9])
- A3.5: 光照→暗转变时, 维管束鞘细胞的代谢通讯发生快速重编程

**创新点**: 引入空间细胞通讯维度, 将光信号从"细胞内"拓展到"组织协调"层面。

---

### Aim 4: 细胞类型特异的基因调控网络与核心因子鉴定

**目标**: 整合空间转录组与表观组/激素组数据, 构建光质调控节间发育的基因调控网络 (GRN), 鉴定关键转录因子。

**分析方法**:

- **SCENIC+**: 空间GRN推断 — 识别每个细胞类型中的核心TF及其靶基因模块
- **光信号+激素通路整合**: 将HY5/PIF/ARF/DELLA 靶基因与空间表达数据交叉
- **WGCNA共表达模块**: 鉴定光响应共表达模块及其空间分布
- **顺式调控元件 (CRE) 分析**: 参考大豆Cell CRE数据库[6], 分析光响应基因启动子富集的motif
- **跨物种保守性**: 将大豆光响应GRN与拟南芥/水稻/玉米的空间GRN比较[14-15]

**预期结果**:

- A4.1: 鉴定3-5个节间特异的光响应核心TF (如GmHY5, GmPIF3, GmARF6, GmNAC1)
- A4.2: 构建表皮→皮层→维管束的光信号GRN级联模型
- A4.3: 光质通过调控GA20ox/GA2ox的空间表达模式重置GA梯度
- A4.4: H3K27me3标记在光响应基因启动子上的空间差异分布 (参考MSI1-PRC2[11])
- A4.5: 大豆节间光响应GRN与拟南芥下胚轴的保守性和分化

**创新点**: 将表观基因组和激素信号整合到空间GRN框架中, 提供多层调控视角。

---

### Aim 5: 关键因子的功能验证

**目标**: 通过大豆毛根转化和CRISPR基因编辑, 验证Aim 4鉴定的核心TF在光质调控节间伸长中的功能。

**实验设计**:

```
候选基因 (Top 5 TF)
  ├── GmHY5 (CRY通路核心)
  ├── GmPIF3a/b (PHYB通路核心)
  ├── GmARF6 (生长素响应核心)
  ├── GmNAC1 (次生壁调控)
  └── GmPRE1 (HLH, 细胞伸长)
       ↓
  大豆毛根转化 (快速验证, 2-3周)
       ↓
  OE / RNAi / CRISPR-Cas9
       ↓
  表型: 节间长度/直径/细胞大小/细胞壁厚度
       ↓
  RNA-seq验证下游靶基因
       ↓
  稳定转化 (选择1-2个核心基因)
```

**验证体系**:

- **大豆毛根转化**: 快速筛选候选基因功能 (2-3周周期)
- **CRISPR-Cas9 敲除**: 构建 Gmhy5, Gmpif3a/b 突变体
- **过表达**: 35S或节间特异启动子驱动
- **表型量化**: 节间长度/直径/细胞数/细胞大小
- **下游验证**: RNA-seq 确认靶基因调控
- **跨物种**: 拟南芥异源表达验证功能保守性 (参考SlTAC1→番茄[13])

**预期结果**:

- A5.1: GmPIF3-OE → 节间伸长、对LRFR超敏感 (模拟避荫表型)
- A5.2: GmHY5-OE → 抑制节间伸长、对LBL不敏感
- A5.3: GmARF6 介导生长素信号促进表皮细胞伸长
- A5.4: GmNAC1 调控次生壁建成, 与伸长程序解耦联
- A5.5: GmHY5/GmPIF3 双突恢复野生型表型 → 拮抗调控

**创新点**: "毛根快速筛选+稳定转化确认"的双层验证策略, 大幅缩短大豆功能基因组周期。

## 五、潜在问题与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| 节间木质化致RNA降解 | 中 | 幼嫩材料+EDTA脱钙; RNA质检RIN>6即可接受 |
| Stereo-seq对木质化组织渗透差 | 中 | Visium替代; 或先做snRNA-seq确定细胞类型→空间映射 |
| 大豆稳定转化周期长(6-12月) | 高 | 毛根转化快速筛选(2-3周); 提前构建CRISPR载体 |
| 光质处理间差异效应量小 | 低 | 延长处理至7-14天; 增加生物学重复(n≥4) |
| 空间分辨率不足以区分细胞亚型 | 中 | 整合snRNA-seq提高分辨率; HD版本 |
| 不同节间取样位置偏差 | 低 | 严格标准化取样位置(节间中部); 纵切面验证 |

## 六、创新性与预期贡献

### 理论贡献

1. **首次解析作物节间发育的空间细胞图谱** — 填补茎秆发育的细胞类型参照空白
2. **建立光质-空间-发育三维整合框架** — 将环境信号整合到空间发育生物学中
3. **揭示光信号的空间传递机制** — 从"细胞自主"到"组织协调"的范式转变

### 应用价值

1. 为大豆**耐密植分子育种**提供靶基因和调控模块
2. 为**光质调控株型**的精准农业提供理论基础
3. 建立的空间参照图谱可服务于大豆功能基因组学社区

### 技术贡献

1. 首次在大豆中应用 Stereo-seq 空间转录组技术
2. 建立"毛根转化→CRISPR"的大豆基因快速验证体系
