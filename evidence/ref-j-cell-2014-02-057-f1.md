# Interestingly, we found that in the adult, Noggin was upregulated in DP as HFs transitioned from Ana

## Claim
Interestingly, we found that in the adult, Noggin was upregulated in DP as HFs transitioned from AnaI/AnaII–III; moreover, when Shh was ablated, this failed to occur (Figures 4B and 4C).

## Biological Context
Transit-amplifying cells orchestrate stem cell activity and tissue regeneration.
