# If not neutralized, ROS can inhibit development through mechanisms such as leaf …

## Claim
If not neutralized, ROS can inhibit development through mechanisms such as leaf abscission, altered root gravitropism, and, notably, damage to the photosynthetic system, all of which directly impair crop productivity (de Souza et al., 2025a; de Souza et al., 2025b).
