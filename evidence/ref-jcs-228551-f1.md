# Datasets generated using these techniques include profiles of plants enriched or depleted …

## Claim
Datasets generated using these techniques include profiles of plants enriched or depleted in the stomatal lineage (Bergmann et al., 2004; Pillitteri et al., 2011), genome-wide maps of SPCH binding sites (Lau et al., 2014), identification of MUTE targets by RNA-seq following MUTE induction (Han et al., 2018), and cell type-specific transcriptional profiles (Adrian et al., 2015).
