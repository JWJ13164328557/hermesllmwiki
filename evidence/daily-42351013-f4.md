# ProbeST is designed to output a final probe set optimized for specific hybridization to …

## Claim
ProbeST is designed to output a final probe set optimized for specific hybridization to target genes by meeting the following guidelines (as suggested by 10X Genomics probe design instructions [ ]): the probes should target coding regions, the 25th nucleotide of the LHS probe (at the 3’ end) must be a T, and the GC content should be between 44–72% for each probe.
