# Taken together, these data suggest that PARP activation drives an accelerated aging phenotype in XPA

## Claim
Taken together, these data suggest that PARP activation drives an accelerated aging phenotype in XPA and that pharmacological intervention with PARP inhibitors or compounds that increase NAD+ can partially normalize this phenotype.

## Biological Context
Defective Mitophagy in XPA via PARP-1 Hyperactivation and NAD+/SIRT1 Reduction
