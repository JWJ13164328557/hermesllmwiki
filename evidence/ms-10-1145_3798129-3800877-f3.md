# We show that each strong IDU transformation can be represented as a random permuton constructed from

## Claim
We show that each strong IDU transformation can be represented as a random permuton constructed from the basic permutons I (identity), D (decreasing), and U (uniform) via a simple operation called up-combination, which we introduce in this paper.
