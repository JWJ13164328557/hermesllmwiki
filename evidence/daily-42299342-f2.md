# A conserved regulatory framework involves the MYB–bHLH–WD40 (MBW) complex, in which …

## Claim
A conserved regulatory framework involves the MYB–bHLH–WD40 (MBW) complex, in which R2R3-MYB and bHLH transcription factors interact with WD40 proteins to activate (or repress) anthocyanin pathway genes in a tissueand developmental stage-dependent manner (Gonzalez et al., 2008; Hichri et al., 2011; Zhang et al., 2018).
