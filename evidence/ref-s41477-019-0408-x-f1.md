# Taken together, these results show that JA is able to function as a wound signal within several minu

## Claim
Taken together, these results show that JA is able to function as a wound signal within several minutes to 2 h, and acts upstream of auxin to promote DNRR from leaf explants.

## Biological Context
Jasmonate-mediated wound signalling promotes plant regeneration.
