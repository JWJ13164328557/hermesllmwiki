# By using data augmentation, we show the network more possible inputs than are actually present in th

## Claim
By using data augmentation, we show the network more possible inputs than are actually present in the static training set of images, forcing the model to learn different representations of the input images and reducing the chances of overfitting the model.

## Biological Context
Iterative image segmentation of plant roots for high-throughput phenotyping.
