# We report all isotope data in δ-notation using the equation δ 13 C or δ 15 N = 1000 * [( …

## Claim
We report all isotope data in δ-notation using the equation δ 13 C or δ 15 N = 1000 * [( R sample / R standard ) – 1], where the R sample and R standard represent the ratios 13 C: 12 C or 15 N: 14 N in the sample and standard.
