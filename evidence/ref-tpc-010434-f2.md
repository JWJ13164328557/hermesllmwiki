# Here, we report that transcriptional feedback loops exist between the WER, CPC, and GL2 genes and th

## Claim
Here, we report that transcriptional feedback loops exist between the WER, CPC, and GL2 genes and that they are used as part of a lateral inhibition pathway to define the cell-type pattern in the root epidermis.

## Biological Context
Cell pattern in the Arabidopsis root epidermis determined by lateral inhibition
