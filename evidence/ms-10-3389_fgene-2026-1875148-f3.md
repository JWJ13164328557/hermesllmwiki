# We report both levels of correction simultaneously: (1) genome-wide Benjamini–Hochberg FDR correctio

## Claim
We report both levels of correction simultaneously: (1) genome-wide Benjamini–Hochberg FDR correction, using the actual number of genes tested in each group as the correction baseline; and (2) internal FDR correction within the 13 selected genes.
