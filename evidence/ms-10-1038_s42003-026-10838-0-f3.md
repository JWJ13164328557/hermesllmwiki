# We found that N₂O reduces functional network modularity and dis- rupts hierarchical network organiza

## Claim
We found that N₂O reduces functional network modularity and dis- rupts hierarchical network organization during visual stimulation, with the strongest effects in higher-order integrative systems and relative preserva- tion of visual networks.

## Biological Context
Subanesthetic nitrous oxide alters large-scale network organization and insula connectivity during visual stimulation
