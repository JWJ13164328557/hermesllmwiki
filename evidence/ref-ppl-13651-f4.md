# Calcium ions interact with Ca2+ sensors, like inositol-3-phosphate (IP3), phospholi- pase C and calc

## Claim
Calcium ions interact with Ca2+ sensors, like inositol-3-phosphate (IP3), phospholi- pase C and calcineurin-B-like proteins (CBLs) and genes encoding these factors are generally up-regulated in drought-stressed roots (Cheong et al., 2003; Pandey et al., 2013).

## Biological Context
Shaping the root system architecture in plants for adaptation to drought stress.
