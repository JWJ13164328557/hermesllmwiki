# The co- expression network analysis between OsERF48 and root-specific overexpression of ERF48 root R

## Claim
The co- expression network analysis between OsERF48 and root-specific overexpression of ERF48 root RNA-seq data showed that calmodulin- like protein genes, OsCML16, is a direct target of OsERF48 that together enhanced root growth and drought tolerance (Jung et al., 2017).

## Biological Context
Shaping the root system architecture in plants for adaptation to drought stress.
