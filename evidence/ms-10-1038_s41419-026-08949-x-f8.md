# Taken together, these data demonstrate that SMAD3, RUNX2, JUN and FOS bind consensus DNA sequences c

## Claim
Taken together, these data demonstrate that SMAD3, RUNX2, JUN and FOS bind consensus DNA sequences coordinately with each other, forming an interconnected transcriptional network that may function as a CRC in tumor cells.

## Biological Context
Core transcriptional regulatory circuitry identified from patient-derived tumor cells provides a specific vulnerability for rhabdomyosarcoma
