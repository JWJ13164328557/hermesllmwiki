# The released SNRK2 phosphorylates ABA- responsive element (ABRE)-binding factors (ABFs), which bind 

## Claim
The released SNRK2 phosphorylates ABA- responsive element (ABRE)-binding factors (ABFs), which bind to cis-acting elements (ACGTGG/TC) to activate downstream gene expression [42, 43].

## Biological Context
The ABA-induced NAC transcription factor MdNAC1 interacts with a bZIP-type transcription factor to promote 花青素 synthesis in red-fleshed apples
