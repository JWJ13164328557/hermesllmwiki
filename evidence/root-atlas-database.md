# Root Atlas Enables Community Access to Root scRNA-seq Datasets

## Claim

An online interactive database (Root Atlas) enables community-wide access to root scRNA-seq datasets from multiple plant species, providing interactive visualization, gene expression querying, and cell-type annotation tools.

## Methodological Context

Plant single-cell datasets are distributed across individual publications with inconsistent formats and annotation standards. Root Atlas addresses this by curating, re-processing, and hosting root scRNA-seq data in a unified framework, making it accessible to the broader plant biology community without requiring computational expertise.
