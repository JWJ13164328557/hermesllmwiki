# Upon extracellular ligand (e.g., TGF- β1) binding, the type II receptor (e.g., TGFBR2) phosphorylate

## Claim
Upon extracellular ligand (e.g., TGF- β1) binding, the type II receptor (e.g., TGFBR2) phosphorylates the type I receptor (e.g., TGFBR1) via the GS domain, which activates the receptor-regulated SMADs (R- SMADs; e.g., SMAD2/3).

## Biological Context
A novel positive feedback regulatory loop, TGF-β1/SMAD4/miR-184, controls the follicular development in sows.
