# Functional enrichment analysis of the FASTIS DEGs using the EnrichR database revealed top enriched G

## Claim
Functional enrichment analysis of the FASTIS DEGs using the EnrichR database revealed top enriched GO terms such as cholesterol homeostasis, TNF signaling and IFN response, while top depleted GO terms included mitotic spindle, G2/M checkpoint and especially E2F target genes.

## Biological Context
Fatty acid synthesis therapy-induced senescence (FASTIS) in cancer cells
