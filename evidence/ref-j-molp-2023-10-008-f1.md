# Through chromatin immunoprecipitation followed by sequencing (ChIP-seq) analysis using transgenic co

## Claim
Through chromatin immunoprecipitation followed by sequencing (ChIP-seq) analysis using transgenic cotton lines expressing 35S::GoPGF- GFP, we found that GoPGF directly binds to the promoters of GoHSFA4a and GoNAC42 (Figure 4B).
