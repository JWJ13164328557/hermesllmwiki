# Potential off-target sites were initially assessed using CRISPR-P v2.0 and further predicted using C

## Claim
Potential off-target sites were initially assessed using CRISPR-P v2.0 and further predicted using Cas-OFFinder implemented through CRISPR RGEN Tools (www.rgenome.net, accessed 11 on March 2024), based on sequence similarity against the Cajanus reference genome (Supplementary Material S7; Supplementary Figure S4).
