# Using a gain of function approach, we found that tethering TRB proteins with an artiﬁcial zinc ﬁnger

## Claim
Using a gain of function approach, we found that tethering TRB proteins with an artiﬁcial zinc ﬁnger triggered gene silencing over the FWA region as well as many other ZF off-target regions.

## Biological Context
Arabidopsis TRB proteins function in H3K4me3 demethylation by recruiting JMJ14.
