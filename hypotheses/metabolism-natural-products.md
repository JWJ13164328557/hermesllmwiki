# 代谢与天然产物 假说集

基于 [[metabolism-natural-products|代谢与天然产物 Synthesis]] 的 1032 条证据、149 篇文献推演生成（总知识库 1032 条证据对象）。5 条假说聚焦知识空白与共识延伸，覆盖类黄酮 MBW 复合体、激素-代谢信号链路、苯丙烷代谢流分配、光质-代谢耦合及生物碱跨细胞转运等核心问题。

### H1: MBW 复合体通过 MYB 旁系同源基因实现细胞类型特异性类黄酮调控

**陈述**：MBW (MYB-bHLH-WD40) 复合体在不同细胞类型中激活不同类黄酮靶基因的特异性并非由 bHLH 或 WD40 亚基决定，而是由细胞类型特异性表达的 **MYB 旁系同源基因** 驱动——每个 MYB 变体携带不同的顺式元件识别偏好和蛋白互作界面，从而在表皮、维管束鞘、腺毛等不同细胞类型中激活不同的类黄酮分支通路（花青素、原花青素、黄酮醇等）。这一 "MYB 组合密码" 的解析是理解植物组织特异性代谢调控的关键。

**证据基础**：Synthesis §类黄酮与花青素生物合成 — MBW 复合体在草莓 (FaMYB5)、甜瓜 (CmMYB6)、拟南芥 (MYB75/PAP1)、梨 (EsMYB90) 等多个物种中保守，但各 MYB 调控的代谢谱存在显著差异；EsMYB90 单一过表达即可显著提升多种类黄酮代谢物水平，表明单个 MYB 足以大幅改变代谢输出（Evidence: integrated-metabolomic-and-transcriptomic-analysis）；RHA2B 介导 MYB30 降解促进 MYB75 调控的花青素合成，揭示不同 MYB 之间存在竞争/替代关系（Evidence: rha2b-mediated-myb30-degradation）；AtbHLH113 与 PAP1/MYB75 特异性互作调控花青素合成，进一步提示 MYB 身份决定复合体靶标选择性；Synthesis 知识空白 #1 明确指出 "MBW 复合体如何实现细胞类型和发育阶段特异性调控尚不清晰"。

**可检验预测**：
1. 对拟南芥/番茄叶片进行 scRNA-seq 后，类黄酮途径活跃的不同细胞亚群（如表皮、维管束鞘、腺毛）中各自表达不同的主导 R2R3-MYB 基因，且各 MYB 旁系同源基因之间的表达相关性在细胞类型内高（Pearson r > 0.7）、跨细胞类型低（r < 0.3）
2. DAP-seq 或 ChIP-seq 显示不同 MYB 旁系同源基因在全基因组范围内结合不同的靶基因集合——任意两个 MYB 之间的靶基因 Jaccard 相似度 < 0.5，各自富集不同的下游类黄酮分支酶基因（如花青素特异 MYB 富集 DFR/ANS 启动子，原花青素特异 MYB 富集 ANR/LAR 启动子）
3. 在烟草或拟南芥原生质体中瞬时表达不同 MYB 旁系同源基因 + 共同 bHLH/WD40 伴侣后，靶向代谢组学检测到截然不同的类黄酮代谢物谱——花青素 MYB 产生矢车菊素/芍药花素衍生物，原花青素 MYB 产生儿茶素/表儿茶素衍生物
4. MYB 蛋白结构域交换实验（domain swap）显示，DNA 结合域（R2R3 区域）而非蛋白互作域（C 端）决定了靶基因选择性——交换 R2R3 区域即可交换代谢输出谱
5. CRISPR 敲除特定细胞类型中的主导 MYB 仅影响该细胞类型中对应类黄酮分支的代谢物积累，而对其他细胞类型和其他类黄酮分支无显著影响

**证伪条件**：
- 若同一细胞类型中多个 MYB 旁系同源基因共表达且丰度相近（各占 >20% 总 MYB 表达），而非由单一主导 MYB 驱动
- 若 DAP-seq 显示不同 MYB 的结合位点高度重叠（Jaccard 相似度 >0.8），即 MYB 间靶基因选择性不存在
- 若不同 MYB 在瞬时表达实验中产生不可区分的代谢物谱（代谢组 PCA 中不同 MYB 样本混合在一起）
- 若 CRISPR 敲除特定 MYB 后无任何类黄酮代谢物变化（冗余补偿完全掩盖功能丧失）

**检验方法**：
1. **scRNA-seq + 细胞类型鉴定**：对拟南芥莲座叶和草莓果实进行单细胞转录组测序（10x Genomics），使用 Seurat/Scanpy 无监督聚类鉴定细胞亚群，提取各亚群中 R2R3-MYB 基因表达矩阵
2. **候选 MYB 的 DAP-seq**：对每种细胞类型中表达量最高的 1-2 个 MYB 进行体外 DAP-seq（DNA affinity purification sequencing），鉴定全基因组结合位点，比较靶基因集的 Jaccard 相似度
3. **瞬时表达 + 代谢组学**：在烟草叶片中农杆菌介导共表达候选 MYB + AtbHLH001/AtTTG1（固定 bHLH/WD40 伴侣），72h 后进行靶向 LC-MS/MS 类黄酮代谢组学分析
4. **MYB 结构域交换实验**：构建 R2R3 结构域嵌合 MYB 蛋白（MYB-A 的 R2R3 + MYB-B 的 C 端，及反向组合），验证代谢输出是否随 DNA 结合域而改变
5. **细胞类型特异性 CRISPR**：利用细胞类型特异性启动子（如表皮 AtML1p、维管束鞘 AtSHRp）驱动 Cas9，在特定细胞类型中敲除主导 MYB，通过激光显微切割 (LCM) 分离靶细胞后进行 qPCR 和代谢物分析

**优先级**：★★★（直接回答 Synthesis 首要知识空白；检验方法成熟；对代谢工程具有直接指导价值）

### H2: 茉莉酸甲酯诱导次生代谢物积累依赖于跨代谢分支保守的 NAC-MYB 转录级联

**陈述**：茉莉酸甲酯 (MeJA) 广泛诱导萜类、生物碱和苯丙烷类代谢物积累的机制中存在一个 **保守的 NAC → MYB 转录级联**——类似于生长素通过 ARF-NSC-MYB 级联调控次生壁合成的机制（Synthesis §共识发现 #2）。MeJA 信号激活特定 NAC 转录因子后，该 NAC 因子直接靶向不同代谢分支特异性的 MYB 转录因子（类黄酮 MYB、萜类 MYB、生物碱 MYB），最终启动各分支次生代谢物合成基因的表达。这一级联的保守性意味着跨代谢分支共享相同的上游信号解码逻辑。

**证据基础**：Synthesis §共识发现 #2 — 生长素通过 PbrARF13-PbrNSC-PbrMYB132 调控次生壁合成的完整级联框架已建立；CmNAC25 靶向 CmMYB6 正调控甜瓜花青素合成，证明 NAC→MYB 级联在代谢调控中存在（Evidence: cmnac25-targets-cmmyb6）；Synthesis §激素交叉调控 — MeJA 广泛诱导萜类、生物碱和苯丙烷类代谢物积累是已知现象，但中间信号组分缺失；Synthesis 知识空白 #2 明确指出 "激素信号与特化代谢之间的完整信号链路缺失"；MeJA 信号通路核心组分（COI1-JAZ-MYC2）已阐明，但 MYC2 下游如何连接不同代谢分支的 MYB 因子尚不清楚。

**可检验预测**：
1. 拟南芥 MeJA 时程 RNA-seq（0-24h）中，至少 2 个 NAC 转录因子在 MeJA 处理后 1-3 小时内显著上调（log2FC ≥ 2），早于任何已知代谢分支 MYB 基因的上调（6-12h），构成时间上的 NAC→MYB 级联顺序
2. ChIP-seq 揭示候选 NAC 转录因子在至少 3 个不同代谢分支 MYB 基因（如类黄酮 AtMYB75/PAP1、萜类相关 MYB、生物碱相关 MYB）的启动子区有直接结合峰，结合基序（NACRS）在靶启动子中显著富集（FDR < 0.01）
3. nac 双突变体（敲除 2 个候选 NAC）在 MeJA 处理后，至少 3 类次生代谢物（花青素、萜类挥发物、苯丙烷类）的诱导积累显著减弱（≥50% 降低），而 nac 过表达株系在无 MeJA 处理下即表现组成型代谢物积累
4. 候选 NAC 的靶 MYB 启动子中 NAC 结合位点突变（CRISPR 编辑 cis 元件）后，MeJA 无法诱导该 MYB 及其下游代谢通路表达
5. 跨物种验证：番茄/烟草中候选 NAC 同源基因的 VIGS 沉默同样减弱 MeJA 诱导的多种次生代谢物积累

**证伪条件**：
- 若 MeJA 时程 RNA-seq 未检测到任何 NAC 因子在 MYB 基因上调之前响应（NAC 和 MYB 同时或 MYB 先于 NAC 上调）
- 若 ChIP-seq 未发现候选 NAC 在代谢分支 MYB 启动子区有任何结合峰（无直接靶向关系）
- 若 nac 突变体的 MeJA 诱导代谢物谱与野生型无显著差异（全局代谢组分析显示 >90% 代谢物变化幅度一致）
- 若 MeJA 诱导的代谢物积累完全可由 MYC2 直接激活代谢酶基因解释，不需要 NAC-MYB 中间级联

**检验方法**：
1. **MeJA 时程转录组**：拟南芥 Col-0 经 100 μM MeJA 处理，在 0、1、3、6、12、24h 取样进行 RNA-seq（3 生物重复），筛选早期（1-3h）响应的 NAC 转录因子，使用 STEM/ImpulseDE2 进行时序模式聚类
2. **ChIP-seq**：对候选 NAC 构建 NAC-GFP 融合蛋白转基因系，MeJA 处理 3h 后取材，GFP 抗体 ChIP-seq 鉴定全基因组结合位点，重点分析代谢分支 MYB 启动子区的结合峰
3. **CRISPR 突变体验证**：构建候选 NAC 的单突和双突株系（CRISPR-Cas9），MeJA 处理后进行非靶向 LC-MS 代谢组学和靶向类黄酮/萜类定量
4. **EMSA + 酵母单杂**：验证候选 NAC 与靶 MYB 启动子中 NACRS 元件的体外和体内直接结合
5. **跨物种保守性验证**：在番茄中通过 VIGS 沉默候选 NAC 同源基因，MeJA 处理后检测萜类挥发物和苯丙烷类代谢物变化

**优先级**：★★★（填补激素-代谢信号链路核心空白；检验可行性高；NAC-MYB 级联若被证实，将成为代谢工程通用调控靶点）

### H3: 苯丙烷代谢流在类黄酮与木质素分支间的分配由 4CL 基因家族成员的组织特异性差异表达与底物选择性共同决定

**陈述**：苯丙烷途径在类黄酮和木质素两条主要分支之间的代谢流分配，主要由 **4-香豆酸:辅酶 A 连接酶 (4CL) 基因家族成员的差异化调控** 决定——不同 4CL 旁系同源基因对羟基肉桂酸底物（4-香豆酸、咖啡酸、阿魏酸、芥子酸）具有显著不同的 Km 和 Vmax，且其表达受独立的转录调控模块（类黄酮调控模块 vs 木质素调控模块）控制。具体而言，"类黄酮型" 4CL 成员优先利用 4-香豆酸并受 MBW 复合体调控；"木质素型" 4CL 成员对多种羟基肉桂酸底物具有广泛活性，并受 NAC-MYB 次生壁级联调控。这一分工在细胞类型水平上决定了碳流走向。

**证据基础**：Synthesis §共识发现 #4 — 苯丙烷途径是初生与次生代谢的关键分叉点，下游分为类黄酮和木质素两条主要路径；Synthesis §木质素、纤维素与细胞壁 — PbrARF13-PbrNSC-PbrMYB132 级联特异性调控木质素和纤维素合成，PbrMYB24 同时激活木质素和纤维素合成基因但不影响类黄酮途径；Synthesis §类黄酮与花青素 — EsMYB90 和 FaMYB5 主要提升类黄酮代谢物，对木质素的影响未知；4CL 位于苯丙烷途径通用部分与分支特异性部分的分界点，是理论上控制碳流分配的最关键酶；在杨树和拟南芥中已鉴定多个 4CL 旁系同源基因，但功能分化尚未系统解析。

**可检验预测**：
1. 系统发育分析将拟南芥/杨树/大豆的 4CL 家族分为至少两个功能分化分支——Class I（参与木质素合成，与次生壁 NAC-MYB 调控模块共表达）和 Class II（参与类黄酮合成，与 MBW 调控模块共表达），分支间 dN/dS > 0.5
2. 体外重组表达的 Class I 4CL 对阿魏酸和芥子酸的催化效率（kcat/Km）至少是 Class II 4CL 的 3 倍；反之，Class II 4CL 对 4-香豆酸的催化效率至少是 Class I 4CL 的 2 倍
3. 启动子::GUS 融合显示 Class I 4CL 在木质化组织（茎维管束、根中柱）高表达，Class II 4CL 在类黄酮积累组织（花青素着色花瓣、UV 暴露叶片表皮）高表达——两者空间表达模式的重叠区域（如维管束鞘同时需要木质素和类黄酮）恰好是两类 4CL 共表达的区域
4. 在拟南芥 4cl1 突变体（Class I 缺失）中，木质素含量降低 ≥40% 而花青素含量无显著变化；在 4cl3 突变体（Class II 缺失）中，花青素含量降低 ≥30% 而木质素含量无显著变化
5. 过表达 Class II 4CL 可将碳流导向类黄酮合成，在保持木质素含量不变的情况下提升花青素和黄酮醇含量 ≥50%（代谢工程验证）

**证伪条件**：
- 若所有 4CL 家族成员在体外酶动力学上对不同底物的 Km 差异 < 2 倍（即无非对底物选择性）
- 若所有 4CL 成员在所有组织中组成型共表达（组织间表达相关性 > 0.8），无空间表达分化
- 若单基因 4CL 突变体代谢物谱与野生型无差异（强功能冗余）
- 若 Class I 和 Class II 4CL 受相同的上游转录调控模块（而非分别受 NAC-MYB 和 MBW 控制）

**检验方法**：
1. **系统发育与选择压力分析**：收集拟南芥（4 个 4CL）、杨树（5+ 个 4CL）、大豆（4+ 个 4CL）的全部 4CL 序列，使用 PAML 进行分支模型选择压力分析，检测正向选择位点
2. **重组蛋白酶动力学**：在大肠杆菌中重组表达各 4CL 同源蛋白，纯化后以 HPLC 为基础测定对 4-香豆酸、咖啡酸、阿魏酸、芥子酸的 Km、Vmax 和 kcat
3. **组织特异性表达定位**：构建各 4CL 启动子驱动 GUS/GFP 的转基因拟南芥系，组织化学染色和共聚焦显微镜观察空间表达模式；同时结合已发表的拟南芥 eFP Browser 和单细胞转录组数据交叉验证
4. **CRISPR 敲除 + 代谢物分析**：构建各 4cl 单突变体和 4cl1/4cl3 双突变体，测定木质素（乙酰溴法）、花青素（分光光度法）和靶向类黄酮谱（LC-MS/MS）
5. **代谢工程验证**：在拟南芥中过表达 Class II 4CL（4CL3），测定花青素和木质素的定量变化，验证代谢流重定向假说

**优先级**：★★（为代谢工程改造提供关键靶点；检验方法成熟；若被证实，4CL 将成为苯丙烷代谢流定向工程的核心操控节点）

### H4: 光质通过隐花色素 (CRY)-HY5/BBX-MBW 轴直接调控保护性类黄酮合成，是单双子叶植物保守的代谢光保护机制

**陈述**：蓝光/UV-B 通过隐花色素 (CRY1/CRY2) 光受体信号 **直接激活 MBW 复合体的 MYB 组分表达**，从而启动保护性类黄酮（黄酮醇、花青素、原花青素）的合成——这一 CRY → HY5/BBX → MYB → 类黄酮合成基因的级联在单子叶植物（玉米 ZmCRY1）和双子叶植物（拟南芥 AtCRY1/2）中保守，构成植物光保护应答的核心代谢模块。该模块的跨物种保守性意味着其起源可追溯至被子植物共同祖先，且在不同物种中仅存在下游 MYB 靶标和终产物类黄酮谱的物种特异性微调。

**证据基础**：Synthesis §类黄酮与花青素生物合成 — 玉米 ZmCRY1 调控 UV-B 保护性类黄酮化合物和蜡质的合成（Evidence: zmcry1-gl2-wax-maize）；光质与 UV-B 通过 ZmCRYs 调控保护性类黄酮化合物合成；Synthesis §激素交叉调控 — 光信号 (CRYs) 与激素信号在代谢调控中汇聚；拟南芥中 HY5 是 CRY 信号的核心下游转录因子，BBX 家族成员（BBX20/21/22）参与光形态建成和花青素调控；MYB75/PAP1 启动子包含 HY5 结合 G-box 元件；Synthesis §与大豆节间光质项目关联 — 大豆中可能同样存在 CRY 介导的光质-类黄酮调控通路，对大豆光质项目具有直接协同价值。

**可检验预测**：
1. 拟南芥 cry1cry2 双突变体在 UV-B/蓝光处理后，保护性类黄酮（山奈酚/槲皮素糖苷、花青素）积累量相比野生型降低 ≥60%，而遮光对照中两者无显著差异（基因型×处理的显著交互效应，FDR < 0.01）
2. ChIP-seq 鉴定 HY5 直接结合至少 2 个 MBW 复合体 MYB 基因（如 MYB75/PAP1、MYB90/PAP2、MYB113、MYB114）的启动子 G-box 元件，且 UV-B 处理后 HY5 结合信号增强 ≥3 倍
3. 在 hy5 突变体中过表达 MYB75/PAP1 可部分恢复 UV-B 诱导的花青素积累（恢复至野生型的 ≥50%），证明 HY5 通过 MYB 中介发挥功能
4. 玉米 zmcry1 突变体叶片在 UV-B 处理下，ZmMYB 同源基因（与拟南芥 MYB75/PAP1 最接近的玉米 R2R3-MYB）的表达诱导显著减弱（log2FC 降低 ≥2），类黄酮积累同步减少
5. 跨 5 个物种（拟南芥、番茄、大豆、水稻、玉米）的系统分析显示，CRY 下游核心信号组分（HY5/BBX）与 MBW MYB 启动子的结合事件在所有检测物种中保守——至少 50% 的检测物种中观察到该调控关系

**证伪条件**：
- 若 cry1cry2 双突变体中 UV-B 诱导的类黄酮积累与野生型无显著差异（代谢组分析显示所有类黄酮化合物的诱导幅度一致）
- 若 HY5 ChIP-seq 在 MBW MYB 启动子区未检测到结合峰，HY5 与类黄酮调控无直接物理连接

### H5: 萜类吲哚生物碱的完整生物合成依赖于基因簇内共表达的转运蛋白介导中间体跨细胞/跨细胞器转运

**陈述**：长春碱、喜树碱等复杂萜类吲哚生物碱 (TIA) 的生物合成被 **空间分隔在不同细胞类型和不同细胞器中**——早期步骤发生在表皮细胞的内质网（strictosidine 合成），中间体经 MATE/ABC/NRT-PTR 家族转运蛋白输出后进入特化细胞（如异形细胞/乳汁管），再完成后期修饰（如 vindoline 合成）。这些转运蛋白的编码基因位于 TIA 生物合成基因簇 (BGC) 内或其邻近区域（≤100 kb），且与合成基因呈转录共调控——共享相同的上游转录因子（如 ORCA3/BIS1 等 jasmonate-responsive AP2/ERF 因子）。这一机制解释了为何仅有合成酶基因不足以在异源系统中重建完整 TIA 途径。

**证据基础**：Synthesis §生物碱与氨基酸 — 喜树碱生物合成存在细胞特异性表达和细胞区室化调控，长春花萜类吲哚生物碱途径具有细胞类型特异性，青蒿素生物合成已证实腺毛细胞特异性转录调控；长春花 TIA 途径中 strictosidine 合成发生在表皮细胞，而 vindoline 合成的后期步骤在异形细胞/乳汁管中进行——中间体 loganic acid/secologanin 和 tryptamine 需跨细胞转运；长春花基因组中已鉴定 TIA 生物合成基因簇（BGC），包含多个合成酶基因和 AP2/ERF 调控因子；Synthesis 知识空白 #4 明确指出 "天然产物生物合成中的细胞区室化与转运机制所知甚少"；MATE 转运蛋白在植物次生代谢物转运中发挥核心作用（如烟草尼古丁转运蛋白 JAT1/MATE）。

**可检验预测**：
1. 长春花叶片空间转录组分析 (Stereo-seq/LCM-RNA-seq) 显示 TIA 早期步骤基因（STR、TDC）在表皮细胞中高表达，而后期步骤基因（D4H、DAT）在异形细胞/维管束相关细胞中高表达——两套基因表达的空间相关系数 < 0.3
2. 长春花基因组中 TIA BGC 内或邻近区域（±100 kb）至少编码 3 个预测转运蛋白基因（MATE、ABC 或 NRT/PTR 家族），且这些转运蛋白与 TIA 合成酶基因在 WGCNA 共表达网络中属于同一模块（模块成员相关系数 > 0.7）
3. 在烟草叶片中瞬转 TIA 早期合成酶（TDC + STR）+ 候选转运蛋白的组合可检测到 strictosidine 从合成细胞向胞外培养基的转运（LC-MS 检测培养基中的 strictosidine 信号 ≥ 细胞内信号的 30%），而单独表达合成酶时 strictosidine 仅积累在细胞内
4. 候选转运蛋白的 CRISPR 敲除（在长春花毛状根或悬浮细胞中）导致中间体（如 loganic acid 或 secologanin）在合成细胞内异常积累，而终产物（vindoline/catharanthine）减少 ≥50%，表明跨细胞转运被阻断
5. 候选转运蛋白基因的启动子包含与 TIA 合成酶基因相同的顺式调控元件（如 JRE/GCC-box，受 ORCA3/BIS1 结合），且 MeJA 处理可协同诱导转运蛋白和合成酶基因表达

**证伪条件**：
- 若单细胞空间转录组数据显示 TIA 途径所有酶基因在同一细胞类型中表达（空间相关系数 > 0.7），无需跨细胞转运
- 若 TIA BGC 内/邻近区域无任何可检测的转运蛋白编码基因（或虽有但表达水平极低，FPKM < 1）
- 若候选转运蛋白在烟草瞬转系统中无任何底物转运活性
- 若转运蛋白 CRISPR 敲除后终产物水平无变化——表明中间体可通过被动扩散或其他非特异性机制完成细胞间转移

**检验方法**：
1. **空间转录组学**：对长春花叶片进行 Stereo-seq（华大）或 10x Visium 空间转录组测序，同时进行 LCM-RNA-seq（激光捕获异形细胞和表皮细胞），将 TIA 途径基因表达映射到空间坐标
2. **生物信息学筛选**：在长春花基因组中定位 TIA BGC 边界，提取 BGC 及 ±100 kb 侧翼区域的所有预测转运蛋白基因（使用 InterProScan/TMHMM 注释），通过 WGCNA 共表达网络（使用已发表的长春花 RNA-seq 数据集）筛选与 TIA 合成酶共表达的候选转运蛋白
3. **烟草瞬转异源表达系统**：农杆菌介导在烟草叶片中共表达 TIA 早期合成酶（TDC+STR+CPR）± 候选转运蛋白，72h 后分别提取叶片和浸润培养基进行 LC-MS 代谢物检测
4. **CRISPR 敲除 + 代谢组学**：在长春花悬浮细胞或毛状根培养体系中，CRISPR-Cas9 靶向敲除候选转运蛋白，非靶向代谢组学（LC-MS/MS）检测中间体和终产物的积累变化
5. **调控元件分析**：克隆候选转运蛋白启动子，通过酵母单杂和 EMSA 验证 ORCA3/BIS1 等已知 TIA 调控因子是否直接结合其启动子

**优先级**：★★（为合成生物学中重建完整 TIA 途径提供关键缺失组件；空间转录组学是当前前沿技术；但实验体系门槛较高——长春花遗传转化效率低）
