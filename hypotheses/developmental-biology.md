# 发育生物学 推演假说

基于 [[developmental-biology]] 知识综合中的共识发现、知识空白和跨主题关联，推演以下 5 条可检验假说。

---

## 假说 1：CRY1–PIN1 极性重定位假说

**陈述**
蓝光受体 CRY1 通过直接或间接调控形成层区 PIN1 蛋白的亚细胞极性定位，改变生长素流在木质部母细胞和韧皮部母细胞之间的分配方向，从而决定木质部/韧皮部的分化比例。在低 R:FR（模拟密植遮荫）条件下，CRY1 活性下降导致 PIN1 在形成层区径向壁上的定位发生偏移，使生长素更多地流向韧皮部一侧，木质部分化受到抑制。

**推理链**
1. 已有证据表明 CRY1 过表达导致杨树形成层区细胞层数显著减少 → CRY1 直接影响形成层活性
2. PIN1 蛋白极性定位总是朝向未来细胞扩张方向 → PIN1 极性决定生长素流向
3. PXY/TMO5 模块调控木质部/韧皮部比例 → 存在一个上游信号整合光质信息
4. **推理跳跃**：CRY1–PIN1 之间存在信号耦合，且该耦合的物理场所是形成层区 PIN1 的亚细胞重新定位

**关键预测**
- 形成层区特异性 PIN1-GFP 在 cry1 突变体中将呈现异常的极性定位模式
- 低 R:FR 处理应导致 PIN1 在形成层区径向壁上的分布不对称性增加
- 在形成层中特异性表达 PIN1 显性负突变体应模拟 cry1 的木质部减少表型

**可检验性：⭐⭐⭐⭐⭐（高）**
转基因报告系、激光共聚焦成像、光质处理、形成层特异性启动子均已成熟可用。

## 假说 2：愈伤组织-根端分生组织连续谱假说

**陈述**
愈伤组织并非等同于根端分生组织，而是处于从"创伤响应/胁迫记忆状态"到"根端分生组织状态"的连续发育谱上。WIND1 主导谱系的前端（创伤响应→细胞重编程），ERF115–PAT1 主导谱系的后端（干细胞微环境重建→分生组织成熟）。不同外植体来源（根/茎/叶）和组织年龄在连续谱上的起始位置不同，决定了再生效率和器官发生方向的差异。

**推理链**
1. 愈伤组织转录组类似根尖分生组织，但不是完全相同 → "类似"暗示差异存在
2. 创伤诱导通路（WIND1 依赖）与激素诱导通路（CIM 依赖）在分子机制上不同 → 两条通路可能作用于不同阶段
3. ERF115–PAT1 在干细胞微环境重建中关键 → 代表再生过程的"终端"
4. **推理跳跃**：WIND1 和 ERF115 在时间轴上先后作用，且两条通路之间的过渡状态决定了再生结果

**关键预测**
- 时间序列 scRNA-seq 将捕获从 WIND1^high ERF115^low 到 WIND1^low ERF115^high 的连续细胞状态转变
- wind1 突变体在 ERF115 诱导后仍无法完成干细胞微环境重建 → 表型不可被下游因子回补
- 不同组织来源的外植体在 UMAP 上的起始坐标不同，但最终汇聚于同一终点

**可检验性：⭐⭐⭐⭐（高）**
单细胞多组学时间序列、可诱导转基因系统均可实现；难点在于连续谱的定量建模。

## 假说 3：光控细胞周期效应的器官特异性假说

**陈述**
光质对植物细胞周期的加速效应在不同分生组织中存在器官特异性差异。节间居间分生组织（intercalary meristem）对蓝光比例的敏感性显著高于根尖分生组织（RAM），因为前者共表达 CRY1 和 PHOT 光受体，而 RAM 中 CRY1 表达水平较低。这一差异的分子基础在于器官特异性转录因子对 CRY1 启动子的差异化调控。

**推理链**
1. 光照使根尖细胞周期缩短至约 12.57 小时 → 光加速根尖细胞周期
2. CRY1 调控形成层活性，后者是节间次生生长的核心 → 蓝光在节间有额外靶标
3. 根尖和茎尖具有不同的转录组 → 光受体的下游信号组分可能存在器官特异性
4. **推理跳跃**：节间居间分生组织对蓝光的细胞周期响应强于根尖，且这种差异由 CRY1 的器官特异性表达水平决定

**关键预测**
- EdU 标记实验：相同蓝光处理下，节间居间分生组织的 S 期细胞比例增幅 > 根尖分生组织
- CRY1 启动子活性（CRY1pro::GUS）在节间基部区域强于根尖
- 在 RAM 中异位过表达 CRY1 应使根尖获得"节间样"的蓝光高敏感性细胞周期响应

**可检验性：⭐⭐⭐⭐（高）**
EdU 标记、GUS 报告系和 EdU 脉冲追踪实验均为常规技术。

## 假说 4：节间纵向光质解读梯度假说

**陈述**
大豆节间沿纵轴方向存在一个内源的"光质解读梯度"（photoreception gradient）：顶部幼嫩节间优先通过 phyB 感知 R:FR 信号启动避荫伸长，而基部较老节间优先通过 CRY1 感知蓝光信号启动次生加厚。这一梯度的分子基础是赤霉素（GA）和细胞分裂素（CK）沿节间轴向的拮抗分布——GA 在顶部节间富集驱动伸长，CK 在基部节间富集驱动形成层活性——而该激素梯度本身受光质调控。

**推理链**
1. CRY1 调控形成层活性 → 基部节间（形成层更活跃）应对蓝光更敏感
2. phyB 介导避荫响应（R:FR 感知）→ 顶部节间（伸长最活跃）应对 R:FR 更敏感
3. GA 驱动细胞伸长，CK 驱动细胞分裂 → 二者在功能上拮抗
4. **推理跳跃**：GA/CK 沿节间的空间梯度是光质信号的"翻译器"，将光信息转化为位置特异性的发育输出

**关键预测**
- 纵向分段 LC-MS 测激素：顶部节间 GA₃ 浓度 > 基部，基部节间 tZ 型 CK 浓度 > 顶部
- 低 R:FR 处理消除 GA 梯度（各节间 GA 均升高），蓝光富集处理消除 CK 梯度
- 节间分段 RNA-seq 应揭示 GA 响应基因和 CK 响应基因沿纵轴的镜像表达模式

**可检验性：⭐⭐⭐⭐（高）**
激素定量、光质处理和转录组分析均可在现有大豆项目中实现。

## 假说 5：miR165/6–节间维管模式的光质门控假说

**陈述**
光质通过调控 miR165/6 在节间横切面上的径向梯度表达，间接控制 HD-ZIP III（PHB/PHV/REV）蛋白的功能域，从而在节间的不同纵向位置建立差异化的维管束排列模式。具体而言，蓝光通过 CRY1 信号促进 miR165/6 在形成层外侧（韧皮部侧）的积累，限制 PHB 的表达域，使维管束保持离散排列；而低 R:FR/低蓝光条件下 miR165/6 的径向梯度被削弱，PHB 表达域扩展，导致维管束融合和木质化增强。

**推理链**
1. miR165/6 在根中转录后限制 PHB 表达域调控辐射状模式 → miR165/6-PHB 模块是模式建成的通用机制
2. CRY1 影响形成层活性 → CRY1 可能通过 miR165/6 间接作用于维管模式
3. 低 R:FR 促进茎伸长和木质化 → 已知的避荫表型与 PHB 功能增益表型有重叠
4. **推理跳跃**：光质→CRY1→miR165/6→PHB 构成一条从环境信号到维管模式建成的完整信号通路

**关键预测**
- miR165/6 传感器（MIR165/6pro::erGFP）在蓝光处理下显示清晰的径向极性梯度，在低 R:FR 下梯度消失
- phb-1d（PHB 功能增益）突变体在正常光照下即呈现低 R:FR 条件下的维管束融合表型
- cry1 突变体中 miR165/6 的径向梯度显著减弱，可通过形成层特异性 miR165/6 过表达回补维管表型

**可检验性：⭐⭐⭐⭐（高）**
miRNA 传感器、CRISPR 突变体和形成层特异性启动子均为成熟工具；大豆中的验证需要稳定的遗传转化体系。

## 假说间关联

```
假说 1 (CRY1–PIN1 极性重定位)
  ├── 与假说 5 共享上游 CRY1 信号 → 分别解释维管比例（1）和维管排列模式（5）
  ├── 与假说 4 共享"节间纵向差异"主题 → 假说 1 关注径向，假说 4 关注纵向
  └── 与假说 3 共享"蓝光信号器官特异性"前提 → 假说 1 的验证可在节间外植体中测试

假说 2 (愈伤组织连续谱)
  └── 独立假说，但与假说 4 相关：节间不同位置的外植体再生能力差异
     可由其在连续谱上的起始位置解释

假说 3 (光控细胞周期的器官特异性)
  └── 与假说 4 直接关联 → 假说 3 的"器官特异性"可推广为假说 4 的"节间位置特异性"
```

## 潜在反证

- **假说 1**：若 cry1 突变体中 PIN1-GFP 极性定位无显著变化，则 CRY1 可能通过 PIN1 非依赖途径（如 PIN3/PIN7 或其他生长素转运体）调控形成层活性
- **假说 2**：若 wind1 erf115 双突变体仍能形成正常根端分生组织，则连续谱模型需修正为多因子并行模型
- **假说 3**：若 CRY1 在 RAM 和节间中表达水平相当但细胞周期响应不同，则器官特异性来自下游信号组分而非受体丰度
- **假说 4**：若节间纵向激素梯度在光质处理前后无显著变化，则光质可能绕过激素直接调控发育基因
- **假说 5**：若 miR165/6 传感器在光质处理下无径向梯度变化，则 PHB 的表达域调控可能由光质直接作用于其启动子或蛋白稳定性
