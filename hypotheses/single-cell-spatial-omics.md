### H1: 大豆节间至少包含 12 种 snRNA-seq 可区分的细胞类型，且可通过跨物种直系同源标记基因进行注释

**陈述**：大豆（Glycine max）节间组织在单细胞分辨率下可解析为不少于 12 种转录组学可区分的细胞类型——包括表皮、皮层、内皮层、韧皮部、木质部薄壁细胞、维管形成层、髓薄壁细胞及其发育亚状态。这些细胞类型的标记基因集可通过拟南芥和水稻直系同源推断获得，且大豆节间与水稻节间共享核心保守细胞类型，同时存在豆科特有类群。

**证据基础**：Synthesis 共识 #1（scRNA-seq 可跨物种可靠解析主要细胞类型，拟南芥 ≥15 种、水稻包括外皮层等单子叶特有类型）、共识 #2（根是植物单细胞图谱最全面的器官）；知识空白 #1（大豆缺乏任何单细胞和空间转录组图谱）；水稻两个栽培品种根尖 scRNA-seq 已建立单子叶参考范式；玉米雌穗和叶片图谱证明单细胞方法可跨器官推广。

**可检验预测**：
1. 大豆节间 snRNA-seq（10x Genomics）可鉴定 ≥12 个转录组学可区分的细胞簇，各簇表达已知直系同源标记基因（如内皮层 GmSCR、维管束 GmSHR）
2. 不同细胞类型差异富集特定生物学过程 GO 条目——表皮细胞富集角质/蜡质合成、维管细胞富集次生壁合成与转运蛋白、髓细胞富集贮藏蛋白
3. 维管形成层与韧皮部/木质部之间识别到过渡态细胞群，构成沿拟时序的发育连续体
4. 跨物种比较揭示大豆节间与水稻节间共享 8–10 个同源细胞类型，但大豆具有 1–2 个豆科特异性细胞类群（可能与结瘤相关的维管重构有关）

**证伪条件**：
- 若 snRNA-seq 仅能区分 ≤5 个细胞簇，且簇间差异主要由技术噪声而非生物信号驱动
- 若大豆节间转录异质性极低（各解剖区域的转录组高度相似），表明该组织不适合单细胞分辨率研究
- 若跨物种标记基因映射失败——即拟南芥/水稻已知标记基因在大豆中无明确一对一直系同源或表达无细胞特异性

**检验方法**：
1. **snRNA-seq + 聚类分析**：采用 10x Genomics 平台对大豆节间细胞核进行测序，使用 Seurat/Scanpy 进行无监督聚类、差异表达分析和标记基因鉴定
2. **跨物种直系同源映射**：通过 OrthoFinder/InParanoid 将拟南芥和水稻已知细胞类型标记基因映射到大豆基因组，验证标记基因在各细胞簇中的表达特异性
3. **拟时序分析**：使用 Monocle 3/Slingshot 重建维管发育轨迹，鉴定过渡态细胞群和命运分支点
4. **空间转录组验证**：利用 Stereo-seq 或 10x Visium 对大豆节间切片进行空间转录组测序，将 snRNA-seq 细胞簇映射到组织空间位置

**优先级**：★★★（知识空白直接填补 + 大豆光质项目基础设施）

### H2: 不同光质条件诱导大豆节间细胞类型特异性的差异转录程序，而非统一的组织水平响应

**陈述**：红光/远红光比例（R:FR）降低和蓝光处理在大豆节间不同细胞类型中激活截然不同的转录响应程序，而非产生均匀的全组织响应。具体而言：(a) 表皮和皮层细胞的赤霉素（GA）代谢和细胞壁松弛基因对低 R:FR 最敏感，驱动荫蔽诱导的伸长；(b) 维管束细胞的光形态建成基因（如 CRY/PHOT 下游靶标）对蓝光变化响应幅度最大；(c) 髓细胞在光质处理下主要表现代谢重编程而非细胞形态变化。

**证据基础**：Synthesis 共识 #5（细胞类型特异性胁迫响应超越经典共享胁迫程序——热胁迫和免疫响应中均观察到细胞类型特异转录差异）；ZmHSP90-ZmWAK2 介导的表皮-叶肉细胞通讯模式在光质响应中可能存在类比机制（表皮感知光信号→传递至内部组织）；玉米叶片空间转录组学已证明发育梯度分析在组织层次异质性研究中的有效性；大豆节间光质项目关联。

**可检验预测**：
1. 低 R:FR 处理下，表皮细胞 GA20ox/GA3ox 表达上调幅度 ≥ 皮层细胞的 2 倍、≥ 髓细胞的 5 倍（细胞类型×处理的显著交互效应，FDR < 0.05）
2. 蓝光处理下，维管束细胞中 CRY1/CRY2 下游靶基因（如 HY5、BBX 家族）上调幅度显著高于表皮和皮层（log2FC 差异 ≥ 1.5）
3. 细胞通讯推断（CellChat/NicheNet）识别到 "表皮 → 皮层 → 维管束" 的光信号传递配体-受体链，涉及生长素（AUX/IAA）、油菜素内酯（BRI1/BSK）和肽信号（CLE/CLV）
4. 至少 3 种细胞类型的拟时序分化轨迹在光质处理后发生显著偏移（拓扑相似度 < 0.7），表明光质改变细胞分化方向而非仅调控成熟细胞代谢

**证伪条件**：
- 若所有细胞类型在光质处理下呈现均一的转录变化幅度，方差分析未检测到显著的细胞类型×处理交互效应
- 若光响应基因（如 GA 代谢基因、光受体下游靶标）的表达变化在各细胞类型间无统计学显著差异
- 若细胞通讯推断未识别到任何跨细胞类型的信号传递网络，配体-受体共表达模式在各细胞类型对间均匀分布

**检验方法**：
1. **多条件 snRNA-seq**：大豆节间在对照（白光/R:FR=1.2）、低 R:FR（0.2）、蓝光富集和远红光富集四种条件下进行细胞核分离与测序，比较各细胞类型的差异表达谱
2. **细胞通讯推断**：使用 CellChat（配体-受体数据库）和 NicheNet（配体活性预测）跨细胞类型分析信号传递网络，重点关注光信号→激素信号的转导链
3. **拟时序对比分析**：对每种条件下独立运行 Monocle 3，定量比较各细胞类型沿拟时序的表达轨迹拓扑相似度
4. **空间转录组 + 光质处理**：在 Stereo-seq 平台上对光质处理后的节间切片进行空间转录组测序，将 snRNA-seq 细胞类型映射到空间坐标，验证细胞通讯的空间邻近性

**优先级**：★★★（直接服务于大豆光质项目 + 从描述到机制的跃迁）

### H3: 拟南芥内皮层 Casparian 带形成受层级调控网络而非线性级联控制——仅顶层主调控因子扰动即可引发全局崩溃

**陈述**：内皮层沿分化轨迹动态表达的约 800 个基因并非构成简单的线性调控级联，而是形成层级化的调控网络：MYB36 为顶层主调控因子（占据网络的最高层级），SHR/SCR 为中间层细胞命运决定因子，过氧化物酶和木质素合成酶等为底层的终端效应基因。该网络呈现 "中心-辐射" 拓扑（hub-and-spoke），仅 ~5% 的顶层因子（MYB36 及其直接辅因子）的扰动即可引发 >50% 的下游网络基因表达失调。

**证据基础**：Synthesis 共识 #6（发育假时间分析揭示了谱系特异性转录动力学——内皮层约 800 个基因沿分化轨迹动态表达，涉及 MYB36/SHR/SCR 等关键调控因子以及木质素合成通路）；知识空白 #3（细胞类型特异性调控网络的功能验证匮乏——内皮层 800 个动态基因中哪些是功能必需的未知）；MYB36 被多篇文献一致指向 Casparian 带形成主调控因子；SHR 和 SCR 在根径向模式建成中功能已知。

**可检验预测**：
1. MYB36 CRISPR 敲除导致 800 个动态基因中 >50%（≥400 个）表达显著失调，包括 SHR/SCR 下游靶标和木质素合成通路的全套基因
2. 下游效应基因（如过氧化物酶基因 PER3/PER39/PER64）单独 CRISPR 敲除仅产生局部 Casparian 带着色异常（木质素沉着减少但带状结构仍可识别），不改变细胞命运或 SHR/SCR 表达
3. ChIP-seq 揭示 MYB36 在 ≥200 个动态基因的启动子区有直接结合峰（包括 SHR 和 SCR 的启动子），形成前馈调控回路
4. 网络中存在冗余旁路——同一组下游效应基因可被 MYB36 或其旁系同源物 MYB68/MYB84 共同调控，单一旁系敲除不产生完全表型

**证伪条件**：
- 若 MYB36 敲除后 800 个动态基因中 >70% 仍保持正常表达水平，表明 MYB36 并非网络枢纽
- 若单个下游效应基因（如 PER3）敲除即产生与 MYB36 敲除相似的全谱 Casparian 带缺失表型，表明调控关系为线性级联
- 若 800 个基因的启动子区缺乏 MYB36 结合基序（AC-I/AC-II 元件）的显著富集

**检验方法**：
1. **CRISPR-Cas9 靶向敲除 + RNA-seq**：在内皮层特异性启动子（如 CASP1p）驱动 Cas9 的拟南芥系中敲除 MYB36、SHR、SCR 及选定的下游效应基因，对根进行 RNA-seq 并对比野生型，量化 800 个基因的表达扰动幅度
2. **ChIP-seq**：使用 MYB36-GFP 融合蛋白系进行 ChIP-seq，鉴定 MYB36 在全基因组中的结合位点，计算与 800 个动态基因启动子的重叠比例
3. **内皮层特异性荧光报告系统**：构建 CASP1::GFP 和 MYB36 下游靶标启动子::mCherry 双报告系，在敲除背景下实时监测 Casparian 带形成和网络扰动
4. **层级网络建模**：使用 GENIE3/SCENIC 从 scRNA-seq 数据推断基因调控网络，结合 CRISPR 验证结果量化网络层级和鲁棒性

**优先级**：★★★（从描述到因果机制的关键跃迁 + 已在顶级期刊中获得关注）

### H4: 同步 snRNA-seq + snATAC-seq 多组学分析可揭示植物细胞中染色质 "预备态"——在基因表达变化之前预测细胞命运决定

**陈述**：在植物根组织中，同步分析同一细胞核的转录组（snRNA-seq）和染色质可及性（snATAC-seq）可实现比单一模态更早的细胞命运变化检测。染色质可及性变化先于基因表达变化至少 2 小时——即存在 "染色质预备态"（chromatin-primed state），细胞在该状态下已建立未来分化方向的开放染色质图谱但尚未启动相应基因的转录。这种预备态可鉴定仅靠转录组无法区分的细胞亚群。

**证据基础**：Synthesis 共识 #3（核基方法是原生质体法的可行替代方案——snRNA-seq/snATAC-seq 可避免细胞壁酶解诱导的胁迫假象）；知识空白 #6（单细胞多组学在植物中仍处于萌芽阶段）；snATAC-seq 已被证明可基于差异染色质可及性解析拟南芥根细胞类型，与 scRNA-seq 分类一致；哺乳动物领域多组学整合（如 10x Multiome）的成熟应用提供了方法论借鉴。

**可检验预测**：
1. WNN（加权最近邻）聚类整合 snRNA-seq + snATAC-seq 可额外鉴定 ≥3 个仅靠单一 snRNA-seq 模态无法区分的细胞亚群（ARI 增量 ≥ 0.1）
2. 沿拟南芥根发育拟时序：预备态细胞中 TF 结合基序的染色质可及性增加先于该 TF 靶基因的 mRNA 表达上调 ≥2 小时（通过拟时序位置偏移定量）
3. 预备态细胞群在 WNN 聚类中形成独立于转录组的聚类——即具有相似的 RNA 表达谱但不同的染色质可及性图谱，富集 bHLH/MYB/NAC 等发育调控 TF 的结合基序
4. 10x Multiome 平台的 RNA 与 ATAC 模态在拟南芥根细胞类型分类中高度一致（ARI > 0.85），表明两种模态从不同维度捕获相同的生物学信号

**证伪条件**：
- 若多组学整合未发现任何单一模态无法检测的新细胞亚群（WNN 与 RNA-only 聚类结果完全相同）
- 若染色质可及性变化与基因表达变化在拟时序上完全同步（无可检测的时间偏移），无证据支持 "预备态" 概念
- 若 RNA 模态与 ATAC 模态的细胞类型分类一致性低（ARI < 0.5），表明两种数据类型的噪声过高，无法进行有意义的整合

**检验方法**：
1. **10x Multiome (单核 RNA + ATAC)**：对拟南芥根尖进行单核分离，使用 10x Genomics Multiome 试剂盒同步建库，在同一细胞核中捕获转录组和染色质可及性信息
2. **WNN 聚类与模态权重分析**：使用 Seurat v5 WNN 聚类方法整合双模态数据，对比 RNA-only、ATAC-only 和 WNN 三种策略的分类分辨率
3. **拟时序偏移定量**：分别基于 RNA 模态和 ATAC 模态独立运行 Monocle 3 构建拟时序，将同一细胞核在两条拟时序上的位置进行配对比较，量化染色质可及性变化相对基因表达变化的时间偏移
4. **TF 基序富集与预备态鉴定**：在预备态候选细胞群中运行 chromVAR/motifmatchr，鉴定可及性显著增加但对应靶基因未上调的 TF 基序

**优先级**：★★（技术前沿探索 + 方法学基础设施建设，但直接产出不确定性较高）

### H5: 植物空间转录组整合方法的精度取决于组织解剖复杂度——高细胞密度区域需要基于概率模型的解卷积方法

**陈述**：现有跨模态整合工具在植物组织中的空间映射精度与组织的细胞密度和解剖复杂度呈负相关。对于高细胞密度的植物分生组织（如根尖、茎尖），基于概率模型的解卷积方法（cell2location、RCTD）显著优于基于嵌入对齐的方法（Harmony、Tangram）；而在低细胞密度的成熟组织区域，两类方法性能差异不显著。这一性能差异源于高密度区域中多个细胞类型的转录组信号在空间位点高度混合，嵌入方法倾向于产生 "细胞类型混合映射" 错误。

**证据基础**：Synthesis 共识 #4（空间转录组整合是连接转录组聚类与组织空间结构的关键——Harmony、Tangram 等工具可将 scRNA-seq 细胞注释映射到空间坐标）；知识空白 #2（空间转录组整合方法的系统基准测试不足——Harmony 等工具在植物中的性能尚未与 Tangram、cell2location 等专用方法全面比较）；拟南芥根尖分生组织作为高细胞密度区域的典型代表；玉米叶片空间转录组学提供了低密度区域的参考案例。

**可检验预测**：
1. 在拟南芥根尖分生组织区域（细胞密度 >5000 cells/mm²），cell2location/RCTD 的细胞类型映射 AUC 高于 Harmony/Tangram ≥15%（配对 t 检验 p < 0.01）
2. 在玉米叶片成熟区域（细胞密度 <1000 cells/mm²），四种方法的映射 AUC 差异 <5%，无统计学显著差异
3. 高密度区域中，嵌入对齐方法（Harmony/Tangram）的 "细胞类型混合" 错误率（每个空间位点被分配 ≥2 种细胞类型的比例）≥30%，而解卷积方法（cell2location/RCTD）≤15%
4. 基于 splatter/SymSim 生成的模拟植物空间转录组数据可准确重现上述性能排序——模拟参数（细胞密度、组织复杂度）与映射精度之间的函数关系可被定量建模

**证伪条件**：
- 若在拟南芥根尖分生组织中四种方法的映射精度无统计学显著差异
- 若低密度参考区域中解卷积方法因过拟合反而表现更差（AUC 低于嵌入方法 ≥10%）
- 若模拟数据无法重现真实数据的性能排序，表明性能差异并非由细胞密度驱动，而是其他混杂因素

**检验方法**：
1. **配对 scRNA-seq + 空间转录组基准测试**：使用已发表的拟南芥根 scRNA-seq 参考图谱与对应的 Stereo-seq/10x Visium 空间数据，分别运行 Harmony、Tangram、cell2location 和 RCTD 四种方法，以已知原位杂交标记基因为金标准评估映射精度（AUC、ROGUE 指数）
2. **模拟数据生成**：使用 splatter 和 SymSim 框架生成不同细胞密度梯度（500–10000 cells/mm²）的模拟植物空间数据，系统评估各方法的精度-密度函数
3. **多解剖区域分区分析**：将拟南芥根按分生组织区、伸长区和成熟区分区评估，定量比较同一方法在不同区域的性能衰减曲线
4. **多物种外部验证**：在水稻根尖和玉米叶片空间转录组数据上重复上述基准测试，验证结论是否具有跨物种普适性

**优先级**：★★（方法学基准 + 社区基础设施，但非直接生物学发现）
