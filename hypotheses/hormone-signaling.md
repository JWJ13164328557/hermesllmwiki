### H1: DELLA蛋白浓度依赖性互作组切换假说

**陈述**: DELLA蛋白在不同浓度阈值下切换优先互作伙伴——低浓度时优先结合生长促进型转录因子（PIF、BZR1），高浓度时转向胁迫响应型转录因子（JAZ、MYC2）。这种浓度依赖的互作组切换使GA信号成为植物生长-防御平衡的分子变阻器（rheostat），而非简单的开/关切换。

**证据基础**:
- DELLA是多种激素信号的"物理整合中枢"：GA、JA、auxin、BR、光信号均通过DELLA蛋白交叉对话（Synthesis 共识发现 #1）
- DELLA-PIF互作是光-GA耦合的核心节点：phyB通过降解PIF与GA通过降解DELLA两条平行途径协同调控下胚轴伸长（Synthesis §8 光-激素交叉对话）
- MdRGL2a直接与MdbHLH162互作，桥接GA和JA信号调控花青素合成（Synthesis §4 DELLA蛋白作为多激素整合中枢）
- BES1/BZR1是DELLA的已知互作伙伴（Synthesis §4）
- 知识空白 #2：DELLA剂量-互作组切换的定量证据不足——不同GA/DELLA浓度下互作组的定量组成变化缺乏系统的Co-IP/MS数据

**可检验预测**:
1. 在GA浓度梯度（0 → 100 μM GA₃）处理下，DELLA Co-IP/MS将显示两个互作组"相"：低GA时PIF/BZR1富集，高GA时JAZ/MYC2富集，两者之间存在一个阈值浓度（~1-10 μM range）
2. DELLA蛋白结构域截断突变体中，GRAS结构域的特定α-螺旋介导与生长促进型TFs的结合，不同结构域负责与胁迫响应型TFs的结合——两者可被突变分离
3. 在DELLA功能获得型突变体（如 *gai-1*，DELLA不被降解）中，即使施加外源GA，PIF靶基因仍被抑制——表明DELLA蛋白丰度而非GA分子本身决定下游输出

**证伪条件**: 在覆盖两个数量级的GA浓度梯度（0.01–10 μM GA₃）下，DELLA互作组组成无定性变化（所有互作伙伴的丰度按相同比例缩放，无切换行为）。

**检验方法**:
1. **梯度GA处理 + Co-IP/MS定量互作组**: 使用GR-DELLA融合蛋白（地塞米松诱导核定位的DELLA），在GA浓度梯度下进行Co-IP/MS，使用label-free定量比较各浓度点的互作组组成
2. **FRET-FLIM活体互作检测**: 构建DELLA-CFP与PIF-YFP、JAZ-YFP、BZR1-YFP的FRET对，在GA梯度下测量FRET效率变化曲线，寻找阈值行为
3. **DELLA结构域截断突变体的酵母双杂交筛选**: 系统截断DELLA的N端DELLA域、GRAS域各子域，鉴定与PIF、BZR1、JAZ、MYC2分别互作的最小结构域
4. **原生质体双荧光素酶报告系统**: 使用PIF响应启动子（如 *PIL1pro:LUC*）和MYC2响应启动子（如 *LOX2pro:LUC*），在DELLA梯度表达下测量两个报告基因的活性比率

**优先级**: ★★★ 最高 — 回答激素信号整合的核心机制问题

### H2: 染色质预配置决定细胞激素响应能力假说

**陈述**: 细胞对特定激素信号的转录响应能力不由激素梯度单独决定，而由发育过程中建立的染色质可及性预配置决定。只有激素信号终端转录因子结合位点（motif）处于开放染色质区域的细胞，才"有能力"对该激素产生转录响应。激素分子本身是"许可信号"而非"指令信号"——它激活已预配置的转录程序，而非从头建立新的调控网络。

**证据基础**:
- 水稻根scRNA-seq揭示：生长素合成基因在分生组织细胞中富集表达，而响应基因在过渡/伸长区激活——合成和响应在空间上分离（Synthesis §1 细胞类型特异性）
- 拟南芥根24个细胞簇中，QC和干细胞簇展现独特的生长素信号谱（Synthesis §1）
- 共识发现 #2：细胞类型特异性激素响应由染色质预配置决定——scRNA-seq一致表明激素响应能力是细胞类型固有的
- CK-SA协同芽再生中，ARR10/ARR12和NPR1是HDAC抑制的表观遗传靶点——染色质关闭时这些基因沉默，HDAC抑制使它们重新可及（Synthesis §2 CK-SA协同与表观遗传调控）
- 知识空白 #1：大豆节间中各激素通路的细胞类型特异性响应缺乏单细胞分辨率数据

**可检验预测**:
1. scATAC-seq与scRNA-seq多组学联合分析将显示：激素TF结合motif侧翼的染色质可及性在激素处理前后不变——可及性由细胞类型决定，不因激素处理而改变
2. 在无激素响应的细胞类型中异位表达先锋转录因子（pioneer TF，如特定的GRAS或bHLH家族成员），可打开原本关闭的激素TF结合位点，使这些细胞获得对该激素的响应能力
3. HDAC抑制剂（如TSA）处理将扩大激素响应的细胞类型范围——原本不响应某激素的细胞类型在染色质全局开放后获得响应能力
4. 不同物种间，同源细胞类型的激素响应基因集保守性高于全基因组背景——表明染色质预配置模式在进化中保守

**证伪条件**: 激素处理前后，不同细胞类型间激素TF结合位点侧翼的染色质可及性发生全局性、大规模变化（而非仅限少数直接靶基因的局部变化）。

**检验方法**:
1. **scATAC-seq + scRNA-seq多组学（Multiome）**: 对拟南芥根尖（已知细胞类型注释完善）在mock vs 五种激素（IAA/CK/GA/BR/JA）分别处理1h后进行10x Multiome测序，比较激素响应基因启动子可及性与表达的关系
2. **HDAC抑制剂预处理实验**: TSA预处理打开全局染色质后，施加各激素，scRNA-seq比较TSA+激素 vs 单独激素的响应细胞类型数量变化
3. **先锋转录因子异位表达**: 在根表皮细胞（典型不响应CK）中异位表达先锋TF候选（如LEC1或FUS3），ATAC-seq检测ARR结合motif是否变为可及，RNA-seq检测对CK是否获得响应
4. **CRISPR介导的motif区域染色质状态操纵**: 使用dCas9-SunTag系统靶向招募染色质重塑因子到特定激素TF结合motif区域，检测是否足以赋予激素响应能力

**优先级**: ★★★ 最高 — 重新定义激素信号的生物学逻辑

### H3: Type-B RR代谢开关的跨物种保守性假说

**陈述**: Type-B RR转录因子对生长素合成基因（*YUC*家族）的转录激活和对ABA合成基因（*NCED*家族）的转录抑制这一双重调控模式在被子植物中广泛保守。该"代谢开关"使单一转录因子同时上调"生长许可"信号和下调"胁迫"信号，构成CK信号调控细胞生长-胁迫平衡的通用分子逻辑。

**证据基础**:
- 梨中PbRR9-like通过双重转录调控同时激活*PbYUC4*（auxin合成↑）和抑制*PbNCED6*（ABA合成↓），实现auxin/ABA比率的重新编程（Synthesis §2 CK作为三激素代谢开关）
- ARR1通过直接激活*SHY2/IAA3*实现CK→auxin信号交叉对话——这是CK-auxin交叉的经典节点（Synthesis §2 信号转导核心模块）
- 共识发现 #3：激素信号间存在"代谢层面"的交叉对话——Type-B RR直接结合代谢酶基因启动子
- 知识空白 #3：该机制在拟南芥、番茄、水稻中是否保守未知
- KNOX转录因子下游同时靶向CK和GA两条激素通路——存在"代谢开关"的平行先例（Synthesis §2）

**可检验预测**:
1. 拟南芥ARR10/ARR12的ChIP-seq将在*AtYUC*家族（如*YUC3/YUC5/YUC8/YUC9*）和*AtNCED*家族（如*NCED3/NCED5/NCED9*）启动子区域检测到显著富集的结合峰
2. 拟南芥 *arr10 arr12* 双突变体中，内源IAA水平下降而ABA水平上升——auxin/ABA比率降低
3. 水稻 *OsRR*（Type-B RR同源基因）过表达株系的RNA-seq中，*OsYUC*同源基因上调、*OsNCED*同源基因下调——该模式在单子叶植物中也保守
4. *YUC*和*NCED*基因启动子上Type-B RR结合motif（ARR1结合位点，AGATHY consensus）的数量和排列在被子植物中保守，且这两个基因家族的启动子区域存在染色质环（Hi-C可检测）使Type-B RR可同时接触两个位点

**证伪条件**: 在拟南芥ARR10/ARR12 ChIP-seq中，*NCED*家族基因启动子区域无显著富集（FDR > 0.05），或ChIP-qPCR验证阴性。

**检验方法**:
1. **跨物种ChIP-seq比较**: 对拟南芥（pARR10:ARR10-GFP）、番茄（pSlRR:SlRR-GFP）、水稻（pOsRR:OsRR-GFP）进行ChIP-seq，交叉比较YUC和NCED同源基因启动子的结合情况
2. **CRISPR/Cas9多重突变体代谢组**: 在拟南芥中构建 *arr1 arr10 arr12* 三突变体和 *arr10 arr12* 双突变体，LC-MS/MS同时定量内源IAA、CK、ABA水平
3. **原生质体瞬时双荧光素酶报告系统**: 克隆来自拟南芥、番茄、水稻的 *YUC* 和 *NCED* 启动子驱动LUC/REN报告基因，共表达同源Type-B RR，测量激活/抑制比率
4. **HiChIP/Hi-C鉴定启动子互作**: 在CK处理的拟南芥幼苗中进行H3K27ac HiChIP，检测Type-B RR结合的*YUC*和*NCED*启动子区域之间是否存在三维染色质互作

**优先级**: ★★ 高 — 揭示激素交叉对话的新范式，但依赖跨物种验证资源

### H4: BR-BES1代谢阀门的碳流定量分配假说

**陈述**: BR信号通过BES1对类黄酮合成酶（*CHS*/*CHI*/*F3H*/*FLS*等）启动子的直接抑制，实现碳流在初生代谢（纤维素合成/细胞壁扩展/生长）和次生代谢（类黄酮/花青素/UV防护）之间的定量分配。BR水平高时BES1核定位多→阀门偏向关闭→碳流优先进入生长；BR水平低/UV-B胁迫时BES1磷酸化失活→阀门开放→碳流转入类黄酮防护。该阀门本质上是植物在生长速度和环境韧性之间的碳经济决策机制。

**证据基础**:
- BES1直接结合并抑制PFG MYB（MYB11/MYB12/MYB111）启动子——这是类黄酮合成早期步骤的调控枢纽（Synthesis §3 BR-BES1类黄酮代谢阀门）
- ACbHLH144响应BR信号并结合*GA2ox7*启动子增强GA失活——表明BR→GA的交叉对话也在代谢层面运作（Synthesis §3）
- 共识发现 #3：激素信号间的"代谢层面"交叉对话
- 知识空白 #6：BES1调控下碳流在初生/次生代谢间定量分配的代谢流直接证据缺失
- BR-BES1模块与光信号耦合：UV-B降低BR信号→BES1磷酸化→类黄酮合成去抑制→UV防护——构成环境响应-代谢出口的完整逻辑链

**可检验预测**:
1. ¹³C-葡萄糖脉冲追踪实验将显示：BR处理组中¹³C在纤维素和半纤维素的incorporation显著高于对照组，而在花青素和山奈酚/槲皮素苷中的incorporation显著低于对照组——两者呈反比关系
2. BES1-GR诱导系统中，地塞米松梯度处理将产生类黄酮含量的梯度下降和纤维素含量的梯度上升——阀门开度与BES1核定位量呈连续函数关系
3. *bes1-D*（BES1功能获得型）突变体在UV-B胁迫下无法充分积累类黄酮，导致UV-B敏感性增加——表明阀门"卡"在关闭位置
4. 代谢组学分析将显示：BES1调控的碳流分配在初生代谢（纤维素合成）和次生代谢（苯丙烷通路）之间存在trade-off，总碳同化速率不变而分配方向改变

**证伪条件**: ¹³C代谢流分析显示BR处理与未处理之间，碳在初生代谢和苯丙烷代谢间的分配比率无显著差异（p > 0.05, n ≥ 4 biological replicates）。

**检验方法**:
1. **¹³C₆-葡萄糖脉冲追踪 + LC-MS代谢流分析**: 在BES1-GR诱导系中，±地塞米松预处理后施加¹³C₆-葡萄糖，追踪¹³C在纤维素（酸水解→衍生化→GC-MS）、花青素（LC-MS/MS）和有机酸中的同位素富集模式
2. **BES1-GR梯度诱导系统**: 构建 *bes1* 背景下的BES1-GR回补系，设置6个地塞米松浓度梯度（0/0.01/0.1/1/10/100 μM），24h后同时进行转录组和靶向代谢组检测
3. **UV-B胁迫下的阀门动态**: 对WT和 *bes1-D* 进行UV-B照射（0/1/3/6/12h时间序列），LC-MS检测类黄酮积累动态和生长速率（下胚轴伸长速率）的反向变化
4. **¹⁴C-蔗糖分区追踪**: 采用经典的同位素分区法——¹⁴C-蔗糖饲喂后分馏提取初生代谢物（热水提取→纤维素/淀粉/蛋白）和次生代谢物（甲醇提取→类黄酮），计算分配比率

**优先级**: ★★ 高 — 揭示碳经济决策的分子机制，但代谢流实验周期长

### H5: bHLH蛋白滴定网络的激素可调谐性假说

**陈述**: bHLH转录因子间的抑制性二聚体扣押（MdbHLH162扣押MdbHLH3/MdbHLH33）与DELLA解救（MdRGL2a竞争性结合MdbHLH162，释放MdbHLH3/MdbHLH33）构成一个"蛋白滴定网络"。GA（通过促进DELLA降解改变游离MdbHLH3浓度）和JA（通过转录激活MdbHLH162增加扣押容量）两路激素信号可独立调谐该网络的输出，使花青素合成呈现梯度式而非开关式调控。该网络是"蛋白互作介导的计算"在植物中的范例。

**证据基础**:
- MdbHLH162通过扣押正调控因子MdbHLH3/MdbHLH33抑制花青素合成；MdRGL2a竞争性结合MdbHLH162，释放MdbHLH3/MdbHLH33恢复*MdDFR/MdUF3GT*转录（Synthesis §4 DELLA-bHLH-bHLH三元蛋白滴定）
- GA促进MdRGL2a降解，因此GA水平通过DELLA蛋白丰度调谐bHLH二聚体组成（Synthesis §4）
- MdbHLH162是JA信号的下游靶标——JA激活其表达，通过bHLH二聚体扣押调控花青素（Synthesis §5 JA信号核心模块）
- 共识发现 #4：蛋白滴定是激素调控代谢输出的新兴范式
- COI1-JAZ-MYC2 JA信号模块与DELLA存在交叉（通过JAZ-DELLA互作），但MdbHLH162-MdRGL2a代表了不依赖JAZ-DELLA互作的新交叉路径

**可检验预测**:
1. 单独GA处理使花青素含量呈S型递增曲线，单独JA使花青素含量呈递减曲线；GA+JA同时处理时，花青素水平取决于GA/JA的浓度比值——而非简单加和——定量拟合一个"GA/JA比率 → 花青素输出"的响应函数
2. 在 *MdRGL2a-OE*（DELLA过表达）背景中施加JA，JA对花青素的抑制效果被削弱——因为过量的MdRGL2a可扣押更多MdbHLh162，释放出的MdbHLH3超过JA上调的MdbHLH162的扣押能力
3. 数学模型（常微分方程描述bHLH二聚体平衡 + DELLA互作）将预测：当MdbHLH162/MdbHLH3蛋白比率 > 2时，花青素合成被完全抑制；比例在0.5-2之间时呈线性梯度调控；比例 < 0.5时花青素接近饱和
4. 在拟南芥中重建该三元体系（AtDELLA + 异源MdbHLH162 + AtTT8/GL3），可在非苹果系统中再现GA/JA双输入的花青素调控逻辑——表明该网络是可移植的信号计算模块

**证伪条件**: 在覆盖生理范围的GA和JA浓度组合（4×4因子设计）下，花青素含量仅对GA或JA之一产生响应，无GA×JA交互效应（two-way ANOVA interaction term p > 0.1）。

**检验方法**:
1. **激素因子设计 + 靶向代谢组**: 苹果愈伤组织或幼苗，GA₃（0/1/10/100 μM）× JA-Me（0/10/100/500 μM）4×4因子设计，48h后LC-MS/MS定量花青素各组分，two-way ANOVA + 响应面回归
2. **Western blot蛋白定量 + 建模**: 在因子设计下同时western blot定量MdbHLH162、MdbHLH3、MdRGL2a蛋白水平，将实测蛋白比率与花青素输出拟合数学模型，检验模型预测力（R² > 0.8）
3. **Co-IP验证蛋白滴定逻辑**: 在因子设计各处理下，以MdbHLH162为诱饵进行Co-IP，定量共沉淀的MdbHLH3和MdRGL2a比率变化，验证"滴定"是否按预测的化学计量进行
4. **拟南芥异源重建**: 在拟南芥 *tt8* 突变体中同时表达MdbHLH162和MdRGL2a，检测花青素表型对GA/JA的响应是否重现苹果中的双输入逻辑

**优先级**: ★★★ 最高 — 揭示蛋白互作"计算"的新范式，可直接用数学建模+实验验证
