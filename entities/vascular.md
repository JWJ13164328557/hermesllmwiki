# 🪵 Plant Vascular System — Evidence Hub

## Components

植物维管系统由三个主要组织组成:

- **形成层 (Cambium)**: 维管干细胞，产生次生木质部和韧皮部
- **木质部 (Xylem)**: 水分和矿物质运输，包括导管、管胞、木纤维
- **韧皮部 (Phloem)**: 光合产物运输，包括筛管、伴胞、韧皮纤维
