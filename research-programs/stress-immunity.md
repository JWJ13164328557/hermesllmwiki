# 📋 Research Program: 胁迫与免疫 — 跨物种细胞类型特异性与胁迫记忆

## Central Question

**植物胁迫应答如何超越「共享胁迫程序」呈现细胞类型特异性？免疫-生长权衡能否被定量化为可预测的分子成本？胁迫记忆在多组学层面如何编码与维持？**

> 本项目为纯知识推演方案——基于已有公开数据的整合分析与知识图谱推理，不涉及湿实验。核心目标是从跨物种比较视角，系统解析胁迫-免疫领域的三个根本性知识空白。

---

## 项目背景

植物胁迫生物学已积累海量数据——从拟南芥模式系统的精细机制解析到水稻、小麦、玉米、马铃薯等作物的组学数据。然而，三个根本性问题尚未被系统回答：

| 核心问题 | 当前认知局限 | 本项目推理策略 |
|---------|-------------|--------------|
| **细胞类型特异性** | 经典胁迫研究以整体组织为分析单元，忽视了表皮、皮层、内皮层、维管束等细胞层的分化响应 | 跨物种整合 5+ 已发表的 scRNA-seq/snRNA-seq 胁迫数据集，系统比较细胞类型特异性转录程序的共性与物种特化 |
| **免疫-生长权衡** | OsNPR1-IPA1、RB 选择性剪接等个案已被发现，但缺乏跨物种的定量比较框架和可泛化的 cost-benefit 模型 | 建立多物种免疫成本指数，从能量代谢、碳分配、核糖体占位等维度量化 trade-off |
| **胁迫记忆** | 胁迫 priming 现象已被描述，但其染色质编码（组蛋白修饰记忆）、转录记忆和代谢记忆的完整链条未被打通 | 整合 ATAC-seq、ChIP-seq（H3K4me3/H3K27me3）、RNA-seq 和代谢组数据，重建胁迫记忆的多层级编码逻辑 |

本项目基于 **stress-immunity Synthesis**（475 条证据，144 篇文献）的系统知识综合，以纯知识推演方式，从跨物种比较视角出发，构建植物胁迫与免疫的统一理论框架。

## Aim 1: 多物种细胞类型特异性胁迫应答图谱比较

**检验假设**: H1 — 植物胁迫应答的细胞类型特异性模式在物种间既有保守核心（如维管束细胞的 ABA 响应），也存在物种特化（如豆科根瘤细胞的独特胁迫程序）；细胞类型比物种更能解释胁迫转录响应的方差。

**科学依据**:
- 胁迫响应具有细胞类型特异性（共识#4）：小麦根盐胁迫呈现表皮-皮层-内皮层分化响应（[[ev-41133438-01]]），马铃薯叶热胁迫中 MCs 和 ECs 沿不同轨迹响应（[[potato-leaf-heat-scrna-f5]]），玉米病原侵染中 ZmHSP90-ZmWAK2 介导表皮-叶肉通讯（[[b3-l7tWWswvI2rZ5ba_4V2BsQ]]）
- 苜蓿镉胁迫单核多组学揭示不同根细胞类型的差异化染色质可及性（[[alfalfa-cadmium-sc-multiomics]]）
- 小麦盐胁迫呈现亚基因组不对称表达（[[ev-41133438-04]]），提示多倍体物种的细胞类型特异性可能有额外维度

**推理框架**:

```
数据整合:
  已发表 scRNA-seq/snRNA-seq 胁迫数据集:
  ┌──────────────┬─────────────────┬──────────────┐
  │ 物种          │ 胁迫类型          │ 组织          │
  ├──────────────┼─────────────────┼──────────────┤
  │ 小麦 (Triticum)│ 盐胁迫 (NaCl)    │ 根尖          │
  │ 马铃薯 (Solanum)│ 热胁迫 (HS)      │ 叶片          │
  │ 玉米 (Zea)     │ 病原侵染 (Fungal) │ 叶片          │
  │ 苜蓿 (Medicago)│ 镉胁迫 (Cd²⁺)    │ 根            │
  │ 拟南芥 (Arabidopsis)│ 多种胁迫       │ 根/叶         │
  │ 水稻 (Oryza)   │ 冷胁迫/盐胁迫     │ 根/叶         │
  └──────────────┴─────────────────┴──────────────┘
```

**分析流程**:

```mermaid
Step 1: 统一重分析
  各数据集独立 QC → 标准化 → 聚类 → 细胞类型注释
  → 同源基因映射 (OrthoFinder → 跨物种 orthogroup 统一 ID)

Step 2: 细胞类型 × 胁迫响应矩阵
  对每种细胞类型:
    计算胁迫 vs 对照 DEG
    → 构建 "细胞类型胁迫响应谱" (Cell-type Stress Response Profile, CSRP)
    → CSRP = {orthogroup: log2FC} 向量

Step 3: 跨物种比较
  → 同细胞类型 (如根表皮) 跨物种 CSRP 余弦相似度
  → UMAP 嵌入: 所有 (物种 × 细胞类型 × 胁迫) 组合
  → 方差分解: 物种 vs 细胞类型 vs 胁迫类型的解释度

Step 4: 保守模块与特化模块鉴定
  → 至少 3/5 物种共享的胁迫响应 orthogroup → "保守核心胁迫程序"
  → 单物种特有的细胞类型胁迫标记 → "物种特化胁迫模块"
  → 富集分析: 保守模块的 GO/通路 (预期: ROS、蛋白折叠、ABA 信号)
```

**关键推理节点**:
- 维管束细胞（木质部前体/韧皮部前体）是否在跨物种胁迫响应中呈现最高保守性？（预期：是 — 维管系统进化古老，胁迫响应可能深度保守）
- 表皮细胞胁迫响应是否物种特化程度最高？（预期：是 — 表皮直接接触环境，适应各自生态位）
- 多倍体物种（小麦）的亚基因组不对称表达是否在特定细胞类型中更显著？

**产出**:
- 跨物种细胞类型胁迫响应统一图谱
- 「保守核心胁迫程序」基因集 (~200-500 orthogroups)
- 物种特化胁迫模块目录
- 方差分解结果：细胞类型 > 胁迫类型 > 物种？（待检验）

**里程碑**: Month 1-8，建立跨物种细胞类型胁迫响应比较框架

## Aim 2: 免疫-生长权衡的跨物种定量框架

**检验假设**: H2 — 免疫-生长 trade-off 遵循跨物种保守的能量经济学原理：每单位免疫激活消耗的碳/氮/能量可通过「免疫成本指数」(Immune Cost Index, ICI) 量化；不同物种在 Pareto 前沿上的位置反映其生活史策略。

**科学依据**:
- OsNPR1-IPA1 模块协调水稻免疫与发育（共识#2）：OsNPR1 是 IPA1 功能必需因子，二者共同调控大量重叠靶基因（[[pdf-koag153-f6]], [[pdf-koag153-f7]]）
- RB 选择性剪接可平衡马铃薯生长与免疫：不同剪接异构体分别倾向于激活防御或维持发育（[[pdf-koag153-f4]]）
- 免疫-生长权衡缺乏定量框架（空白#2）
- 糖感知通过 O-GlcNAc 糖基化连接代谢状态与免疫信号（[[daily-42146548]]），提示代谢中间产物可能是 trade-off 的量化桥梁

**推理框架**:

```
免疫成本指数 (ICI) 建模:

ICI = C_defense / (C_defense + C_growth)

其中:
  C_defense:
    - 防御基因表达量 (TPM 加权求和: PR 基因、PAL、NPR1 等)
    - 次生代谢物合成成本 (以碳骨架数估算: 类黄酮、木质素、芥子油苷)
    - 防御蛋白翻译成本 (核糖体占位比: 防御相关 mRNA / 总 mRNA)
    → 归一化为 "防御碳当量" (Defense Carbon Equivalent, DCE)

  C_growth:
    - 光合基因表达量 (LHCB、RBCS、PSBA 等)
    - 核糖体蛋白基因表达量
    - 细胞周期基因表达量 (CYCB、CDKB 等)
    → 归一化为 "生长碳当量" (Growth Carbon Equivalent, GCE)
```

**跨物种分析矩阵**:

| 数据维度 | 数据来源 | 目标 |
|---------|---------|------|
| 转录组 (bulk RNA-seq) | 已发表的多物种胁迫/感染数据集 | DCE vs GCE 比值计算 |
| 代谢组 | 公开代谢组数据库 (MetaboLights) | 次生代谢物碳成本估算 |
| 蛋白质组 | PRIDE 数据库 | 核糖体占位间接推断 |
| 基因组 | 各物种参考基因组 | 基因家族拷贝数 (防御 vs 生长基因) |
| 表型组 | 文献挖掘 | 生物量-抗病性相关性 |

**推理步骤**:

```
Step 1: 数据收集与标注
  检索 GEO/SRA/MetaboLights/PRIDE:
    → 物种: 拟南芥、水稻、玉米、小麦、马铃薯、番茄、苜蓿
    → 条件: 病原菌侵染 + 对照
    → 时间点: 感染后 0h/6h/12h/24h/48h
    → 每个物种收集 ≥3 个独立研究

Step 2: ICI 时间序列计算
  对每个物种×感染时间点:
    → 计算 DCE (防御碳当量)
    → 计算 GCE (生长碳当量)
    → ICI = DCE / (DCE + GCE)
    → 绘制 ICI 时间曲线

Step 3: Pareto 前沿鉴定
  以 DCE 为 x 轴、GCE 为 y 轴
    → 各物种数据点分布
    → 拟合 Pareto 前沿 (理论最大生长 + 最大防御边界)
    → 每个物种距离 Pareto 前沿的距离 = "免疫效率" (Immune Efficiency)

Step 4: 物种策略分类
  → 高 ICI + 低生长恢复: "防御优先型" (Defense-prioritizer)
  → 低 ICI + 高生长恢复: "生长优先型" (Growth-prioritizer)
  → 中 ICI + 快速恢复: "弹性平衡型" (Resilient-balancer)
```

**跨物种比较预期**:

| 物种 | 预测策略 | 推理依据 |
|------|---------|---------|
| 拟南芥 | 防御优先型 | 短生命周期，单次繁殖，防御即可保证繁殖成功 |
| 水稻 | 弹性平衡型 | 驯化种，人工选择平衡产量与抗性 |
| 小麦 | 弹性平衡型 | 多倍体缓冲，亚基因组可分工防御与生长 |
| 马铃薯 | 防御优先型 | RB 基因剪接暗示防御可塑性高 |
| 玉米 | 生长优先型 | C4 高光合效率，可补偿防御成本 |
| 苜蓿 | 弹性平衡型 | 多年生，需平衡即时防御与持续生长 |

**产出**:
- 跨物种 ICI 定量曲线
- 免疫-生长 Pareto 前沿模型
- 物种生活史策略分类（防御优先/生长优先/弹性平衡）
- 可泛化的 trade-off 基因集（如 NPR1、生长素响应因子、核糖体蛋白）

**里程碑**: Month 3-12，建立免疫-生长 trade-off 的跨物种定量分析框架

## Aim 3: 胁迫记忆的多组学编码机制

**检验假设**: H3 — 胁迫记忆以层级编码方式存储：染色质层面的组蛋白修饰（H3K4me3 在 priming 基因启动子的维持）构成初级编码，转录因子网络的反馈回路构成次级编码，代谢物积累（如脯氨酸、海藻糖的维持性升高）构成三级编码。三层编码在不同时间尺度上维持记忆，且其解耦合或衰退预测记忆丧失。

**科学依据**:
- 多次/轻度胁迫暴露引发胁迫记忆现象（知识空白#5），但染色质-转录-代谢的完整编码逻辑未建立
- 生育酚在柑橘低温适应中被持续诱导（[[accumulation-of-tocopherols-and-transcriptional-regulation-f2]]），提示代谢记忆的存在
- 光控释放型 ABA 可增强水稻耐盐性（[[daily-42216516]]），暗示激素信号的时序模式本身就是一种记忆形式
- 抗氧化防御系统以年龄依赖方式响应胁迫（[[daily-42178064]]），表明发育阶段与胁迫记忆存在交互

**推理框架**:

```
胁迫记忆的三层编码模型:

Level 1 — 染色质记忆 (小时→天):
  Priming 刺激后:
    H3K4me3 在「记忆基因」启动子区维持 (即使胁迫解除)
    H3K27me3 在「生长基因」启动子区瞬时去除后恢复
  → 关键推论: 染色质记忆 = 组蛋白修饰的滞后动力学

Level 2 — 转录记忆 (天→周):
  胁迫解除后:
    部分 TF 维持低水平表达 (自激活反馈回路)
    ABA/JA/SA 信号通路组件持续表达
  → 关键推论: 转录记忆 = TF 正反馈回路的双稳态性

Level 3 — 代谢记忆 (天→周→月):
  Priming 刺激后:
    渗透保护物质 (脯氨酸、海藻糖) 维持高水平
    次生代谢物 (类黄酮、酚酸) 持续积累
    抗氧化酶活性的基线偏移
  → 关键推论: 代谢记忆 = 代谢通路的代谢物反馈锁定
```

**数据整合策略**:

```
数据层       数据来源                    提取信息
─────────────────────────────────────────────────
染色质层    已发表的 ChIP-seq/ATAC-seq   H3K4me3/H3K27me3 动态
            (priming 实验)                染色质可及性变化
转录层      已发表的 RNA-seq             TF 和靶基因的
            (priming + 再胁迫)              表达轨迹
代谢层      已发表的代谢组                Priming 标记代谢物
            (priming + 再胁迫)              鉴定
```

**推理步骤**:

```
Step 1: Priming 数据的系统收集
  关键词检索: "stress priming" / "stress memory" / "defense priming" + 植物
  → 优先物种: 拟南芥 (数据最丰富)、水稻、玉米
  → 胁迫类型: 干旱 priming、热 priming、病原 priming
  → 收集标准: 含 priming → 恢复 → 再胁迫 三阶段设计的研究

Step 2: 三层编码的时间序列整合
  对每个 priming 研究:
    → 染色质层: H3K4me3/H3K27me3 随时间的维持/衰减曲线
    → 转录层: 记忆基因 (持续上调) 和非记忆基因 (恢复正常) 的分类
    → 代谢层: 代谢物浓度衰减半衰期 (t₁/₂)
    → 寻找三层编码的时间对齐关系

Step 3: 记忆强度预测模型
  建立逻辑回归/随机森林模型:
    特征: 染色质状态 × TF 表达 × 代谢物浓度
    标签: 再胁迫时的响应幅度增强 vs 无增强
    → 识别记忆的最强预测因子
    → 检验三层编码是加性 (additive) 还是层级因果 (causal hierarchy)

Step 4: 跨胁迫类型的记忆特异性
  比较: 干旱 priming → 热再胁迫 vs 干旱 priming → 干旱再胁迫
    → 交叉保护 (cross-protection) 的分子基础
    → 哪些记忆是胁迫类型特异 vs 通用的
```

**关键推理节点**:
- H3K4me3 的维持半衰期是否决定转录记忆的持续时间？
- 代谢记忆是否能在染色质和转录记忆消退后独立存在？（如脯氨酸在胁迫解除后仍维持高水平数周）
- ABA 信号通路是否是跨胁迫记忆的「通用记忆中枢」？（共识#1: ABA 是跨胁迫类型的核心信号枢纽）

**产出**:
- 胁迫记忆三层编码模型
- Priming 记忆基因集（染色质标记基因、TF 反馈回路基因、代谢记忆标记物）
- 记忆持续时间预测因子列表
- 跨胁迫交叉保护的分子基础

**里程碑**: Month 6-20，建立胁迫记忆的多层级编码理论框架

## Aim 4: 两阶段防御重编程的细胞类型归属

**检验假设**: H4 — 两阶段防御重编程的「快速信号阶段」（Ca²⁺ 内流、ROS 爆发、MAPK 磷酸化）由表皮和保卫细胞等环境接触细胞类型主导；「持续转录重编程阶段」由维管束和叶肉等内部细胞类型主导。两阶段之间存在由表皮→维管方向的信号传递。

**科学依据**:
- 多模块分析定义了两阶段防御重编程：第一阶段（快速信号激活）→第二阶段（细胞类型特异性转录与代谢调整）（[[b3-l7tWWswvI2rZ5ba_4V2BsQ-f5]]）
- 两阶段防御重编程的细胞自主性程度未知（空白#4）
- 玉米表皮细胞 ZmHSP90 与叶肉细胞 ZmWAK2 的跨细胞层通讯（[[b3-l7tWWswvI2rZ5ba_4V2BsQ]]）提供了细胞类型层级通讯的范例
- 马铃薯热胁迫中 MCs 和 ECs 的轨迹分化（Node 1/Node 2）（[[potato-leaf-heat-scrna-f5]]）提示不同类型细胞在时间维度上遵循不同程序

**推理框架**:

```
时间 × 细胞类型 双层矩阵:

            早期 (0-2h)        中期 (2-12h)       晚期 (12-48h)
          ──────────────────────────────────────────────────────
表皮      Ca²⁺ spike ⚡        ROS 消退           恢复正常
           MAPK 磷酸化         防御信号释放          (记忆形成?)
          
保卫细胞  气孔关闭              ABA 持续信号        恢复开放
           (物理防御)           (化学防御启动)
          
叶肉      ROS 接收             转录重编程            代谢重编程
           (信号传递目标)       防御蛋白翻译           次生代谢物积累
          
维管束    长距离信号传递        系统获得性抗性         SAR 维持
           (电信号/ hydraulic)  NPR1-SA 信号          (记忆整合?)
```

**数据整合策略**:

```
所需数据:
  1. 时间序列 scRNA-seq (感染后 0/2/6/12/24/48h)
     → 现有玉米数据可用 ([[b3-l7tWWswvI2rZ5ba_4V2BsQ]])
     → 补充: 拟南芥叶片病原侵染时间序列

  2. 细胞类型特异性:
     Phase 1 标记: Ca²⁺ 信号基因 (CML/CBL/CIPK)、RBOH (ROS 产生)、MAPK 级联
     Phase 2 标记: PR 基因、NPR1 靶基因、次生代谢酶基因、TF (WRKY/NAC/MYB)

  3. 跨细胞通讯推断:
     → CellChat/NicheNet: 表皮→叶肉→维管 的配体-受体对
     → 验证: 已知的 ZmHSP90-ZmWAK2 对作为阳性控制
```

**推理步骤**:

```
Step 1: Phase 标记基因集定义
  Phase 1 特征: |log2FC| 峰值在 0-2h, 4h 后快速回落
  Phase 2 特征: |log2FC| 峰值在 6-24h, 持续至 48h
  → 基于已发表时间序列 RNA-seq 数据定义

Step 2: 细胞类型 × Phase 归属矩阵
  对 scRNA-seq 数据的每种细胞类型:
    → Phase 1 标记基因在该细胞类型的表达比例
    → Phase 2 标记基因在该细胞类型的表达比例
    → 计算 Phase dominance score = P2_ratio / (P1_ratio + P2_ratio)

Step 3: 时间轨迹推断
  RNA velocity / 拟时序分析:
    → 从「早期响应细胞」到「晚期响应细胞」的过渡
    → 是否有细胞状态转变（如叶肉细胞从光合状态→防御状态）

Step 4: 跨细胞信号传递建模
  整合配体-受体对:
    → 表皮(Phase 1)释放的信号分子 (如 ROS、肽类、ATP)
    → 叶肉/维管(Phase 2)接收的受体
    → 构建「信号传递时间表」
```

**关键推理**:
- 表皮细胞是否释放「信号级联触发因子」启动内部细胞的 Phase 2？
- 如果阻断表皮 Phase 1（如通过表皮特异性 RBOH 抑制），内部细胞的 Phase 2 是否仍能启动？
- 两阶段的时间间隔（Phase 1 → Phase 2 的延迟）在不同胁迫类型间是否保守？
- 维管束在 Phase 2 中是否仅是 SAR 信号的被动传递者，还是自身也进行大量转录重编程？

**产出**:

## Aim 5: 胁迫信号网络的跨物种保守性与信号特异性

**检验假设**: H5 — CBL-CIPK 钙信号网络在 PTI 免疫和非生物胁迫中共享核心模块，但通过「信号特异性适配器」（如不同的磷酸化底物偏好、细胞类型特异性表达）区分不同胁迫来源。JA 信号的物种保守性被高估——其在单子叶谷物中的功能可能被其他激素通路补偿。

**科学依据**:
- CBL2/4-CIPK31 既参与盐胁迫渗透调节（磷酸化棉子糖合酶）又参与 PTI 中的钙信号传导（[[daily-42213884]], [[pdf-ijms232416200-f1]]），同一模块如何区分胁迫来源的信号特异性不清楚（空白#8）
- 大麦（Hordeum vulgare）在某些胁迫下 JA 水平未显著变化，但其他激素水平升高（[[ev-42204451-01]]），挑战 JA 作为通用胁迫信号分子的假设（空白#3）
- ABA 是跨胁迫类型的核心信号枢纽（共识#1），但其下游信号输出如何根据胁迫类型调整尚不明确

**推理框架**:

```
信号网络的「核心 + 适配器」模型:

              胁迫输入 (干旱/盐/冷/病原)
                    │
        ┌───────────┼───────────┐
        ↓           ↓           ↓
    Ca²⁺信号     激素信号     ROS信号
  (CBL-CIPK)   (ABA/JA/SA)  (RBOH/POD)
        │           │           │
        └───────────┼───────────┘
                    ↓
          信号特异性适配器
      (底物偏好、表达模式、
       蛋白互作伴侣、亚细胞定位)
                    │
        ┌───────────┼───────────┐
        ↓           ↓           ↓
    干旱响应    盐胁迫响应     免疫响应
   (气孔关闭)   (渗透调节)   (PTI/ETI)
```

**推理步骤**:

```
Step 1: CBL-CIPK 信号特异性分析
  收集 5 物种 × 3 胁迫类型 (盐/病原/干旱) 的 CBL-CIPK 表达数据
    → 构建 CBL-CIPK 共表达网络
    → 鉴定每种胁迫条件下特异激活的 CBL-CIPK 组合
    → 磷酸化底物预测 (基于已知磷酸化基序)
    → 检验: 同一 CBL-CIPK 模块在不同胁迫下是否靶向不同底物？

Step 2: JA 信号跨物种保守性系统评估
  物种矩阵: 拟南芥 | 水稻 | 玉米 | 小麦 | 大麦 | 马铃薯 | 番茄 | 苜蓿
  数据来源: 
    → 每种物种的胁迫后 JA 定量数据 (文献挖掘)
    → JA 合成基因 (LOX/AOS/AOC/OPR) 的表达响应
    → JA 信号基因 (JAZ/MYC) 的表达响应
  
  分析:
    → 计算每个物种的「JA 响应度」(JA Responsiveness Score)
    → 比较单子叶 vs 双子叶的 JA 响应度
    → 检验: 单子叶中 JA 响应度是否显著低于双子叶？
    → 替代分析: 在低 JA 响应度物种中，哪些激素通路被上调补偿？

Step 3: ABA 信号输出差异化
  已知 ABA 同时调控:
    → 干旱: 气孔关闭 (保卫细胞特异)
    → 盐: 渗透调节 (根细胞特异)
    → 冷: OsNCED3 激活 (广泛)
    → 免疫: SA 通路交互 (系统)
  
  推理: ABA 信号的胁迫特异性是通过「下游 TF 组合编码」实现的
    → 从各胁迫的 ABA 响应 DEG 中提取 TF 结合位点富集模式
    → 鉴定不同胁迫下 ABA 信号激活的不同 TF 组合
    → 构建 "ABA 胁迫特异性代码表"

Step 4: CBL-CIPK 与激素信号的交叉点鉴定
  整合 Aim 1 的细胞类型特异性数据:
    → CBL-CIPK 成员在不同细胞类型中的表达特异性
    → ABA/JA/SA 受体在不同细胞类型中的表达特异性
    → 寻找细胞类型层面的「信号特异性适配器」
```

**跨物种比较预期**:

| 信号组分 | 预期保守性 | 预期分歧 | 推理依据 |
|---------|-----------|---------|---------|
| CBL4-CIPK31 盐响应 | 高 | 多倍体物种 (小麦) 亚基因组偏向 | 渗透胁迫是基础胁迫，CBL-CIPK 进化古老 |
| JA 信号核心 | 双子叶高，单子叶低 | 单子叶谷物 JA 可能退化 | 大麦数据 + 单/双子叶分化时间 |
| SA-NPR1 免疫轴 | 高 (拟南芥-水稻已验证) | NPR1 靶基因集合可能差异 | 共识#2 + 共识#6 |
| ABA 核心合成 (NCED) | 极高 | 下游 TF 组合特异 | 共识#1 |

**产出**:
- 跨物种 CBL-CIPK 信号特异性模型
- JA 信号跨物种保守性热图
- ABA 下游「胁迫特异性代码」（TF 组合）
- 信号特异性适配器候选列表

**里程碑**: Month 10-28，揭示胁迫信号网络的特异性编码逻辑

## 整合推理：从五个 Aims 到统一理论

五个 Aims 的输出将整合为植物胁迫-免疫的三维统一理论框架：

```
        细胞类型轴 (Aim 1 + Aim 4)
             ↑
             │  每种细胞类型有自己的
             │  「胁迫响应程序」
             │
             ├──────────────────→ 时间轴 (Aim 3 + Aim 4)
             │                    Phase 1 → Phase 2 → Memory
             │
             ↓
        能量成本轴 (Aim 2)
        Growth ←→ Defense
        (Pareto 前沿)
        
        信号特异性层 (Aim 5)
        覆盖以上三维，决定响应输出
```

**核心推论**:
1. 细胞类型是胁迫响应的第一解释变量（超越物种和胁迫类型）
2. 免疫-生长权衡由细胞类型的能量预算决定——不同细胞类型的「防御预算」不同
3. 胁迫记忆本质上是细胞类型特异性转录程序在时间维度上的滞后解除
4. 信号特异性不是由「专用通路」实现，而是由「共享通路 + 细胞类型特异性适配器」实现
