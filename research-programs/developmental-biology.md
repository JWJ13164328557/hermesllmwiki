# 📋 Research Program: 植物发育可塑性的保守原理与物种特化机制

## Central Question

**植物如何利用保守的分子模块（生长素极性运输、HD-ZIP III 层级调控、WIND1-ERF115 再生开关）在不同器官（根、维管、分生组织）和不同进化谱系中实现发育的可塑性与稳健性？单细胞技术能否为这一跨物种、跨器官的比较发育生物学提供统一的分析框架？**

> 本 Central Question 直接从 Synthesis 的五项共识发现与五项知识空白中自然引出：共识指出植物细胞具有显著发育可塑性，生长素极性运输是器官发生的核心驱动力；知识空白揭示创伤再生与正常发育的异同、跨物种比较框架缺失、单细胞数据向功能验证的转化鸿沟等关键问题。

| H2 | 维管形成层活性调控存在"核心保守层 + 谱系特异增强层"的双层架构：PXY/TMO5/WOX4 模块为保守核心，次生生长强度由谱系特异模块决定 | Aim 2 |

## Aim 1: 根发育与再生 — 辐射状模式建成与干细胞微环境重建

**检验假设**: H1

**科学问题**: 根辐射状模式（表皮→皮层→内皮层→中柱鞘→维管柱）的分子蓝图在被子植物中多大程度上保守？根尖切除后干细胞微环境重建的分子逻辑是否跨物种共享？单子叶与双子叶植物的侧根/不定根发生机制的分叉点在哪里？

**背景与依据**:
- miR165/6 通过转录后限制 HD-ZIP III（PHB/PHV）的表达域来精细化根辐射状模式，这一机制在拟南芥中已被精确描述（ref-nature08977）
- 根尖切除后邻近细胞中生长素被特异性激活，ERF115–PAT1 复合体驱动干细胞微环境的分子与功能重建（ref-pnas-2003346117, ref-nplants-2016-165）
- 静止中心（QC）细胞已通过第三代测序单细胞转录组分析，鉴定出维持干细胞微环境的关键调控因子（b3-yRRSlByPuOxXKvXBl0_LZg），为根尖干细胞微环境的分子剖析提供了范例
- 中柱鞘细胞的局部径向扩张是侧根原基正确定位的细胞学前提（ref-pnas-1820882116）
- 单子叶植物（水稻、玉米）根系以冠根/不定根为主，其发生机制是否沿用与双子叶侧根相同的分子模块高度未知
- 玉米根发育的细胞命运决定已在单细胞分辨率下被全局描述（ref-pbi-14097），为跨物种比较提供了关键参考

**实验设计**:

| 实验 | 物种 | 组织 | 技术 | 条件/处理 | 生物学重复 | 预期产出 |
|------|------|------|------|-----------|-----------|----------|
| 1.1 双子叶根尖单细胞图谱 | *Arabidopsis thaliana* (Col-0) | 根尖（含干细胞微环境 + 分生区 + 伸长区） | 10x Genomics scRNA-seq | 正常生长，5 dpg | n = 3 | 拟南芥根尖全细胞类型参考图谱 |
| 1.2 单子叶根尖单细胞图谱 | *Oryza sativa* (Nipponbare) / *Zea mays* (B73) | 初生根/冠根根尖 | 10x Genomics scRNA-seq | 正常生长，7 dpg | n = 3 × 2物种 | 水稻/玉米根尖细胞类型图谱 |
| 1.3 根尖切除再生时间序列 | *A. thaliana* + *O. sativa* | 根尖切除后残端（0h/6h/24h/48h/72h） | RNA-seq + 生长素报告系 (DR5::GFP) 成像 | 激光切除根尖干细胞微环境 | n = 3 × 5时间点 × 2物种 | 再生过程转录组级联的跨物种比较 |

| 1.5 保守调控回路验证 | *A. thaliana* + *O. sativa* (CRISPR 突变体: miR165/6, PHB, ERF115 同源基因) | 根尖 | 表型分析 + 报告基因成像 | 正常 + 根尖切除 | n = 3 (≥10 株) | 核心调控模块的跨物种功能验证 |

**分析流程**:
```
scRNA-seq 分析:
  → Cell Ranger → QC (UMI > 500, MT < 15%) → SCTransform 归一化
  → Harmony 批次校正（跨物种整合需 SAMap 同源映射）
  → UMAP 聚类 → 已知标记注释（SHR/SCR/PLT/WOX5 等）
  → 拟时序分析 (Monocle3 / Slingshot)：干细胞 → 各层分化轨迹

  → 时间序列 DEG (ImpulseDE2 / maSigPro) → 早期/中期/晚期响应模块聚类
  → 生长素响应 (DR5) 时空激活动力学 → 与 ERF115 表达的时间和空间相关性

  → miR165/6–PHB 模块在再生过程中的动态变化 (sRNA-seq)

侧根 vs 冠根比较:
  → 发生位点单细胞图谱 → 细胞轨迹比较 (bifurcation analysis)
  → 关键 TF 的跨物种同源关系映射 (OrthoFinder)
  → 保守模块鉴定 + 分叉点基因识别
```

- miR165/6–PHB–生长素回路在根发育中的演化保守性评估

## Aim 2: 维管形成层与次生生长 — 细胞分裂-分化平衡的分子调控

**检验假设**: H2

**科学问题**: 维管形成层的细胞分裂-分化平衡如何在木本植物（杨树）、草本植物（拟南芥/番茄）和缺乏次生生长的植物（水稻）中被差异化调控？是否存在"核心形成层程序"——即一套最小的、在所有含形成层物种中必需的基因调控模块？光信号如何直接参与形成层活性的时空调控？

**背景与依据**:
- AtHB8 标记木质部导管分子前体，S17 标记韧皮部筛分子前体，可在单细胞分辨率下区分维管细胞谱系（cr-10-1242-dev-106104）
- PXY/TMO5 信号模块在原形成层/形成层中调控木质部与韧皮部的比例平衡（ref-pp-18-00463）
- 已开发出在木质部中选择性抑制靶基因转录的方法，实现维管细胞类型特异的遗传操作（ev-33822225），为核心形成层模块的功能验证提供了靶向工具
- 蓝光受体 CRY1 过表达导致杨树形成层区细胞层数显著减少，建立光质与形成层活性的直接联系（blue-light-photoreceptor-cryptochrome-1）
- 杨树初生到次生生长转变涉及主要细胞类型的系统转换（ref-j-molp-2023-03-005）
- 形成层活性调控的分子机制，特别是光质如何精确调控形成层细胞分裂与分化，是领域公认的知识空白（知识空白1）

**实验设计**:

| 实验 | 物种 | 组织 | 技术 | 条件/处理 | 生物学重复 | 预期产出 |
|------|------|------|------|-----------|-----------|----------|
| 2.1 多物种维管单细胞图谱 | *A. thaliana* (花序茎) + *Populus trichocarpa* (幼茎) + *S. lycopersicum* (茎) + *O. sativa* (茎基部) | 维管组织（形成层区 + 邻近分化细胞） | 10x Genomics scRNA-seq | 正常生长（物种匹配条件） | n = 3 × 4物种 | 跨物种维管细胞类型参考图谱 |
| 2.2 形成层核心模块鉴定 | 整合 2.1 四物种数据 | — | 计算: SAMap 跨物种映射 + 共享标记基因鉴定 + GENIE3 调控网络 | — | — | "核心形成层模块"基因集及调控网络 |
| 2.3 杨树光质-形成层响应 | *P. trichocarpa* | 幼茎维管组织 | RNA-seq + ATAC-seq | WL / LBL (蓝光) / LRFR (低R:FR) / FR / DARK, 处理 24h+72h | n = 4 × 5条件 × 2时间点 | 光质调控形成层的转录组与染色质景观 |
| 2.4 双子叶次生生长梯度分析 | *A. thaliana* (花序茎自上而下梯度) + *P. trichocarpa* (节间梯度) | 维管组织纵向分段 | RNA-seq | 自然发育梯度（初生→次生转变） | n = 3 × ≥5位置 × 2物种 | 次生生长启动与增强的分子轨迹 |
| 2.5 CRY1/PHYB 功能验证 | *A. thaliana* (cry1cry2, phyB 突变体) + *P. trichocarpa* (CRY1-OE/RNAi) | 花序茎/幼茎 | 组织学 (切片 + 染色) + RNA-seq | 不同光质条件 | n = 3 | 光受体在形成层调控中的跨物种功能证据 |

**分析流程**:
```
跨物种维管细胞映射:
  → 四物种 scRNA-seq → 各自独立聚类注释 → SAMap 基于同源基因跨物种映射
  → 鉴定"核心维管细胞类型": 形成层干细胞、木质部母细胞、韧皮部母细胞
  → 物种特异细胞类型鉴定（如杨树特异次生生长相关亚群）

核心形成层模块:
  → 共享标记基因 (硬筛选: 在所有含形成层的物种中保守表达)
  → GENIE3/SCENIC 构建各物种独立 GRN
  → 跨物种网络对齐 → 保守模体 (network motifs)
  → 与无次生生长物种 (水稻) 对比 → 次生生长必需基因集

光质分析:
  → 杨树光质 RNA-seq → DESeq2 差异分析 → 共享 vs 特异 DEG
  → ATAC-seq → DiffBind 差异可及性区域 (DAR)
  → DAR 关联基因与 DEG 重叠 → 推定直接调控靶标
  → 光受体下游信号通路基因动态聚类

纵向梯度分析:
  → 位置 × 物种的二维 DEG 矩阵
  → 次生生长启动阶段 (early) vs 增强阶段 (late) 的转录特征
  → PXY/TMO5/WOX4 模块沿梯度的表达动态
```

## Aim 3: 茎尖分生组织维持 — 干细胞稳态与器官发生的时空调控

**检验假设**: H3

**科学问题**: 茎尖分生组织（SAM）中 WUS-CLV 负反馈回路维持干细胞稳态的定量参数在物种间如何变化？营养期→生殖期转变的分子触发器在不同光周期响应类型的物种中是否遵循可预测的调控逻辑？SAM 细胞异质性的空间组织在单子叶与双子叶植物中存在哪些差异？

**背景与依据**:
- 拟南芥营养期 SAM 的单细胞转录组已揭示不同功能域（中央区、周边区、肋状区）的细胞异质性（arabidopsis-sam-scrna）
- WUS-CLV 反馈回路是 SAM 干细胞维持的核心模块，但其定量参数（WUS 蛋白扩散范围、CLV3 感知阈值）的物种差异缺乏系统比较
- 玉米 SAM 的形态和功能组织与拟南芥显著不同（产生更多侧生器官），其单细胞分辨率下的细胞异质性尚未被系统描述
- 成熟与衰老叶片细胞中的基因表达比较揭示发育阶段转换同时受光信号和年龄信号的双重调控（ev-40764913），提示营养期→生殖期转变可能由光周期与年龄两条信号共同门控
- 光信号通过 FT-FD-SOC1 模块调控 SAM 从营养期向生殖期的转变，但长日植物（拟南芥）、短日植物（水稻）、日中性植物（番茄）的调控回路差异尚未从单细胞角度被整合解析

**实验设计**:

| 实验 | 物种 | 组织 | 技术 | 条件/处理 | 生物学重复 | 预期产出 |
|------|------|------|------|-----------|-----------|----------|
| 3.1 双子叶 SAM 单细胞图谱 | *A. thaliana* (Col-0) + *S. lycopersicum* (M82) | 营养期 SAM (含 P0-P3 原基) | 10x Genomics scRNA-seq + 空间转录组 (Stereo-seq) | 正常生长，营养期 | n = 3 × 2物种 | 双子叶 SAM 细胞异质性参考图谱 |
| 3.2 单子叶 SAM 单细胞图谱 | *Z. mays* (B73) + *O. sativa* (Nipponbare) | 营养期 SAM | 10x Genomics scRNA-seq | 正常生长，V3-V5 阶段 | n = 3 × 2物种 | 单子叶 SAM 细胞异质性图谱 |

| 3.5 跨物种 SAM 空间组织比较 | 整合 3.1+3.2 数据 | — | 计算: 空间域映射 + 同源细胞类型鉴定 + 功能域定量比较 | — | — | SAM 空间组织的跨物种演化分析 |

**分析流程**:
```
SAM 单细胞分析:
  → scRNA-seq → 聚类 → 已知 SAM 结构域标记注释:
    中央区 (CZ): WUS/CLV3; 周边区 (PZ): STM/KNAT6; 肋状区 (RZ): KNAT1/ATH1
  → 空间转录组整合: RCTD 空间反卷积 → 结构域边界精确定义
  → 拟时序分析: 中央区干细胞 → 周边区 → 器官原基分化轨迹

单子叶 vs 双子叶 SAM 比较:
  → SAMap 跨物种细胞类型映射
  → 保守 SAM 结构域 (CZ/PZ/RZ) vs 物种特异域
  → 玉米分生组织体积/细胞数显著大于拟南芥的转录基础

相变分析:
  → 时间序列 DEG → 各物种开花诱导的分子级联
  → FT-FD-SOC1 模块及各物种同源基因的表达动态比较
  → 保守相变模块 vs 光周期类型特异模块

WUS-CLV 定量:
  → 共聚焦荧光定量 → WUS 梯度扩散参数
  → 计算建模 → CLV3 反馈抑制的阈值与灵敏度
  → 物种间参数差异与 SAM 大小/器官产生速率的关联
```

## Aim 4: 再生与发育可塑性 — 创伤信号与命运重编程的独立通路

**检验假设**: H4

**科学问题**: 创伤诱导的细胞命运重编程在多大程度上独立于正常发育程序？WIND1-ERF115 再生级联是否是陆生植物通用的创伤响应中枢？愈伤组织的"根端分生组织特征"是植物界的普遍现象还是被子植物特化？再生效率的物种差异由哪些分子层面的障碍（表观遗传屏障、细胞周期再进入能力）决定？

**背景与依据**:
- WIND1 是控制细胞命运转变的关键转录因子，在愈伤组织形成和芽再生中起核心开关作用（ref-j-molp-2026-03-005）
- 创伤诱导的愈伤组织形成通路与激素诱导的通路在分子机制上不同，表明伤口信号是独立的再生触发因素（ref-j-cub-2011-02-020）
- 愈伤组织在转录组层面类似于根尖分生组织，即使来源于地上部组织（ev-20230752）
- 愈伤组织诱导涉及细胞分裂、胁迫响应和内源信号等至少三类基因的协同激活（ref-j-molp-2021-05-028）
- 拟南芥叶片外植体离体根从头发生依赖内源生长素的极性运输与不对称分布（ref-erw213）
- 再生能力的物种差异遗传基础仍不清楚（知识空白2）

**实验设计**:

| 实验 | 物种 | 组织 | 技术 | 条件/处理 | 生物学重复 | 预期产出 |
|------|------|------|------|-----------|-----------|----------|
| 4.1 多物种愈伤再生单细胞时间序列 | *A. thaliana* + *O. sativa* + *S. lycopersicum* + *Marchantia polymorpha* (非维管陆生植物参照) | 叶片/叶状体外植体愈伤组织 | 10x scRNA-seq (时间序列) | 愈伤诱导后 0d/3d/7d/14d/21d | n = 2 × 5时间点 × 4物种 | 再生细胞轨迹的跨物种比较 |
| 4.2 创伤早期响应跨物种比较 | *A. thaliana* + *O. sativa* + *M. polymorpha* | 叶片/叶状体创伤边缘 (1 mm) | RNA-seq | 创伤后 0h/1h/6h/24h/72h | n = 3 × 5时间点 × 3物种 | 创伤信号级联的演化保守性评估 |
| 4.3 WIND1-ERF115 模块演化分析 | 涵盖绿藻→苔藓→蕨类→裸子→被子植物的基因组 | 全基因组 | 比较基因组学: 同源基因鉴定 + 系统发育树 + 选择压力分析 | — | — | WIND1/ERF115 家族演化历史与功能域保守性 |
| 4.4 再生效率的表观遗传障碍 | *A. thaliana* (高再生) + *S. lycopersicum* (中等) + *O. sativa* (中低) | 外植体愈伤组织 | ATAC-seq + ChIP-seq (H3K27me3, H3K4me3) | 愈伤诱导前 (0d) + 诱导后 (7d) | n = 2-3 × 2时间点 × 3物种 | 表观遗传可及性与再生效率的关联 |
| 4.5 再生 vs 正常发育整合比较 | 整合 Aim 4 再生 scRNA-seq + Aim 1/2/3 正常发育 scRNA-seq | — | 计算: 多组学整合 + 共享/特异模块鉴定 | — | — | "发育程序"与"再生程序"的系统比较 |

**分析流程**:
```
再生单细胞时间序列:
  → 四物种 scRNA-seq → 各自整合 (scVI/Harmony)
  → RNA velocity → 命运转变方向推断
  → 拟时序: 外植体细胞 → 早期愈伤 → 增殖愈伤 → 器官原基
  → 分支点分析 (TradeSeq): 芽再生 vs 根再生 vs 持续增殖的分支基因

跨物种再生比较:
  → SAMap 跨物种细胞映射（再生细胞类型）
  → 共享再生轨迹 vs 物种特异再生轨迹
  → 再生效率相关基因模块鉴定

创伤响应级联:
  → 时间序列聚类 (Mfuzz): 早期 (0-1h) / 中期 (6-24h) / 晚期 (72h)
  → TF 富集 → 推定创伤主调控因子（WIND1/ERF115 等）
  → 各物种共享/特异创伤响应模块

表观遗传分析:
  → ATAC-seq: 愈伤诱导前后的染色质可及性变化
  → 跨物种 DAR 比较: 再生相关基因座的开放度差异
  → H3K27me3/H3K4me3 与再生基因表达的相关性

再生 vs 发育:
  → 再生轨迹 vs 正常发育轨迹 → 共享细胞状态 vs 再生特异状态
  → 共享标记基因 vs 再生特异标记基因
  → "根端特征"在愈伤组织中的定量评估（与 Aim 1 根尖数据的相似度）
```

**产出**:

- 创伤→愈伤→器官再生的跨物种细胞轨迹比较
- WIND1-ERF115 再生级联的演化起源与功能域保守性

- "再生程序"与"发育程序"的共享/独立模块定量评估

## Aim 5: 跨物种比较发育调控网络 — 保守核心与谱系特化

**检验假设**: H5

**科学问题**: 植物发育的核心调控网络在多大程度上具有跨器官、跨物种的通用性？四个发育模块（根、维管、分生组织、再生）之间是否存在共通的调控语法？能否通过比较发育生物学建立从模式植物到作物、从草本到木本的"发育原理可迁移性"评估框架？

**背景与依据**:
- 多物种比较发育生物学的整合框架缺失是领域核心知识空白（知识空白5）
- 植物胚胎发育呈现"沙漏"模式——早期和晚期物种间转录组差异大而中期保守（b4-tQ-g_5fH-4YwC8OyEwkrYg），暗示发育过程中存在普适的演化约束
- 单细胞组学技术正在革新发育生物学研究范式（共识5），但跨物种、跨器官的数据整合方法仍不成熟
- 从单细胞数据到功能验证的鸿沟是限制该领域转化的关键瓶颈（知识空白3）

**实验设计**:

| 实验 | 物种 | 数据来源 | 技术 | 条件/处理 | 预期产出 |
|------|------|----------|------|-----------|----------|
| 5.1 跨器官调控语法鉴定 | 整合 Aim 1-4 所有 scRNA-seq 数据 (≥5 物种 × ≥4 器官) | 根尖 + SAM + 维管 + 愈伤（全部物种） | 计算: 跨器官细胞类型元分析 + 共享 TF 模体鉴定 | — | "发育调控语法"——跨器官通用的 TF 组合与调控模式 |
| 5.2 跨物种 GRN 整合与比较 | 各物种独立 GRN (GENIE3/SCENIC 构建) → 网络对齐 | Aim 1-4 各物种 GRN | 计算: 网络拓扑比较 (NetRep) + 保守模体识别 + 物种特化连线鉴定 | — | 保守核心网络 + 各物种特化子网络 |
| 5.3 发育沙漏的细胞类型解析 | 胚胎 scRNA-seq (公共数据) + 胚后器官 scRNA-seq (本方案数据) | 拟南芥/水稻/斑马鱼（跨界参照） | 计算: 发育阶段转录组保守性量化 + 沙漏模式检验 | — | 植物胚后发育是否存在"器官发生沙漏"的跨物种证据 |
| 5.4 可迁移性评估框架 | 整合 Aim 5.1+5.2+5.3 结果 | — | 计算: 保守性评分 × 功能重要性 × 表型效应量 → 可迁移性指数 | — | 从模式生物到作物的基因功能可迁移性定量评估矩阵 |
| 5.5 关键预测的功能验证 | *A. thaliana* + *O. sativa* + *S. lycopersicum* (CRISPR 突变体) | SAM / 根尖 / 维管 | 表型分析 + RNA-seq | 基于 5.4 预测的 10-15 个候选基因 | CRISPR 验证，测试可迁移性评估框架的预测准确性 |

**分析方法**:
```
跨器官调控语法:
  → 所有维度 scRNA-seq 数据整合 (meta-atlas)
  → 细胞类型 × 物种 × 器官 三维矩阵
  → SCENIC 推断所有细胞类型的调控子 (regulon)
  → 跨器官共享调控子富集检验（Fisher's exact test）
  → 器官特异调控子鉴定
  → "核心调控语法" = 在所有/大多数器官中活跃的 TF 组合

跨物种 GRN 比较:
  → 各物种独立 GRN 构建 (GENIE3 + SCENIC)
  → 网络模体分析 (FANMOD)
  → 保守模体 (在 ≥3 物种中保守) vs 物种特异模体
  → 网络重连 (rewiring) 分析: 同源 TF 在不同物种中的靶基因差异

沙漏分析:
  → 各发育阶段转录组保守性量化 (Phylostratigraphy + TAI)
  → 胚后器官发育是否呈现类似的沙漏模式
  → 在细胞类型分辨率下测试沙漏假说

可迁移性指数:
  → 综合三个维度:
    1. 序列保守性 (OrthoFinder dN/dS)
    2. 表达模式保守性 (跨物种细胞类型表达相关性)
    3. 网络位置保守性 (GRN 中心度)
  → 加权评分 → 可迁移性排名
```

**里程碑**:
- M5.1 (月12): 跨器官 scRNA-seq 整合数据矩阵建立
- M5.2 (月24): 跨物种 GRN 比较分析完成
- M5.3 (月30): 可迁移性评估框架 v1.0
- M5.4 (月36): 预测功能验证数据 + 框架改进

**产出**:
- 植物发育"核心调控语法"图谱（Figure 5）——跨器官、跨物种的通用 TF 组合
- 跨物种发育 GRN 保守性与重连全景
- 胚后发育"沙漏"模式的细胞类型证据
- 模式生物→作物的发育基因可迁移性评估矩阵
- 10-15 个候选基因的跨物种功能验证数据

## 物种选择逻辑

本方案选择以下物种覆盖植物发育多样性的关键节点:

| 物种 | 类群 | 轮次 | 发育特征 | 在本方案中的角色 |
|------|------|------|----------|-----------------|
| *Arabidopsis thaliana* | 双子叶/十字花科 | 草本/短生命周期 | 有限次生生长；成熟遗传工具 | **模式参照** — 所有 Aim 的基础参考物种 |
| *Solanum lycopersicum* (番茄) | 双子叶/茄科 | 草本/中等 | 一定次生生长；日中性开花；中等再生 | **中间型** — 桥接拟南芥与杨树 |
| *Populus trichocarpa* (杨树) | 双子叶/杨柳科 | 木本/多年生 | 显著次生生长；典型的形成层活动 | **次生生长极端型** — Aim 2 核心物种 |
| *Oryza sativa* (水稻) | 单子叶/禾本科 | 草本/一年生 | 无次生生长；冠根为主；短日开花 | **单子叶模式参照** — 单/双子叶比较 |
| *Zea mays* (玉米) | 单子叶/禾本科 | 草本/一年生 | 大型 SAM；丰富分生组织突变体资源 | **SAM 特化型** — Aim 3 核心单子叶物种 |
| *Marchantia polymorpha* (地钱) | 苔藓类/地钱门 | 非维管 | 无真正根/维管/形成层；低冗余基因组 | **演化外类群** — Aim 4 再生演化起源参照 |

## Knowledge Base Integration

本方案基于知识库:
- **692 Evidence Objects**（发育生物学相关，覆盖根发育、维管形成层、分生组织、细胞命运决定、胚胎发生、光信号调控）
- **1 Synthesis Page**: [developmental-biology](../synthesis/developmental-biology.md)（94 篇文献综合）
- **五项共识发现**:
  1. 植物细胞具有显著发育可塑性 — 愈伤组织本质上是异位激活的根端分生组织程序
  2. 生长素的极性运输和局部积累是器官从头发生的核心驱动力
  3. 维管发育受 HD-ZIP III/TMO5/PXY 等转录因子层级调控
  4. 光信号直接参与发育过程的时空调控（CRY1→形成层活性）
  5. 单细胞组学技术正在革新发育生物学研究范式
- **五项知识空白**:
  1. 形成层活性调控的光质分子机制未完全阐明
  2. 创伤再生与正常发育程序的异同
  3. 单细胞数据到功能验证的转化鸿沟
  4. 节间发育的纵向模式缺乏系统研究
  5. 多物种比较发育生物学的整合框架缺失

所有假设可直接追溯至上述证据对象与知识综合。本方案的 Central Question 正是从共识发现的通用原理与知识空白的未解问题之间的张力中直接引出。
