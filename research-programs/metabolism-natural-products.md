# 📋 Research Program: 植物特化代谢的分子机制解析与理性代谢工程

## Central Question

**植物类黄酮、木质素、萜类和生物碱等天然产物的生物合成如何在分子层面（转录级联、代谢酶分工、跨细胞转运）被精确调控？能否基于这些机制知识构建理性代谢工程的预测框架？**

本方案围绕 5 条可检验假说，组织为 5 个递进式研究目标——从 MBW 复合体的细胞类型特异性（Aim 1）到 NAC-MYB 激素信号级联（Aim 2），从苯丙烷代谢流分配的酶学基础（Aim 3）到光质-代谢耦合的进化保守性（Aim 4），再到天然产物基因簇内转运蛋白的功能鉴定（Aim 5）。Aim 1-3 建立代谢调控的核心机制框架，Aim 4 连接光生物学与代谢，Aim 5 探索合成生物学缺失组件。

> **证据驱动的范围界定**：现有综合中的次级代谢子主题在覆盖度上并不均衡——类黄酮（约 40 篇）、木质素（约 15 篇）证据最为充分，本方案的核心 Aim（1、3、4）与之对应；而 **萜类/类胡萝卜素（约 8 篇）的转录调控**（番茄中 APETALA2 家族成员的转录级联、生姜 6-姜辣素生物合成进化、单萜物种特异性调控；Synthesis §萜类与类胡萝卜素）与 **淀粉/糖代谢的碳分配**（PpbZIP44、miR156a-StSPL9 模块；Synthesis §淀粉与糖代谢）虽已有证据支撑，但未被任一 Aim 直接覆盖——上述通路分别由 AP2/ERF 型因子和 bZIP/miRNA 模块主导，而非本方案已聚焦的 MBW/NAC-MYB/ARF 模式，构成有待拓展的二阶研究空白（详见 Aim 2 延伸与 Knowledge Base Integration）。


## Aim 1: 单细胞分辨率解析 MBW 复合体的 "MYB 组合密码" — 细胞类型特异性类黄酮调控

**检验假设**: H1 — MBW 复合体的细胞类型特异性由不同 MYB 旁系同源基因驱动，每个 MYB 携带独特的顺式元件识别偏好

**背景与依据**:
MBW (MYB-bHLH-WD40) 复合体是类黄酮/花青素合成的核心调控模块，在草莓 (FaMYB5)、甜瓜 (CmMYB6-CmNAC25)、拟南芥 (MYB75/PAP1-AtbHLH113) 和梨 (EsMYB90) 等多个物种中保守。然而，不同细胞类型中 MBW 复合体如何选择性激活特定类黄酮分支通路（花青素 vs 原花青素 vs 黄酮醇）仍不清楚。RHA2B 介导 MYB30 降解促进 MYB75 花青素合成的发现（Evidence: rha2b-mediated-myb30-degradation）提示不同 MYB 之间存在功能替代和竞争关系。本 Aim 通过单细胞转录组和 DAP-seq 直接解析 "哪个 MYB 在哪个细胞类型激活哪条类黄酮分支"。

**实验设计**:
- **物种**: 拟南芥 Col-0（模式，遗传资源丰富）、栽培草莓 Fragaria × ananassa（果实类黄酮模式系统）、番茄 Solanum lycopersicum（验证跨物种保守性）
- **技术**: 10x Genomics scRNA-seq（拟南芥叶片原生质体/草莓果肉/番茄果皮）+ DAP-seq（候选 MYB 体外全基因组结合谱）
- **处理**: UV-B 诱导（促进类黄酮积累，提高代谢活跃细胞的检出率）vs 白光对照，各 3 个生物学重复
- **发育阶段**: 至少 2 个发育时间点（类黄酮积累初期和高峰期），以捕捉 MBW 组合的动态变化

**分析流程**:
```
scRNA-seq → QC (nFeature > 500, MT% < 10%) → Seurat v5 无监督聚类
    → 细胞类型注释（基于拟南芥根/叶参考图谱标记基因映射）
    → R2R3-MYB 家族表达热图 → 每细胞类型的主导 MYB 鉴定
    → 类黄酮结构基因模块得分（CHS, CHI, F3H, DFR, ANS, UFGT, ANR, LAR, FLS）
    → 细胞类型 × 类黄酮分支相关性热图
DAP-seq → 各候选 MYB 全基因组结合位点
    → 靶基因 Jaccard 相似度矩阵 → 功能分化量化
    → 结合基序 de novo 分析 (MEME) → 鉴定 MYB 间基序偏好差异
整合 → MYB 表达细胞类型 × MYB 结合靶标 × 下游代谢物
    → "MYB 组合密码" 规则表
```

**关键比较**:
- 同一物种中不同细胞类型（表皮 vs 维管束鞘 vs 腺毛）的主导 MYB 身份及其靶基因差异
- 不同物种间功能等效的 MYB 成员（如拟南芥 MYB75 vs 草莓 FaMYB5 vs 番茄 SlMYB75）的 DAP-seq 靶基因保守度
- UV-B 诱导前后 MBW MYB 组分的表达变化和细胞类型贡献

**产出**:
- 多物种类黄酮单细胞转录组图谱
- 5-8 个 MYB 旁系同源基因的 DAP-seq 全基因组结合谱
- "MYB 组合密码 → 类黄酮代谢输出" 映射规则
- 细胞类型特异性类黄酮调控的标记基因集

**里程碑**: 建立 MBW-MYB 组合与类黄酮代谢输出的细胞类型特异性映射关系

## Aim 2: MeJA-NAC-MYB 转录级联的时程重构与功能验证

**检验假设**: H2 — 茉莉酸甲酯诱导的多种次生代谢物积累依赖保守的 NAC→MYB 转录级联

**背景与依据**:
MeJA 广泛诱导萜类、生物碱和苯丙烷类代谢物积累，但中间信号组分缺失（Synthesis 知识空白 #2）。生长素通过 PbrARF13-PbrNSC-PbrMYB132 调控次生壁的级联框架（Synthesis §共识发现 #2）和 CmNAC25→CmMYB6 的花青素调控级联（Evidence: cmnac25-targets-cmmyb6）共同提示 NAC→MYB 可能是激素-代谢信号传导的通用模式。Jasmonate 信号的核心通路（COI1-JAZ-MYC2）已阐明，但 MYC2 下游如何激活不同代谢分支的 MYB 因子仍未知。

> **证据补充（2026-08-24）**: 值得注意的是，萜类/类胡萝卜素分支的激素与光响应主要由 **AP2/ERF 型因子**主导（如番茄 AP2 家族成员的转录级联调控类胡萝卜素；Synthesis §萜类与类胡萝卜素），其调控逻辑与类黄酮/苯丙烷的 MBW/NAC-MYB 模式**分属不同转录因子家族**。因此 H2 的 NAC-MYB 级联主要解释类黄酮/苯丙烷分支，而萜类分支更可能走 ORCA3/BIS1 等 AP2/ERF 通路（恰与 Aim 5 的 TIA BGC 调控因子重叠）。本 Aim 的时程转录组与 GSEA 将同时监测 AP2/ERF 家族的时序响应，为后续把萜类/类胡萝卜素分支纳入统一激素-代谢框架（候选 H6）预留数据接口。

**实验设计**:
- **物种**: 拟南芥 Col-0（主系统）、番茄 Micro-Tom（验证跨物种保守性）
- **处理**: 100 μM MeJA 时程处理（0, 1, 3, 6, 12, 24h），3 个生物学重复
- **基因型**: WT、候选 NAC 单/双 CRISPR 突变体、NAC 过表达系

**分析流程**:
```
时程 RNA-seq (18 样本: 6 时间点 × 3 重复)
    → 差异表达分析 (DESeq2, |log2FC| ≥ 1, padj < 0.05)
    → 时序模式聚类 (STEM/ImpulseDE2) → 鉴定早期 (1-3h) NAC 响应者
    → 与代谢分支 MYB 表达时序的交叉相关分析 (CCA)
    → 基因集富集分析 (GSEA): 各代谢分支通路 (KEGG MAPK/类黄酮/萜类/苯丙烷)
候选 NAC ChIP-seq (MeJA 3h)
    → peak calling (MACS2) → 靶基因注释
    → 重点: 代谢分支 MYB 启动子区结合峰
    → 结合基序富集 (HOMER) → NACRS 元件验证
EMSA + 酵母单杂 → 验证 NAC-MYB 启动子直接结合
CRISPR 突变体验证 (nac1 nac2 双突 + NAC-OX)
    → MeJA 处理后非靶向 LC-MS 代谢组学
    → WT vs 突变体的代谢物诱导幅度比较
```

**关键比较**:
- MeJA 响应 NAC 因子的时序模式（早期波 vs 晚期波）
- 不同代谢分支 MYB（类黄酮 MYB75、萜类相关 MYB、生物碱相关 MYB）的 NAC 靶向关系
- WT vs nac 突变体 MeJA 代谢组的全局差异（PCA + 火山图）
- 拟南芥 vs 番茄中 NAC-MYB 级联的保守性

**产出**:
- MeJA 响应的完整时程转录组数据集
- 2-3 个候选 NAC 的 ChIP-seq 全基因组靶标图谱
- NAC-MYB-代谢酶的三层级转录调控网络
- nac 突变体和过表达系的 MeJA 诱导代谢组

**里程碑**: 构建由 MeJA 到各代谢分支的完整 NAC→MYB→代谢酶转录级联模型

## Aim 3: 4CL 基因家族功能分化与苯丙烷代谢流分配的酶学-遗传双验证

**检验假设**: H3 — 4CL 家族成员的组织特异性表达和底物选择性差异共同决定苯丙烷代谢在类黄酮与木质素分支间的碳流分配

**背景与依据**:
苯丙烷途径是初生代谢（莽草酸途径 → 苯丙氨酸）与次生代谢之间的关键分叉点，4CL 是催化羟基肉桂酸生成相应 CoA 硫酯的最后一步通用酶，其产物直接进入类黄酮（通过 CHS）或木质素单体（通过 CCR/CAD）合成。PbrARF13-PbrNSC-PbrMYB132 级联特异性调控木质素而不影响类黄酮，而 MBW 复合体特异性调控类黄酮——两种独立调控模块在 4CL 节点如何实现代谢流分配？本 Aim 通过酶动力学、遗传学和代谢工程三管齐下回答此问题。

**实验设计**:
- **物种**: 拟南芥（4 个 4CL 基因）、杨树 Populus trichocarpa（5+ 个 4CL，木质化模式系统）、大豆 Glycine max（作物验证）
- **策略**: 系统发育 + 酶动力学 → 遗传敲除 → 过表达代谢工程 → 调控网络整合

**分析流程**:
```
系统发育与选择压力分析
    → 多物种 4CL 序列收集 → MAFFT 比对 → IQ-TREE 系统发育树
    → PAML 分支模型 dN/dS → 正向选择位点鉴定
    → 共表达网络 (WGCNA): 各 4CL 成员与类黄酮/木质素通路基因的共表达模式
重组蛋白酶动力学
    → E. coli 表达 + Ni-NTA 纯化 → 4 种底物 (4-香豆酸/咖啡酸/阿魏酸/芥子酸)
    → HPLC 酶偶联法测定 Km, Vmax, kcat → 底物特异性热图
组织特异性表达定位
    → 各 At4CLp::GUS 转基因拟南芥 → 组织化学染色
    → 与已发表拟南芥 eFP/scRNA-seq 数据交叉验证
CRISPR 突变体代谢组
    → 4cl1 (Class I, 木质素型), 4cl3 (Class II, 类黄酮型) 单突 + 双突
    → 木质素测定 (乙酰溴法) + 花青素测定 (分光光度法) + 靶向类黄酮 LC-MS/MS
过表达代谢工程
    → 35S::4CL3 (Class II) 过表达系 → 碳流重定向验证
    → 木质素和类黄酮双重定量
```

**关键比较**:
- Class I vs Class II 4CL 的底物选择性差异（kcat/Km 比值 ≥ 3 倍？）
- 4CL 表达空间模式与类黄酮积累/木质化组织的空间对应关系
- 单突变体 vs 双突变体的代谢物表型强度（功能冗余程度）
- 不同物种（拟南芥/杨树/大豆）4CL 家族功能分化的保守性

**产出**:
- 多物种 4CL 家族的完整功能分化图谱（系统发育 + 酶动力学 + 表达 + 突变体表型）
- 4CL 作为苯丙烷代谢流控制阀的遗传证据
- Class II 4CL 过表达的代谢工程效果评价

**里程碑**: 验证 4CL 是决定苯丙烷代谢流分配方向的关键酶节点，建立 "哪个 4CL → 哪条代谢分支" 的功能注释

## Aim 4: CRY-HY5/BBX-MBW 光保护代谢轴的多物种保守性功能验证

**检验假设**: H4 — 蓝光/UV-B 通过 CRY→HY5/BBX→MBW-MYB→类黄酮合成的级联是单双子叶植物保守的光保护代谢机制

**背景与依据**:
玉米 ZmCRY1 调控 UV-B 保护性类黄酮和蜡质合成（Evidence: zmcry1-gl2-wax-maize），拟南芥光信号核心组分 HY5 已知参与花青素调控，但 CRY→HY5→MBW-MYB 的直接分子链路尚未被实验建立。Synthesis §激素交叉调控指出光信号与激素信号在代谢调控中汇聚。本 Aim 利用多物种遗传资源直接验证 CRY-HY5-MBW-类黄酮级联的物理存在和功能保守性，同时为大豆节间光质项目提供代谢层面的分子解释框架。

**实验设计**:
- **拟南芥系统**: cry1cry2 双突变体、CRY1-OX 过表达系、hy5 突变体、hy5 35S::MYB75 上位性分析系
- **处理**: UV-B (1.5 W/m²) / 蓝光 (50 μmol/m²/s) / 白光对照，24h，3 个生物学重复
- **多物种验证**: 玉米 zmcry1 突变体、番茄 CRY1a CRY2 VIGS 沉默植株、大豆（关联大豆节间光质项目）

**分析流程**:
```
遗传学验证
    → 拟南芥 WT vs cry1cry2 vs CRY1-OX UV-B/蓝光处理
    → 靶向类黄酮 LC-MS/MS (山奈酚/槲皮素糖苷, 花青素)
    → RNA-seq (全局转录响应)
    → 关键基因 qPCR 验证 (MBW MYB + 类黄酮结构基因)
ChIP-seq
    → HY5-GFP 系 UV-B 处理 6h → ChIP-seq
    → 目标: MBW MYB 启动子 (MYB75/PAP1, MYB90/PAP2, MYB113, MYB114)
    → ChIP-qPCR 独立验证
上位性分析
    → hy5 35S::MYB75 系 UV-B 处理
    → 花青素/黄酮醇定量 → MYB75 过表达能否恢复 hy5 缺陷
多物种保守性
    → 玉米 zmcry1 突变体 UV-B → ZmMYB 表达 + 类黄酮积累
    → 番茄 CRY-VIGS → 类黄酮变化
    → 大豆光质处理 → GmMYB + 类黄酮 (对接大豆节间项目)
启动子保守性分析
    → 5 物种 (拟南芥/番茄/大豆/水稻/玉米) MBW MYB 启动子 G-box/CRE 元件保守性
    → MEME/FIMO 跨物种基序鉴定
```

**关键比较**:
- WT vs cry1cry2 双突的 UV-B 诱导类黄酮积累幅度
- HY5 在 MBW MYB 启动子的直接结合（ChIP-seq 峰的有无和强度）
- MYB75 过表达对 hy5 突变体的回补程度（完全 vs 部分恢复）
- 5 个物种间 CRY-HY5-MBW 调控逻辑的保守性

**产出**:
- CRY→HY5→MBW-MYB 物理和功能链路的完整证据链
- HY5 ChIP-seq 在类黄酮调控 MYB 基因启动子的结合图谱
- 多物种 CRY-类黄酮代谢关联的验证数据集
- 大豆光质-类黄酮调控的候选分子模块

**里程碑**: 建立 CRY-HY5/BBX-MBW-类黄酮的跨物种保守光保护代谢模型

## Aim 5: 萜类吲哚生物碱基因簇内转运蛋白的鉴定与功能性跨细胞转运验证

**检验假设**: H5 — 长春碱等复杂 TIA 的完整生物合成依赖基因簇内共表达的转运蛋白（MATE/ABC/NRT-PTR）介导中间体跨细胞/跨细胞器转运

**背景与依据**:
长春花 (Catharanthus roseus) 萜类吲哚生物碱途径是植物特化代谢区室化的经典案例——strictosidine 的合成发生在表皮细胞内质网，而 vindoline 的后期修饰（D4H/DAT 催化的步骤）发生在异形细胞/乳汁管中。中间体 loganic acid/secologanin 和 tryptamine 需跨细胞转运，但负责这些转运的蛋白尚未被鉴定。青蒿素生物合成中已证实腺毛细胞特异性调控，TIA BGC 内包含 ORCA3/BIS1 等 AP2/ERF 调控因子，提示转运蛋白可能同样存在于 BGC 内并共享转录调控。Synthesis 知识空白 #4 将此列为核心空白。

**实验设计**:
- **物种**: 长春花 C. roseus（主系统，TIA 模式物种）
- **技术**: 空间转录组 (Stereo-seq 或 LCM-RNA-seq) + 共表达网络 + 烟草异源瞬转 + CRISPR 毛状根验证
- **策略**: 空间定位 → 共表达筛选 → 异源功能验证 → 遗传敲除验证

**分析流程**:
```
空间转录组定位
    → 长春花叶片 Stereo-seq 或 LCM-RNA-seq（表皮 vs 异形细胞/维管束）
    → TIA 途径基因表达空间热图 (STR, TDC, D4H, DAT, CPR, G10H, SLS)
    → 鉴定合成步骤的空间分隔模式
生物信息学候选转运蛋白筛选
    → 长春花基因组 TIA BGC 及 ±100 kb 区域注释 (InterProScan/TMHMM)
    → 筛选 MATE, ABC, NRT/PTR 家族预测转运蛋白
    → WGCNA 共表达网络 (已发表长春花 RNA-seq 数据) → 与 TIA 合成酶共表达的候选者
    → 启动子顺式元件分析 (JRE/GCC-box) → 验证是否含 ORCA3/BIS1 结合位点
烟草瞬转异源功能验证
    → 农杆菌共注射: TDC+STR+CPR (早期合成模块) ± 候选转运蛋白
    → 72h 后 LC-MS 检测: 叶片细胞内 + 浸润培养基中的 strictosidine
    → 转运阳性信号: 培养基中 strictosidine ≥ 细胞内 30%
CRISPR 毛状根验证
    → 长春花毛状根转化体系 → CRISPR-Cas9 靶向候选转运蛋白
    → LC-MS/MS 非靶向代谢组 → 中间体积累 vs 终产物减少
```

**关键比较**:
- 表皮细胞 vs 异形细胞中 TIA 早期步骤 vs 后期步骤基因的表达比
- BGC 内/邻近转运蛋白的共表达模块归属（是否与 TIA 合成酶同模块）
- 转运蛋白 ± 合成酶的烟草瞬转系统中 strictosidine 的胞外/胞内分布
- 转运蛋白 CRISPR 敲除前后 TIA 中间体和终产物的浓度变化

**产出**:
- 长春花叶片 TIA 途径的空间转录组图谱
- TIA BGC 内 3-5 个候选转运蛋白的共表达与调控元件分析
- 至少 1 个功能验证的 TIA 中间体转运蛋白
- 转运蛋白-CRISPR 毛状根系及其代谢组数据

**里程碑**: 鉴定首个负责 TIA 中间体跨细胞转运的转运蛋白，填补合成生物学重建完整 TIA 途径的关键缺失组件

## Expected Results & Risk Assessment

| Aim | 预期结果 | 风险等级 | 风险描述与缓解策略 |
|-----|---------|---------|-------------------|
| Aim 1 (H1) | 鉴定到 3+ 个 MYB 旁系同源基因在 3+ 种细胞类型中驱动不同的类黄酮分支通路，MYB DAP-seq 靶基因 Jaccard < 0.5 | 中 | scRNA-seq 对非模式物种（草莓/番茄）可能受原生质体制备效率限制 → 备选：snRNA-seq（核提取）或仅用拟南芥完成深度分析，其他物种做 bulk RNA-seq 验证 |
| Aim 2 (H2) | 鉴定到 2 个 NAC 转录因子在 MeJA 处理 1-3h 内上调且 ChIP-seq 证实直接靶向 ≥2 个代谢分支 MYB，nac 突变体 MeJA 代谢组显著减弱 | 低 | MeJA 体系成熟，RNA-seq 和 ChIP-seq 技术标准化。主要风险：候选 NAC 可能与其他 NAC 功能冗余 → 提前构建双突/三突变体，增加冗余覆盖 |
| Aim 3 (H3) | Class I 和 Class II 4CL 底物选择性差异 ≥3 倍，突变体表型分类明确，过表达实现碳流重定向 | 中 | 重组蛋白表达可能遇到包涵体问题 → 尝试不同表达载体（pCold/pMAL）、不同诱导温度；突变体可能功能冗余 → 双突/三突策略 |
| Aim 4 (H4) | HY5 ChIP-seq 在 ≥2 个 MBW MYB 启动子检测到结合峰，cry1cry2 双突类黄酮诱导降低 ≥60%，多物种验证 4/5 物种保守 | 中 | 已有成熟突变体资源（cry1cry2, hy5）可直接获取。ChIP-seq 抗体质量是主要风险 → 使用已验证的 HY5-GFP 系和商业 GFP 抗体。大豆光质实验依赖大豆项目进展 |
| Aim 5 (H5) | 鉴定到 ≥1 个功能转运蛋白，CRISPR 敲除后终产物减少 ≥50% | 高 | 长春花遗传转化效率低（约 5-10%）→ 前期以烟草异源表达和生物信息学为主，毛状根体系优化后可增加 CRISPR 验证；若空间转录组不可及，使用 LCM-RNA-seq 作为替代方案 |

### 备选方案

- **Aim 1 备选**: 若 scRNA-seq 在非模式物种中失败 → 使用荧光报告基因系（如拟南芥 MBW MYBp::GFP）+ FACS 分选 + 高灵敏度 bulk RNA-seq 的伪单细胞策略
- **Aim 2 备选**: 若 NAC ChIP-seq 信号弱 → 使用 DAP-seq（体外无抗体依赖）替代，或构建 NAC-GR 诱导系统增加瞬时结合信号
- **Aim 3 备选**: 若拟南芥 4CL 功能冗余过强 → 转向杨树（4CL 拷贝数更少，功能分化更明显），利用杨树转基因体系进行功能验证
- **Aim 4 备选**: 若玉米/番茄突变体资源不足 → 使用 CRISPR 分别构建或仅做拟南芥深度分析 + 其他物种启动子保守性分析
- **Aim 5 备选**: 若长春花 CRISPR 不可行 → 在烟草中构建人工 TIA 前体合成 + 转运系统，验证转运蛋白功能；空间转录组数据使用已发表的 LCM-RNA-seq 公共数据
