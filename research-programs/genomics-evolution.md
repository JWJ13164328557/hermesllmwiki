# 📋 Research Program: 多倍化进化如何塑造植物功能多样性

## Central Question

**全基因组倍增（WGD）与多倍化事件如何通过亚基因组不对称演化、基因家族动态重塑和选择压力变迁，驱动植物功能多样性的形成？**

本方案以拟南芥、水稻、棉花、猕猴桃、大豆为核心支点物种，整合生姜、地笋、香蕉、何首乌、蔷薇科等辅助类群，从 WGD 功能后果、基因家族扩张/收缩、群体基因组选择特征和驯化进化四个维度，系统解析多倍化在植物代谢创新、环境适应和人工选择中的进化角色。所有分析基于已发表基因组数据和知识综合推演，不涉及新实验数据产生。

---

## Program Structure

```
Aim 1: WGD 功能后果 — 亚基因组不对称演化与代谢创新
        ↓
Aim 2: 基因家族扩张/收缩 — 跨物种比较与功能分化路径
        ↓
Aim 3: 群体基因组选择特征 — 多物种自然群体的适应性印记
        ↓
Aim 4: 驯化进化 — 多倍化背景下的人工选择重塑
        ↓
Aim 5: 跨物种整合模型 — 多倍化驱动功能多样性的普遍规律
```

五个 Aim 构成从"多倍化事件识别与后果 → 基因家族功能分化 → 群体适应性选择 → 驯化重塑 → 跨物种普遍规律提炼"的完整进化生物学研究链。全部为计算分析与知识整合，无湿实验。

## Aim 1: WGD 功能后果 — 亚基因组不对称演化与代谢创新

**检验假设**: H1 — 多倍化后亚基因组的不对称演化（差异基因保留、表达偏向、TE 积累）是植物代谢多样化和环境适应的核心驱动力，且不对称程度与多倍化事件年龄和倍性水平相关。

### 分析设计

**支点物种与 WGD 背景**:

| 物种 | 倍性 | WGD 事件 | 关键特征 | 亚基因组结构 |
|------|------|----------|---------|-------------|
| *Arabidopsis thaliana* | 二倍体 (2n=10) | α (~35 Mya), β (~70 Mya), γ (~117 Mya) | 多轮古多倍化后极端二倍体化; 模式系统 | 古亚基因组残留 |
| *Oryza sativa* | 二倍体 (2n=24) | ρ (~70 Mya) | 禾本科特有 WGD; 单子叶参照 | 古亚基因组片段 |
| *Glycine max* | 二倍体化古四倍体 (2n=40) | 大豆特异 WGD (~13 Mya) | 近期古多倍化，二倍体化仍在进行 | 可分辨亚基因组区块 |
| *Gossypium hirsutum* | 异源四倍体 (AADD, 2n=52) | 异源多倍化 (~1–2 Mya) | 极近期多倍化；A/D 亚基因组分歧清晰 | At/Dt 双亚基因组 |
| *Actinidia chinensis* | 六倍体 (AABBBB, 2n=174) | 两轮多倍化 | 多亚基因组；同源表达差异丰富 | A1/A2/B1–B4 |

**辅助物种**: 生姜（近期 WGD）、地笋（三倍化）、蔷薇科（共享 WGD）、何首乌（WGD + TE 扩张）、香蕉（Musaceae 冠群 WGD）

### 分析流程

```
Step 1: 收集 5 个支点物种 + 5 个辅助物种的染色体水平基因组和注释
Step 2: 对每个物种进行基因组内共线性检索 (MCScanX / WGDI)
    → 鉴定 WGD 衍生共线性区块
    → 计算同源基因对 Ks 分布，拟合 WGD 峰
Step 3: 亚基因组分区
    → 棉花: A 亚基因组 vs D 亚基因组（祖先已知）
    → 大豆: 基于共线性和 Ks 划分古亚基因组区室
    → 猕猴桃: A vs B 亚基因组（基于祖先物种参照）
    → 拟南芥/水稻: 古亚基因组残片比对
Step 4: 亚基因组不对称指标量化
    → 基因保留率: 各亚基因组保留的 WGD 同源基因比例
    → 表达偏向: 基于公开 RNA-seq 数据计算亚基因组表达优势指数
    → TE 密度: 各亚基因组重复序列含量
    → 假基因化速率: 截断/移码突变频率
    → Ka/Ks 分布: 同源拷贝间选择压力差异
Step 5: 不对称性 × 代谢通路富集
    → 将优势亚基因组的保留基因与 KEGG/PlantCyc 代谢通路交叉
    → 鉴定与物种特异性状相关的代谢通路富集（棉花纤维、猕猴桃维生素 C、大豆异黄酮、生姜姜辣素）
Step 6: 跨物种比较 — 构建"不对称度 × WGD 年龄 × 倍性水平"的三维矩阵
```

### 关键分析

| 分析项 | 方法 | 关键参数 |
|--------|------|---------|
| WGD 共线性鉴定 | MCScanX / WGDI | E-value ≤ 1e-5; ≥ 5 共线性基因 |
| Ks 分布拟合 | WGDI (-ks) → Gaussian 混合模型 | 区分 WGD 峰 vs 背景小规模复制 |
| 亚基因组划分 | 棉花: 基于祖先 A2/D5; 大豆: 基于菜豆/绿豆共线性锚定; 猕猴桃: 基于 A. polygama/A. macrosperma | 参照基因组需为二倍体近缘种 |
| 表达偏向 | log₂(亚基因组A FPKM / 亚基因组B FPKM) | \|log₂FC\| > 1 定义偏向; 至少 5 种组织/条件 |
| 亚基因组不对称指数 | 综合保留率 + 表达偏向 + TE 密度 + Ka/Ks | PCA 降维 → 第一主成分 |
| 代谢通路富集 | KEGG/PlantCyc; Fisher exact test | FDR < 0.05 |

### 核心知识推演逻辑

基于 Synthesis 中的共识发现（共识 #1, #4, #5）: 蔷薇科 75.09% WGD 重复基因对经历纯化选择；地笋 C 亚基因组贡献 93.8% 受选择基因；猕猴桃同源基因在胁迫下差异表达。本 Aim 将这些单个发现系统化为跨物种量化比较，检验"不对称性是普遍规律"这一核心命题。

### 产出

- 10 个物种的 WGD 共线性图谱和 Ks 分布
- 5 个支点物种的亚基因组不对称性量化矩阵
- 亚基因组优势保留基因的代谢通路富集网络图
- 跨物种"不对称度 × WGD 年龄 × 倍性"关联模型

### 里程碑

**M1 (第 8 个月)**: 完成 10 物种 WGD 共线性鉴定和亚基因组不对称性量化

## Aim 2: 基因家族扩张/收缩 — 跨物种比较与功能分化路径

**检验假设**: H2 — WGD 事件驱动了与物种特异性状相关的基因家族的谱系特异性扩张，且扩张模式（全基因组复制 vs 串联复制 vs 散在重复）决定了功能分化的路径和幅度。

### 分析设计

**支点性状-基因家族映射**:

| 物种 | 关键性状 | 目标基因家族/通路 | 已知扩张模式 |
|------|---------|------------------|-------------|
| *Arabidopsis thaliana* | 硫苷代谢、开花调控 | MAM/CYP79 硫苷合成; FLC/CO 开花通路 | α WGD 保留 + 串联复制 |
| *Oryza sativa* | C₃/C₄ 分化、耐淹 | 光合碳固定酶; SUB1A/ERF 耐淹 | ρ WGD + 串联复制 |
| *Glycine max* | 异黄酮合成、结瘤共生 | IFS/CYP93C 异黄酮; NIN/NFR 结瘤信号 | 大豆特异 WGD（~13 Mya） |
| *Gossypium hirsutum* | 纤维发育、油脂合成 | MYB/bHLH 纤维调控; FAD/DGAT 油脂 | At/Dt 亚基因组差异化保留 |
| *Actinidia chinensis* | 维生素 C 合成、果实软化 | GGP/GalUR 维 C; PG/EXP 细胞壁 | 六倍化 + 亚基因组偏向 |
| *Zingiber officinale* | 姜辣素/二苯庚烷 | CCOMT/PKS 姜辣素; MYB 调控 | 谱系特异 WGD + 基因簇 |
| *Musa spp.* | 花青素合成、淀粉代谢 | ANS/F3H/CHS 花青素; GBSS/SS 淀粉 | Musaceae 冠群 WGD |

### 分析流程

```
Step 1: 全蛋白质组直系同源群鉴定
    → OrthoFinder (10 物种 + 外群: 无油樟 Amborella)
    → 输出正交群 (orthogroup) 矩阵
Step 2: 基因家族扩张/收缩分析
    → CAFE v5: 基于物种树和正交群大小估计各分支 λ (生/灭速率)
    → 显著扩张/收缩家族 (family-wise P < 0.05, Viterbi P < 0.05)
Step 3: 复制模式溯源
    → 对每个显著扩张基因家族，分类复制来源:
        - WGD 区块内共线性复制
        - 串联复制 (染色体上相邻, ≤10 基因间距)
        - 散在重复 (非共线性、非串联)
        - 转座子介导复制
Step 4: 功能分化信号检测
    → dN/dS (PAML codeml, M0 vs M7/M8/M2a)
    → 表达分化 (公开 RNA-seq, 多组织): 组织特异性指数 τ
    → 蛋白结构差异 (AlphaFold2 预测结构 RMSD 比较)
Step 5: 扩张时间与 WGD 时间对齐
    → 系统发育分支上的扩张节点 vs 已知 WGD 时间
    → Fisher 精确检验: WGD 后扩张家族是否富集性状相关功能
```

### 关键分析

| 分析项 | 方法 | 关键参数 |
|--------|------|---------|
| 直系同源群鉴定 | OrthoFinder (Diamond 比对) | 10 物种 + Amborella 外群 |
| 基因家族动态 | CAFE v5 | 物种树（基于 APG IV + 文献化石校准）；λ 参数泊松模型 |
| 复制模式分类 | 基因组坐标共定位 + 共线性支持 | WGD ≤ 5 基因间距在共线性区块内; 串联 ≤ 10 基因、同链 |
| 正选择检测 | aBSREL (分支) + BUSTED (基因家族) + MEME (位点) | LRT P < 0.05, FDR 校正 |
| 组织特异性 | τ 指数 (Yanai 2005) | 0 (广泛表达) ~ 1 (组织特异); τ > 0.85 为特异 |
| 功能富集 | GO/KEGG/MapMan | hypergeometric test, FDR < 0.05 |

### 核心知识推演逻辑

基于 Synthesis 共识 #3: 生姜姜辣素合成基因谱系特异性扩张、香蕉特有基因家族磺基转移酶/糖代谢富集、魔芋 LOX 家族分类。本 Aim 升级为系统性的 10 物种正交群动态分析——从"单个物种、单个家族的个案发现"走向"跨物种扩张-功能关联的统计规律"。

关键方法学创新: 将复制模式（WGD/串联/散在）与功能分化幅度（dN/dS、表达分化、结构差异）进行关联分析，检验"WGD 来源的重复基因是否比串联复制更容易发生亚功能化（而非新功能化）"——这是多倍化生物学中备受争议的问题。

### 产出

- 10 物种全蛋白质组正交群矩阵
- 各分支显著扩张/收缩基因家族列表（含功能注释）
- 复制模式 × 功能分化幅度关联统计
- 物种特异性状相关基因家族的进化路径图

### 里程碑

**M2 (第 16 个月)**: 完成跨 10 物种基因家族动态分析和复制模式-功能分化关联

## Aim 3: 群体基因组选择特征 — 多物种自然群体的适应性印记

**检验假设**: H3 — 多倍化产生的冗余基因拷贝在自然群体中经受差异化的选择压力：部分拷贝受纯化选择维持核心功能，部分拷贝在特定环境中受正选择驱动适应性分化，且选择信号的空间分布与亚基因组不对称性相关。

### 分析设计

**群体数据来源**（使用已发表公共数据，不产生新测序数据）:

| 物种 | 群体样本 | 数据类型 | 可获取来源 |
|------|---------|---------|-----------|
| *Arabidopsis thaliana* | 1001 Genomes (1,135 份全球材料) | 全基因组重测序 | 1001genomes.org |
| *Oryza sativa* | 3,000 Rice Genomes (3,024 份) | 全基因组重测序 | IRIC 3K-RG |
| *Glycine max* | 302 份栽培品种 + 30 份野生种 (G. soja) | 全基因组重测序 | SoyBase / NCBI SRA |
| *Gossypium hirsutum* | ~400 份栽培棉 + 野生棉 (G. barbadense/G. arboreum 等) | 全基因组重测序 | CottonGen / NCBI |
| *Actinidia chinensis* | 群体重测序数据（如有公开） | 全基因组重测序 | NCBI SRA |

### 分析流程

```
Step 1: 数据下载与统一处理
    → 下载各物种 VCF/重测序数据
    → 统一 GATK 流程 (若需从 raw data 开始)
    → 质量控制: MAF > 0.05, missing rate < 10%, HWE P > 1e-6
Step 2: 群体遗传结构
    → PCA (前 10 PC) + ADMIXTURE (K 扫描)
    → 系统发育树 (SNP 距离, Neighbor-Joining / FastTree)
    → 连锁不平衡 (LD) 衰减曲线
Step 3: 全基因组选择信号扫描
    → 群体间分化: F_ST (Weir & Cockerham), 滑动窗口
    → 核苷酸多样性: π, θ_W
    → 选择性清除: Tajima's D, iHS (integrated haplotype score), XP-CLR
    → 窗口大小: 物种特异的 LD 衰减距离 (r² = 0.2 时物理距离)
Step 4: WGD 基因的选择压力分析
    → 将选择信号与 WGD 保留基因座交叉
    → 区分: WGD 双拷贝 vs WGD 单拷贝保留 vs 非 WGD 单拷贝基因
    → 比较三类基因的选择信号强度和方向
Step 5: 基因型-环境关联 (GEA)
    → 对拟南芥和水稻（具有丰富地理/气候元数据）进行 GEA
    → 方法: LFMM / BayPass / RDA
    → 鉴定降水量、温度、纬度等与 WGD 基因变异关联的环境因子
Step 6: 选择信号在亚基因组间的分布
    → 比较 At vs Dt (棉花)、优势亚基因组 vs 弱势亚基因组（大豆/猕猴桃）的选择信号富集
    → 检验 H3: 亚基因组不对称与差异化选择压力的一致性
```

### 关键分析

| 分析项 | 方法 | 阈值/参数 |
|--------|------|----------|
| 群体结构 | PCA (PLINK) + ADMIXTURE + FastTree | PC1-10 作为 GWAS/GEA 协变量 |
| 全基因组 F_ST | VCFtools (滑动窗口) | top 1% 为高分化位点 |
| 选择性清除 | selscan (iHS, nSL); XP-CLR | top 1% 作为候选清除信号; XP-CLR 分数 > 95th percentile |
| 核苷酸多样性 | π (VCFtools / pixy) | 窗口大小 = LD₀.₂ 距离 × 2 |
| 基因型-环境关联 | LFMM2 (R 包), BayPass | |z-score| > 4; FDR < 0.05 |
| 跨物种比较 | Fisher 方法合并 P 值; 同源位点比较 | Benjamini-Hochberg FDR |

### 核心知识推演逻辑

基于 Synthesis 共识 #6: GWAS 主效位点不能显著改善基因组预测，提示复杂性状以微效多基因为主。本 Aim 将这一观点延伸至自然群体：在多倍化背景下，冗余基因拷贝的存在降低了单个基因座的选择约束，使得选择信号分散在多个同源拷贝之间——我们预测 WGD 基因座的平均选择信号强度低于单拷贝基因座，但显著位点密度更高。此外，基于 Synthesis 空白 #1（大豆群体基因组研究不足），本 Aim 通过多物种并行分析填补这一空白。

### 产出

- 5 个物种的群体遗传结构图谱
- 全基因组选择信号扫描热图（Manhattan 式全景图）
- WGD 基因 vs 单拷贝基因的选择信号统计比较
- 环境因子-WGD 基因变异关联网络
- 亚基因组偏向性选择信号分布

### 里程碑

**M3 (第 26 个月)**: 完成 5 个物种的群体选择信号扫描和跨物种比较分析

## Aim 4: 驯化进化 — 多倍化背景下的人工选择重塑

**检验假设**: H4 — 作物驯化优先靶向多倍化后保留的冗余基因拷贝，且驯化选择加速了亚基因组功能偏向性——优势亚基因组的驯化相关基因经历了更强烈的选择性清除和功能特化。

### 分析设计

**作物驯化系统**:

| 作物 | 祖先种 | 多倍化与驯化时间关系 | 关键驯化性状 |
|------|--------|-------------------|-------------|
| *Glycine max* | *G. soja* (野生大豆) | WGD (~13 Mya) 远早于驯化 (~5,000 yr) | 裂荚性、蔓生→直立、种子大小、光周期敏感性 |
| *Oryza sativa* | *O. rufipogon* (普通野生稻) | ρ WGD (~70 Mya) 远早于驯化 (~8,000–9,000 yr) | 落粒性 (sh4/qSH1)、株型 (PROG1)、芒 |
| *Gossypium hirsutum* | A 基因组祖先 (G. arboreum 近缘) + D 基因组祖先 (G. raimondii 近缘) | 异源多倍化 (~1–2 Mya) 先于驯化 (~5,000–8,000 yr) | 纤维长度/品质、光周期、株型 |
| *Actinidia chinensis* | 野生猕猴桃 | 六倍体化发生于驯化之前（时间不明） | 果实大小、维生素 C 含量、风味 |
| *Brassica napus* (参考) | B. rapa × B. oleracea | 异源四倍化 (~7,500 yr) 与驯化几乎同步 | 含油量、硫苷、开花时间 |

### 分析流程

```
Step 1: 驯化相关性状基因集
    → 从文献和 QTL 数据库收集中各作物的已克隆驯化基因 (domestication genes)
    → 如: 大豆 (Dt1/GmCRY, GmFT), 水稻 (sh4, PROG1, qSH1, Ghd7), 棉花 (MYB25-like, HOX3)
    → 从 GWAS 目录和 QTL 综合数据补充候选驯化位点
Step 2: 驯化基因的 WGD 溯源
    → 对每个驯化基因/候选位点进行 WGD 状态分类:
        - WGD 保留同源拷贝（双拷贝或多拷贝均保留）
        - WGD 后丢失一个拷贝（单拷贝保留）
        - 非 WGD 来源（串联复制/单拷贝起源）
    → 统计驯化基因中 WGD 来源的比例，与全基因组背景比较 (χ² test)
Step 3: 驯化选择性清除信号
    → 栽培群体 vs 野生群体:
        - F_ST (栽培 vs 野生，全基因组扫描)
        - π_ratio = π_wild / π_cultivated (降低表示清除)
        - Tajima's D 负值区域
    → 重点关注驯化基因 ± 50 kb 窗口多态性
Step 4: 驯化 vs 自然选择的比较
    → 比较驯化基因 (人工选择) vs 环境适应基因 (Aim 3 识别的自然选择信号) 的选择信号强度和模式
    → 检验: 驯化选择是否比自然选择更集中于特定基因组区域（选择性清除更尖锐）
Step 5: 驯化方向与亚基因组偏向性
    → 比较: 驯化基因在优势亚基因组 vs 弱势亚基因组中的富集程度
    → 棉花: At (纤维品质) vs Dt (纤维产量) 亚基因组的驯化贡献比例
    → 大豆: WGD 同源对中，保留拷贝的驯化信号是否更强
Step 6: 多倍化-驯化时间窗口分析
    → 计算多倍化事件与驯化之间的时间间隔
    → 检验: 多倍化与驯化时间间隔越短，驯化基因中 WGD 来源比例越高（如油菜）
```

### 关键分析

| 分析项 | 方法 | 关键参数 |
|--------|------|---------|
| 驯化基因集构建 | 文献挖掘 + QTL 数据库整合 | 高置信已克隆基因为"金标准"集; QTL 区间为扩展集 |
| WGD 溯源 | 共线性搜索 + Ks  | 与 Aim 1 结果交叉 |
| 栽培-野生分化 | F_ST, π_ratio, D_XY | 滑动窗口, top 5% 阈值 |
| 驯化 vs 自然选择比较 | 选择信号强度 (XP-CLR score) 和信号宽度 (LD 范围内连续极端值长度) | Mann-Whitney U test |
| 亚基因组驯化偏向 | 驯化基因亚基因组定位富集 | hypergeometric test vs 全基因组亚基因组基因分布 |

### 核心知识推演逻辑

马铃薯 StCOMT 基因家族（Synthesis）的 18 个成员通过基因复制扩张，为理解"WGD 提供冗余拷贝 → 驯化选择其中特定拷贝"提供了范式。本 Aim 将这一逻辑推广至主要作物，提出核心命题: "多倍化是驯化的进化前适应（pre-adaptation）——多倍化预先产生的冗余基因拷贝为人工选择提供了可靶向的遗传变异池"。

这一命题的验证可解释一个长期困惑: 为何多倍体作物（棉花、小麦、油菜、甘蔗、甘薯）在主要作物中占比异常高（约 75% 的被子植物作物是多倍体）——不是巧合，而是进化必然。

- 亚基因组驯化偏向性统计
- "多倍化-驯化"时间窗口效应分析

## Aim 5: 跨物种整合模型 — 多倍化驱动功能多样性的普遍规律

**检验假设**: H5 — 多倍化后亚基因组不对称演化程度、基因家族功能分化幅度、群体选择信号分布和驯化靶向偏向性之间存在跨物种的定量关联，可以提炼为"多倍化驱动功能多样性"的统一进化模型。

### 分析设计

将 Aim 1–4 的定量输出整合为跨物种可比较的指标体系:

**指标体系**:

| 一级指标 | 二级指标 | 来源 Aim | 量化方法 |
|---------|---------|---------|---------|
| 多倍化特征 | WGD 年龄 (Ks 峰值)、倍性水平、异源/同源 | Aim 1 | Mya 估计; 倍性数; 二分类 |
| 亚基因组不对称度 | 保留率比、表达偏向比、TE 密度比 | Aim 1 | PCA 第一主成分得分 |
| 基因家族创新度 | 谱系特异扩张家族数 / 总家族数; 性状关联度 | Aim 2 | 比例 × 功能富集程度 |
| 群体选择广度 | WGD 基因选择信号中位数; 环境关联 SNP 比例 | Aim 3 | 标准化效应量 |
| 驯化 WGD 偏向度 | 驯化基因中 WGD 来源比例 / 全基因组 WGD 比例 | Aim 4 | 富集比 (enrichment ratio) |
| 性状多样性 | 物种特异性状数量; 代谢物多样性指数 | 文献 | 基于代谢组学文献的化合物数量 |

### 分析流程

```
Step 1: 构建物种 × 指标矩阵
    → 5 个支点物种 + 5 个辅助物种
    → 10 个指标维度
Step 2: 指标标准化与降维
    → Z-score 标准化; PCA 降维
    → 物种在 PC 空间中的分布
Step 3: 相关性分析
    → 指标间 Spearman / Pearson 相关矩阵
    → 控制变量: 分化时间（系统发育独立对比, PIC）
Step 4: 系统发育广义最小二乘法 (PGLS)
    → 检验各指标间的系统发育校正后的关联
    → 例如: WGD 年龄 ~ 亚基因组不对称度; 不对称度 ~ 驯化 WGD 偏向度
Step 5: 结构方程模型 (SEM)
    → 构建因果路径:
        多倍化特征 → 亚基因组不对称 → 基因家族创新 → 性状多样性
        多倍化特征 → 亚基因组不对称 → 驯化 WGD 偏向度
    → 模型拟合评估 (CFI, RMSEA, SRMR)
Step 6: 模型外推与预测
    → 将未纳入建模的物种（如香蕉、生姜）作为检验集
    → 基于 SEM 模型预测其驯化/功能创新潜力
```

### 关键分析

| 分析项 | 方法 | 关键参数 |
|--------|------|---------|
| 指标相关矩阵 | Spearman ρ + 偏相关 (控制 WGD 年龄) | FDR 校正 |
| 系统发育校正 | PGLS (phylolm / caper, R) | 系统发育树来自 Aim 1/2 的物种树 |
| 结构方程模型 | lavaan (R) | ML 估计; CFI > 0.90; RMSEA < 0.08 |
| 外推验证 | 留一法 (leave-one-species-out) 交叉验证 | MAE / RMSE 评估 |

### 预期模型框架

```
多倍化事件 (WGD/Multiplication)
    │
    ├─→ 亚基因组不对称 (Asymmetry Index)
    │       │
    │       ├─→ 代谢通路创新 (Metabolic Innovation)
    │       │       │
    │       │       └─→ 物种特异性状 (Species-specific Traits)
    │       │
    │       └─→ 驯化前适应 (Domestication Pre-adaptation)
    │               │
    │               └─→ 作物驯化成功度 (Domestication Success)
    │
    └─→ 基因家族动态 (Family Turnover)
            │
            └─→ 环境适应广度 (Ecological Breadth)
```

- 指标间系统发育校正关联分析
- 多倍化驱动功能多样性结构方程模型
- 物种功能创新潜力预测排名
- 综合性综述框架（可独立发表为 Review/Trends 文章）

## Expected Results & Risk Assessment

### 预期结果

| 假设 | 核心预期 | 风险等级 | 风险说明 |
|------|---------|---------|---------|
| H1: 亚基因组不对称是普遍规律 | 5 个支点物种均显示显著亚基因组不对称（不对称指数显著偏离 1:1 零假设），不对称度与 WGD 年龄负相关（年龄越大越对称） | 低 | 蔷薇科、地笋、猕猴桃、棉花等已有强先例支持 |
| H2: WGD 来源基因的功能分化路径不同于其他复制模式 | WGD 来源的重复基因对功能冗余保留比例显著高于串联复制，且更倾向于亚功能化而非新功能化 | 中 | 现有数据主要来自拟南芥和蔷薇科；其他物种的证据强度不一 |
| H3: WGD 基因座的平均选择信号弱于单拷贝基因座 | WGD 基因座的 π_ratio 和 F_ST 中位数显著低于单拷贝基因座，但 iHS 极端值密度更高（分散的选择信号） | 中 | 需要足够的群体样本量；部分物种（如猕猴桃）群体数据可能有限 |
| H4: 驯化优先靶向 WGD 保留拷贝 | ≥3 个作物中驯化基因的 WGD 来源比例显著高于基因组背景，且多倍化-驯化间隔越短，偏向越强 | 中 | 驯化基因样本量有限（每种作物仅 ~10–20 个已知克隆基因）；QTL 扩展集信度较低 |
| H5: 跨物种普遍关联可建模 | 结构方程模型至少通过一个显著因果路径（如不对称度 → 代谢创新），且留一法交叉验证预测误差 RMSE < 1 SD | 高 | 10 个物种作为统计单元样本量很小（N=10），统计力有限；系统发育非独立性需谨慎处理 |

### 备选方案

| 风险 | 备选方案 |
|------|---------|
| 某些物种基因组组装质量不满足共线性分析要求 | 使用近缘高质量基因组替代；降低 MCScanX 共线性基因阈值; 仅分析 5 个支点物种，辅助物种定性参考 |
| 群体重测序数据获取受限 | 使用公开变异数据库（如拟南芥 1001 Genomes 已有 VCF; 水稻 3K-RG 已有 SNP 集）避免从 raw data 重处理 |
| 猕猴桃/棉花群体数据量不足 | 降低对应物种的分析深度（仅 F_ST 和 π，不做 iHS/XP-CLR）; 仍可参与跨物种比较 |
| 跨物种直系同源群质量差（远缘物种间） | OrthoFinder 的分层策略; 聚焦 5 支点物种（均为核心真双子叶/单子叶，亲缘适中） |
| PGLS 因 N=10 样本量统计力不足 | 增加功能性状指标（果重、代谢物数量等）作为替代检验; 使用贝叶斯方法适当先验 |
| 结构方程模型过拟合 | 限制路径数量（≤6 条）; 使用 AIC/BIC 模型选择; 报告 Bootstrap 置信区间 |
