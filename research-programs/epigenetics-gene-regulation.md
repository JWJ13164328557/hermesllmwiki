# 📋 Research Program: 表观与基因调控——染色质预配置·TF层级·发育三维调控

## Central Question

**表观遗传修饰（染色质可及性、组蛋白标记）、转录因子网络与发育程序如何构成三维调控体系，决定植物细胞命运转变、器官发生与环境可塑性？**

具体而言：（1）染色质预配置如何在发育转变发生前预设基因表达潜能？（2）WRKY-OBE 等表观阅读器复合物如何在分子层面耦合转录因子结合与组蛋白修饰读取？（3）时序 TF 级联（E2F→MYB/NAC/bHLH）如何被表观状态编码和约束？（4）上述机制在从苔藓到被子植物的进化谱系中如何保守与分化？

## Aim 1: 染色质预配置——发育转变前的表观景观预设

**检验假设**: H1 — 发育转变（细胞分化、器官发生、阶段转换）发生之前，关键基因座的染色质可及性和组蛋白修饰状态已被预设，构成"表观预配置"（epigenetic pre-configuration）；预配置状态决定了后续转录响应的方向、幅度和时序。

### 背景与依据

染色质可及性差异与细胞类型特异性基因表达显著相关（[[differential-accessibility-regulates-cell-type-expression]]），拟南芥根各主要细胞类型展现截然不同的可及性图谱（[[root-cell-type-specific-chromatin-accessibility]]）。然而，一个根本性问题尚未解决：**可及性变化是基因表达变化的原因还是结果？** 回答该问题需要时间序列扰动实验，在发育转变前捕获染色质状态的"预设"信号。

H3K27me3 标记的沉默子样顺式调控元件（CRE）在删除后导致靶基因上调（[[ev-40962852-04]]），提示抑制性表观标记是基因沉默的"预置锁"。H3K4me2/3 作为激活标记被 OBE1 PHD 指蛋白特异性读取（[[ref-embj-2023113639]]），构成激活潜能预设的分子基础。GCN5-ADA2 复合物通过 TF 互作将发育信号转化为组蛋白乙酰化变化（[[ref-j-bbaexp-2007-04-007]]），表明表观预配置可通过特定 TF 被主动建立。

组蛋白乙酰化具有位点特异性，约 7% 拟南芥转录组受乙酰化动态调控（[[ref-genetics-104-033142]]），暗示预配置的范围可能限定在关键调控基因而非全局。

### 实验策略

| 维度 | 方案 |
|------|------|
| **核心范式** | 发育转变前的时间序列染色质分析——在表型/转录变化之前捕获染色质预配置信号 |
| **模型系统** | 拟南芥根发育（时空清晰的细胞命运转变）、水稻穗发育（阶段转换）、大豆节间维管分化 |
| **技术** | snATAC-seq + CUT&Tag（H3K4me3/H3K27ac/H3K27me3）+ 配对 RNA-seq |
| **时间分辨率** | 发育转变前 5-7 个密集时间点（如根近端分生组织→伸长区→分化区过渡带显微切割取样） |
| **扰动验证** | 诱导型 TF 过表达/敲除 + 时间序列染色质分析，检验"表观先行于转录"假说 |

### 分析流程

```
高时间分辨率 snATAC-seq + CUT&Tag
    → 鉴定"预配置区域"：染色质状态变化先于基因表达变化的基因组区域
    → 预配置区域的染色质特征分类：
        - 激活预置（H3K4me3⁺/H3K27ac⁺ 先于转录上调）
        - 沉默预置（H3K27me3⁺ 先于转录下调）
        - 双价预备（H3K4me3⁺/H3K27me3⁺ 共标记—谱系预备基因）
    → 预配置区域与已知 CRE/silencer 重叠分析
    → TF 足迹分析 → 鉴定预配置建立者 TF（pioneer-like factors）
    → 扰动后预配置状态破坏 vs. 恢复的时序动力学
```

### 关键问题

- 染色质预配置的时间窗有多长？是分钟级、小时级还是跨越多个细胞周期？
- 哪些基因座被预配置？是否集中在发育调控基因（转录因子、信号通路节点）？
- 预配置的建立是否需要 DNA 复制（即是否依赖细胞周期）？
- 预配置状态在细胞分裂中的遗传保真度如何？
- 不同发育转变事件（营养→生殖、增殖→分化）是否共享预配置逻辑？

### 产出

- 发育转变前染色质预配置全基因组图谱（≥3 个发育事件）
- 预配置区域的时序分类与功能注释
- 候选"先驱"转录因子列表（通过 TF 足迹和基序富集鉴定）
- 扰动-恢复实验验证预配置因果性
- **Figure 1**: 染色质预配置时序热图 + 预配置→转录的时序偏移模型

### 里程碑

确立"表观预配置"作为发育调控的基本范式——染色质状态在转录变化之前预设基因表达潜能

## Aim 2: WRKY-OBE 表观阅读器复合物的分子机制与调控逻辑

**检验假设**: H2 — WRKY IId-OBERON PHD 指蛋白复合物是连接转录因子 DNA 结合与组蛋白修饰读取的核心"表观阅读器"模块；其通过 CC 结构域靶向特定基因组位点、通过 PHD 指识别 H3K4me2/3、通过 WRKY 结构域实现 DNA 结合，三者的耦合构成了位点特异性转录抑制的分子基础。

### 背景与依据

OBE1 和 OBE2 协同增强彼此对 H3K4me2/3 肽段的结合亲和力，且 WRKY 和 OBE 在全基因组水平共占据靶基因启动子，在非胁迫条件下共同介导大量胁迫响应基因的转录抑制（[[ref-embj-2023113639]]）。这表明 WRKY-OBE 复合物具有"预抑制"功能——在胁迫到来之前将胁迫响应基因的表观状态维持为抑制态。

WRKY11 的 CC 结构域（coiled-coil domain）对于选择特定基因组位点至关重要（[[ref-embj-2023113639]]），提示 CC 结构域是靶标选择的决定因素。IId 亚家族 WRKY 成员可彼此形成同源/异源蛋白网络，增加复合物组成的多样性和调控灵活性。

HDA9-PWR-WRKY53 衰老复合物表明组蛋白去乙酰化酶也可通过类似逻辑（SANT 结构域 + TF）靶向特定基因座（[[ref-eLife-17214]]），暗示"TF-表观阅读器/修饰酶"耦合是植物中普遍存在的调控模式。

### 实验策略

| 维度 | 方案 |
|------|------|
| **结构生物学** | Cryo-EM / X-ray 晶体学解析 WRKY-OBE-DNA-组蛋白肽四元复合物结构（拟南芥 + 大豆 + 水稻） |
| **体外生化** | 重组蛋白 ITC/SPR 测定 WRKY-OBE 对 H3K4me0/1/2/3 的定量结合亲和力；CC 结构域截短/点突变对 DNA 结合的影响 |
| **体内功能** | ChIP-seq（WRKY + OBE 共占位）+ RNA-seq（wrky/obe 突变体）+ ATAC-seq（突变体中染色质可及性变化） |
| **跨物种保守性** | 拟南芥、水稻、大豆、玉米、小立碗藓 OBE 同源蛋白的 H3K4me 结合能力比较（小立碗藓 OBE1 不结合 H3 肽段——进化中的功能获得事件） |
| **扰动验证** | CRISPR 敲除 WRKY IId 或 OBE → 检测靶基因去抑制程度 + H3K4me3 和 H3K27ac 在该基因座的变化 |

### 分析流程

```
结构解析 → WRKY-OBE-DNA-H3K4 四元复合物原子模型
体外生化 → 结合亲和力热力学图谱（KD, ΔH, ΔS）+ 结构域功能图谱
ChIP-seq → WRKY + OBE 全基因组共占位峰鉴定
    → 共占位峰的基因组特征：启动子/增强子/基因体分布
    → 共占位峰的表观特征：H3K4me1/2/3, H3K27ac, H3K27me3, 染色质可及性
    → 共占位靶基因的功能分类（胁迫响应/发育/代谢）
RNA-seq 突变体 → 共占位靶基因的表达变化（预期：去抑制/上调）
跨物种比较 → OBE PHD 指序列与 H3 肽结合能力的系统发生学关联
    → 小立碗藓→被子植物 OBE 功能获得的结构基础
```

### 关键问题

- WRKY-OBE 复合物的化学计量比是多少？一个 OBE 二聚体结合几个 WRKY？
- CC 结构域如何决定基因组靶标选择性——是通过 DNA 序列识别还是染色质环境感知？
- WRKY-OBE 介导的转录抑制是否可逆？胁迫信号如何解除抑制？
- 不同 WRKY IId 成员与不同 OBE 旁系同源物的组合是否产生功能特化？
- 小立碗藓 OBE 的功能获得是如何在陆生植物进化中发生的——关键氨基酸替换？

### 产出

- WRKY-OBE-DNA-H3K4 四元复合物结构模型（Cryo-EM，近原子分辨率）
- WRKY-OBE 全基因组共占位图谱与靶基因网络
- 突变体去抑制表型验证
- OBE PHD 指-组蛋白结合的跨物种系统发生学分析
- **Figure 2**: WRKY-OBE 复合物结构示意 + 共占位基因组浏览器 + 去抑制热图

### 里程碑

在原子结构、生化机制和全基因组水平完整解析 WRKY-OBE 表观阅读器复合物的工作模型，并阐明其在陆生植物进化中的功能获得事件

## Aim 3: 转录因子层级网络与发育时序编码

**检验假设**: H3 — 植物发育进程由时序 TF 级联编码，具体为：E2F 家族驱动细胞增殖阶段，随后 MYB/NAC/bHLH 家族驱动分化阶段；这些 TF 的时序激活受其基因座的表观状态约束，形成"表观→TF 级联→分化"的三维编码逻辑。

### 背景与依据

假时间分析显示，早期基因富集细胞周期相关 TF 基序（E2F 样），晚期基因富集分化 TF 基序（MYB、NAC、bHLH），暗示增殖→分化的时序 TF 级联模型（[[pseudotime-tf-motif-enrichment]]）。

MYB 家族是次生代谢的核心调控因子，与 bHLH 和 WD40 形成 MBW 复合物。bHLH 参与假时间发育级联中的后期分化事件（[[pseudotime-tf-motif-enrichment]]），NAC 家族则在木质部分化中扮演终末分化开关角色（VND/NST/SND 亚家族）。

E2F→MYB/NAC/bHLH 的层级转换可能由以下机制介导：（1）E2F 直接激活早期分化 TF 的转录；（2）细胞周期退出解除对分化 TF 基因座的染色质抑制；（3）组蛋白修饰在层级转换节点处的全局重塑。

### 实验策略

| 维度 | 方案 |
|------|------|
| **模型系统** | 拟南芥根（细胞类型连续体）+ 水稻穗发育（阶段转换清晰）+ 大豆节间维管分化 |
| **单细胞多组学** | scRNA-seq + scATAC-seq（同一细胞的多组学配对或并行分析）联合假时间推断 |
| **扰动实验** | E2F 诱导型 CRISPR 敲除/激活 + scRNA-seq 检测下游 TF 级联变化 |
| **表观约束检验** | 比较 E2F 靶基因 vs 非靶基因的染色质状态——分化 TF 基因座是否在增殖阶段被 H3K27me3 抑制？ |
| **跨层级 TF 关系** | DAP-seq（E2F + MYB + NAC + bHLH）鉴定各层级 TF 的全基因组结合位点，检验是否存在上位 TF 直接结合下位 TF 启动子 |

### 分析流程

```
scRNA-seq 假时间推断 → 假时间轴上的基因表达动态
    → TF 基序富集在假时间窗口的分布
    → GRN 推断 (SCENIC/GENIE3) → E2F→MYB/NAC/bHLH 层级网络
scATAC-seq 假时间分析 → 假时间轴上的染色质可及性动态
    → 分化 TF 基因座的"开放时间窗口"鉴定
    → 与 RNA 表达的时间偏移分析（可及性是否先于表达？→ 回连 Aim 1 预配置）
DAP-seq 跨 TF 结合位点交叉：
    - E2F 是否结合 MYB/NAC/bHLH 启动子？
    - MYB/NAC/bHLH 是否结合下游效应基因启动子？
    - 各层 TF 的结合是否依赖靶基因座的可及性状态？
扰动转录组 → E2F 缺失/激活后，下游层级 TF 的表达变化与假时间轨迹偏移
```

### 关键问题

- E2F→MYB/NAC/bHLH 级联是线性的还是存在旁路和反馈？
- 层级转换的"开关"是什么——E2F 蛋白水平的下降？还是分化 TF 基因座染色质的开放？
- 不同发育背景下（根 vs 叶 vs 花）层级网络的拓扑结构是否保守？
- 分化终端 TF（如 NAC 家族 VND7）是否反馈调控上游层级？
- 层级转换的时间精度如何保证——是否有时序检查点？

### 产出

- 多物种（拟南芥、水稻、大豆）发育假时间 TF 层级网络模型
- E2F→MYB/NAC/bHLH 级联的扰动验证
- 表观状态约束 TF 层级转换的直接证据（scATAC + scRNA 时序偏移）
- 跨物种层级网络保守性/分歧性比较
- **Figure 3**: TF 层级网络的假时间动态模型 + 表观约束示意图 + 扰动后的网络重连

### 里程碑

建立"表观状态编码 TF 层级→TF 层级驱动发育时序"的三维调控模型，并通过多物种比较检验其普适性

## Aim 4: 表观调控机制的物种多样化与进化保守性

**检验假设**: H4 — 核心表观调控机制（组蛋白修饰系统、染色质重塑因子、关键表观阅读器）在陆生植物中高度保守，但靶基因座选择、复合物组成和调控逻辑在物种间发生了显著多样化；这种"保守机制、多样化靶向"的模式是植物适应不同生态位的分子基础。

### 背景与依据

关键发现支持该假说：（1）小立碗藓 OBE1 不结合任何 H3 肽段，而高等植物 OBE 特异识别 H3K4me2/3——表观阅读器功能在陆生植物进化中获得（[[ref-embj-2023113639]]）；（2）H3K27me3 沉默子元件跨物种保守存在，表明抑制性表观逻辑在进化中稳定（[[ev-40962852-04]]）；（3）GCN5-ADA2-CBF1 冷响应模块在拟南芥中鉴定，但大豆/水稻中是否存在同源模块未知。

### 实验策略

| 维度 | 方案 |
|------|------|
| **物种选择** | 进化梯度：小立碗藓（*Physcomitrium patens*）→ 拟南芥（十字花科）→ 水稻（单子叶）→ 大豆（豆科）→ 玉米（C4 单子叶） |
| **组蛋白修饰图谱** | 各物种对应发育阶段（根/叶）的 CUT&Tag：H3K4me3, H3K27ac, H3K27me3, H3K9ac |
| **染色质可及性** | 各物种 snATAC-seq（统一分析流程，消除技术偏差） |
| **同源基因座比较** | 发育调控关键基因的同源基因座（如 WUS-CLV、SCR-SHR、VND-NST、LFY-AP1）的表观状态跨物种比较 |
| **OBE 功能进化** | 各物种 OBE 重组蛋白的 H3 肽结合实验 + 结构比较 + 祖先序列重建 |

### 分析流程

```
统一流程处理多物种 CUT&Tag / snATAC-seq
    → 鉴定各物种的"表观调控单元"（可及性 + 修饰的组合模式）
    → 同源基因座表观状态相似性矩阵（跨物种层次聚类）
    → 保守表观模块：所有物种共享的染色质状态组合
    → 物种特异表观模块：某物种独有的调控逻辑
    → 表观模块与基因组进化事件关联（全基因组复制 WGD、转座子扩张、调控序列更替）
OBE 祖先序列重建 → 推断关键氨基酸替换的时间点与选择压力
    → 结构预测（AlphaFold）+ 体外验证重建祖先蛋白的 H3 结合能力
```

### 关键问题

- 核心发育调控模块（如干细胞维持、器官起始）的表观调控逻辑是否"冻结"在进化中？
- 物种特异的表观创新（如 OBE 功能获得）是否与关键形态创新（如维管系统、花器官）相关？
- 多倍体化后（如大豆 WGD）表观调控网络的"双倍化-分化"逻辑是什么？
- 转座子扩张如何驱动物种特异的染色质景观形成？

### 产出

- 五物种统一流程的表观基因组图谱（可及性 + 4 种组蛋白修饰）
- 同源基因座跨物种表观保守性/分歧性定量矩阵
- OBE PHD 指功能获得事件的祖先序列重建与生化验证
- 物种特异表观模块与形态/生理创新的关联分析
- **Figure 4**: 跨物种表观调控相似性热图 + 进化树枝干标注表观创新事件 + OBE 祖先重建

### 里程碑

绘制陆生植物关键进化节点的表观调控多样化图谱，阐明"保守机制、多样化靶向"的进化逻辑

## Aim 5: 多信号整合——环境输入→表观重塑→发育输出

**检验假设**: H5 — 植物通过有限的表观调控核心模块（组蛋白修饰酶、染色质重塑因子、表观阅读器）整合多种环境信号（光、温度、胁迫），将不同环境输入转化为共享或特异的染色质状态变化，最终汇聚到发育程序的调控上；环境特异性的产生依赖于"TF 差异招募表观修饰酶"机制。

### 背景与依据

光信号：CRY1 介导蓝光响应，WIND1 通过协调组蛋白乙酰化整合环境信号调控细胞命运转变（[[ref-j-molp-2026-03-005]]）。温度信号：CBF1 通过招募 GCN5-ADA2 HAT 复合物激活冷响应基因（[[ref-j-bbaexp-2007-04-007]]）。发育信号：REV-ERBa-HDAC3 模式表明表观修饰与节律信号形成时序回路（[[pdf-j-cell-2014-03-039]]），HDA9-PWR-WRKY53 驱动叶片衰老（[[ref-eLife-17214]]）。

共同主题：不同信号通过不同的 TF 招募相同或相似的组蛋白修饰酶复合物（GCN5、HDA9、HDAC3）来实现信号特异性的表观重编程。即"通用表观酶 + 特异 TF = 信号特异输出"。

### 实验策略

| 维度 | 方案 |
|------|------|
| **模型系统** | 拟南芥（遗传工具最成熟），辅以水稻（农业重要性） |
| **多信号比较** | 光质（蓝光/远红光）、温度（冷/热胁迫）、激素（IAA/GA/ABA）、发育阶段转换（幼年→成年→生殖）——四个维度的表观响应比较 |
| **技术** | 统一流程 CUT&Tag（H3K27ac/H3K27me3/H3K4me3）+ RNA-seq + 配对 ATAC-seq |
| **TF-表观酶互作** | 酵母双杂 + Co-IP 系统筛选与 GCN5、HDA9、HDAC3 等核心表观酶互作的 TF（覆盖光、温、激素各通路代表性 TF） |
| **信号交叉** | 双信号同时处理（如冷+蓝光、干旱+ABA）→ 检验表观响应是叠加还是交互 |

### 分析流程

```
多信号 CUT&Tag 数据整合：
    → 各信号诱导的组蛋白修饰变化基因组目录
    → 信号共享 vs 信号特异的表观响应区域
    → 共享响应区域的功能特征（持家基因？胁迫通用模块？）
    → 特异响应区域的上游 TF 基序推断
RNA-seq：各信号 DEG 与表观变化区域的关联
    → 表观-转录耦合强度比较（哪些信号更依赖表观调控？）
TF-表观酶互作筛选：
    → 各通路 TF 的"表观酶配对图谱"
    → 是否存在一个 TF 同时招募 GCN5（激活）和 HDAC（抑制）的情况？
信号交叉实验：
    → 双信号的表观响应可加性 vs 非可加性
    → 拮抗信号的染色质"竞争"模式（如冷→开放 vs 热→关闭同一基因座）
```

### 关键问题

- 不同环境信号是否使用相同的表观酶库，仅通过 TF 差异实现特异性？还是不同信号拥有专属表观酶？
- 表观重塑的动力学在不同信号间是否一致（冷响应 6h vs 光响应 30min）？
- 输入信号的强度（刺激梯度）如何在染色质层面被编码——是数字式的开关还是模拟式的梯度？
- 表观"记忆"效应——信号撤除后，染色质状态是否恢复至初始？恢复速率是否因信号而异？

### 产出

- 多信号表观响应全基因组图谱（≥4 种环境/发育信号 × 3 种组蛋白标记）
- 核心表观酶（GCN5/HDA9 等）的 TF 互作网络
- 信号共享 vs 特异表观模块的定量分解
- 信号交叉实验的表观可加性/交互性矩阵
- **Figure 5**: 多信号→染色质状态→转录输出的整合流程图 + TF-表观酶配对网络

### 里程碑

揭示植物如何用有限的表观调控工具包整合多样化的环境与发育信号，提出"通用表观酶 + 特异 TF = 信号特异输出"的调控原理

## Expected Results & Risk Assessment

| 假设 | 预期结果 | 置信度 | 风险 | 备选方案 |
|------|---------|--------|------|---------|
| **H1** (染色质预配置) | 在≥2 个发育转变事件中鉴定到≥1000 个预配置区域；染色质变化先于转录变化 1-6h | **中高** — 逻辑推演合理但直接证据有限 | 时间分辨率不足以区分时序（染色质与转录变化几乎同时） | 增加同步化处理（如诱导型发育开关系统）；使用更高时间分辨率（15min 间隔） |
| **H2** (WRKY-OBE 复合物) | 解析四元复合物结构；验证 WRKY-OBE 共占位与靶基因抑制的因果关系；确定小立碗藓→被子植物功能获得的关键氨基酸 | **高** — 已有大量先导数据 | 复合物不稳定/难以获得均一样品用于 Cryo-EM | 分步解析（WRKY-OBE 二元 + OBE-H3 肽二元结构）；使用交联质谱辅助建模 |
| **H3** (TF 层级网络) | 至少 3 个物种中证实 E2F→MYB/NAC/bHLH 层级；E2F 直接结合分化 TF 启动子 | **中高** — 假时间分析一致性高 | 层级关系为间接（通过中间因子）而非直接 TF→TF | 补充中间因子鉴定；使用 ATAC-seq 检验层级转换的染色质门控假说 |
| **H4** (物种多样化) | 核心发育模块表观调控保守（≥70% 同源基因座表观状态相似）；至少鉴定 3 个物种特异表观创新 | **中高** — 分子机制保守性长期确立 | 技术平台跨物种不可比（抗体兼容性、基因组注释质量差异） | 聚焦序列保守性高的核心发育基因；使用同源映射而非直接峰调用比较 |
| **H5** (多信号整合) | 共享表观响应模块占总响应的 30-50%；鉴定至少 5 对新的 TF-表观酶配对 | **中** — 信号特异性证据丰富但整合性研究少 | 信号间交叉过于复杂，核心逻辑难以抽取 | 先完成成对信号分析，再逐步扩展到多信号整合 |

### 整体风险控制

- **跨物种技术兼容性**：各物种基因组注释质量不一 → 建立统一参考流程，使用直系同源群（orthogroup）进行跨物种比较，降低注释偏差影响
- **高维数据整合难度**：五 Aims 产出数据维度极高 → Phase 1 即设计统一元数据标准和数据模型，确保互操作性
- **结构生物学瓶颈**：Cryo-EM 可能需要较长时间优化 → 并行推进体外生化实验（ITC/SPR）和交联质谱，保证在无结构情况下也能获得关键生化信息
- **论文产出平衡**：36 个月时间紧凑 → 每个 Aim 的阶段性成果即可形成独立手稿，不等待全部完成
