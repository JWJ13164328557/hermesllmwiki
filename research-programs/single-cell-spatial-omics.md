# 📋 Research Program: 单细胞与空间多组学 — 从描述性图谱到机制性理解

## Central Question

**单细胞与空间多组学如何从描述性细胞图谱走向植物细胞类型身份（identity）、空间组织（spatial organization）和基因调控逻辑（regulatory logic）的跨物种机理性理解？**

> *Central Question 推演依据*：Synthesis 的 6 条共识发现一致表明，当前植物单细胞领域已完成了主要物种（拟南芥、水稻、玉米）根器官的描述性图谱构建（共识 #1、#2），核基方法提供了可行替代方案（共识 #3），空间整合工具已出现（共识 #4），细胞类型特异性胁迫响应已被初步观察（共识 #5），发育轨迹已被重建（共识 #6）。然而，7 条知识空白暴露了该领域的核心瓶颈：从"看见了什么细胞"到"细胞为什么这样工作"的机制性跨越尚未完成——空间整合方法未经基准测试（空白 #1）、功能验证近乎空白（空白 #2）、原生质体-核法差异未量化（空白 #3）、多组学处于萌芽期（空白 #5）、细胞通讯缺乏实验验证（空白 #7）。本方案的核心命题正是填补这一"描述→机制"的鸿沟。

> **证据更新说明（2026-08-24）**：Synthesis 于本日更新至 **550 条证据 / 78 篇文献**（此前 58 篇/395 条），新增证据进一步夯实了本推演的实证基础，重点强化了两类共识：(i) **共识 #5 细胞类型特异性胁迫响应** ——玉米 `ZmHSP90-ZmWAK2` 介导的表皮-叶肉细胞免疫通讯（`b3-l7tWWswvI2rZ5ba_4V2BsQ`）与热胁迫下的细胞类型特异转录差异，强化了 Aim 5 从"单细胞表型预测"走向"遗传扰动因果验证"的立论；(ii) **共识 #4 空间转录组整合** ——玉米叶片连续空间转录组（`maize-leaf-continuous-spatial`）与小麦花序空间梯度（`wheat-inflorescence-spatial-transcriptome`）证据，强化了 Aim 2 方法基准与空间细胞通讯推演的场景依据。证据量的增长未改变既有 6 条共识与 7 条知识空白的整体结构，故本方案的 Aim 框架保持稳定，仅在 Aims 的证据引用与产出论证上做增量强化。

## Aim 1: 跨物种多器官单细胞转录组图谱与细胞类型演化

**检验假设**: H1 — 主要植物细胞类型（根表皮、皮层、内皮层、中柱鞘、维管等）在被子植物中深度保守，可在拟南芥（双子叶）、水稻和玉米（单子叶）中通过统一注释框架识别；但谱系特异细胞亚型（如单子叶外皮层、豆科根瘤相关细胞类群）反映了演化创新。同时，通过多分辨率聚类策略可界定生物学最优的细胞分类粒度。

**背景与假设依据**:

| 共识/空白 | 内容 | 如何驱动本 Aim |
|-----------|------|---------------|
| 共识 #1 | scRNA-seq 可跨物种可靠解析主要细胞类型 | 提供跨物种比较的理论前提——已验证拟南芥 ≥15 类、水稻含外皮层等单子叶特有类型、玉米花序分生组织域 |
| 共识 #2 | 根是目前最全面的器官图谱 | 选择根作为跨物种比较的锚定器官，已有拟南芥器官尺度图谱（>25 类群）作为"金标准"参考 |
| 空白 #4 | 最优聚类分辨率无共识（15 类 vs 24 类争议） | 通过多分辨率扫描 + 生物学验证（原位杂交/功能扰动）界定最优粒度，而非仅依赖计算指标 |

**实验设计**:

| 物种 | 组织/器官 | 技术平台 | 生物学重复 | 发育时间点 | 预期细胞数/样本 |
|------|----------|---------|-----------|-----------|----------------|
| *Arabidopsis thaliana* (Col-0) | 根尖 (0-5 mm) + 莲座叶 | 10x scRNA-seq (原生质体) | 3 | 5 dpg, 10 dpg (根); 21 dpg (叶) | ~10,000 |
| *Oryza sativa* (日本晴 Nipponbare) | 根尖 (0-5 mm) + 茎基部 | 10x scRNA-seq (原生质体) | 3 | 5 dpg, 10 dpg (根); 30 DAS (茎) | ~10,000 |
| *Zea mays* (B73) | 根尖 (0-5 mm) + 幼叶 (V3期) | 10x scRNA-seq (原生质体) | 3 | 5 dpg, 10 dpg (根); V3 (叶) | ~10,000 |
| *Solanum lycopersicum* (M82) | 根尖 (0-5 mm) | 10x scRNA-seq (原生质体) | 3 | 7 dpg, 14 dpg | ~8,000 |
| *Medicago truncatula* (A17) | 根尖 + 根瘤 (接种后) | 10x scRNA-seq (原生质体) | 3 | 5 dpg, 根瘤 14 dpi | ~8,000 |

> **物种选择逻辑**：拟南芥（双子叶模式，已有最完整参考图谱）、水稻（单子叶模式，单子叶特有细胞类型如外皮层/厚壁组织已验证）、玉米（单子叶+C4，花序图谱已有基础）、番茄（茄科代表，果实发育单细胞研究活跃）、苜蓿（豆科代表，根瘤共生提供独特细胞类型演化视角）。覆盖被子植物三大分支：双子叶、单子叶、豆科。

**分析流程**:

```
Raw FASTQ → Cell Ranger / STARsolo alignment → QC 过滤
    (UMI > 500, genes > 200, mito < 10% for protoplast)
    → Seurat v5 SCTransform 归一化 + Harmony 批次校正
    → PCA + UMAP 降维
    → 多分辨率 Leiden 聚类 (resolution 0.2–2.0, 步长 0.2)
    → 细胞类型注释 — 三层策略:
        L1: 已知标记基因直接注释 (拟南芥根参考 → 水稻同源映射 → 玉米/番茄/苜蓿)
        L2: 无监督 label transfer (Seurat Anchor / scANVI)
        L3: 争议类群通过 RNA in situ 独立验证
    → 发育拟时序: Monocle 3 + scVelo RNA velocity
    → 跨物种整合: SAMap (物种感知映射) / SATURN
```

**多分辨率聚类最优粒度界定**:

```
对每个物种, 扫描 resolution 0.2–2.0:
  1. 计算每个分辨率下的聚类纯度 (silhouette score)
  2. 差异表达基因可重复性 (bootstrap resampling)
  3. 已知解剖结构的吻合度 (标记基因空间验证)
  4. 跨分辨率聚类树稳定性 (clustering tree, Z-score)
→ 输出: 各物种生物学最优分辨率 + 通用建议准则
```

**跨物种细胞类型演化分析**:

```
SAMap 跨物种联合嵌入
  → 共享细胞类型: 跨物种保守的 cluster pairs (ARI > 0.6)
  → 物种特有细胞类型: 无对应 cluster 的孤立类群
  → 标记基因保守率计算:
      保守率 = 跨物种共享标记基因数 / 任一物种总标记基因数
  → 系统发育信号: Bloomberg's K / Pagel's λ
  → 谱系特异创新基因功能富集 (GO/MapMan)
```

**验证方法**:

- RNA 原位杂交: 每个物种 ≥6 个细胞类型标记基因，包含保守标记和物种特异标记
- 与已发表图谱交叉验证: 拟南芥 vs Root Atlas; 水稻 vs 两品种已有数据（日本晴/Azucena）; 玉米 vs 雌穗已有图谱
- 苜蓿根瘤数据通过激光捕获显微切割 (LCM) 独立验证共生相关细胞类型

**产出**:

- 5 物种 × 2 器官的统一单细胞转录组图谱（交互式数据门户）
- 跨物种细胞类型保守性矩阵与演化模型
- 多分辨率聚类最优粒度指南（解决空白 #4）
- 物种特异细胞类型目录（单子叶外皮层、豆科根瘤细胞类群等）

**里程碑**: 建立首个跨被子植物三大分支的统一单细胞注释框架；输出生物学最优聚类分辨率的通用准则

## Aim 2: 空间转录组整合方法系统基准与细胞空间通讯解析

**检验假设**: H2 — 不同空间整合算法（Harmony 联合嵌入 vs Tangram 深度学习映射 vs cell2location 贝叶斯反卷积 vs RCTD 概率分解）在植物组织中存在显著性能差异，其适用场景取决于组织结构和数据稀疏度。空间整合可精确重建发育梯度（如根尖分生组织→分化区的连续空间轴），并实现空间约束下的细胞间配体-受体通讯推断。

**背景与假设依据**:

| 共识/空白 | 内容 | 如何驱动本 Aim |
|-----------|------|---------------|
| 共识 #4 | 空间整合是连接转录组聚类与组织空间结构的关键 | Harmony、Tangram 等工具已验证可行，但仅各自报告自身性能。2026-08-24 更新的 Synthesis 进一步纳入玉米叶片连续空间转录组（`maize-leaf-continuous-spatial`）、小麦花序空间梯度（`wheat-inflorescence-spatial-transcriptome`）及玉米免疫反应的空间-单核整合证据，为本 Aim 的多物种、多组织基准测试提供了更充分的场景依据与外部对照数据集 |
| 空白 #1 | 空间整合方法的系统基准测试不足 | 四种主流工具从未在统一植物数据集上进行公平比较 |
| 空白 #7 | 细胞通讯推断缺乏植物特异实验验证体系 | 现有 CellChat/NicheNet 基于哺乳动物配体-受体数据库，植物特异通讯网络需实验锚定 |

**实验设计**:

| 物种 | 组织 | 空间技术 | 单细胞参考来源 | 重复 | 空间分辨率 | 比较维度 |
|------|------|---------|---------------|------|-----------|---------|
| *A. thaliana* | 根纵切面 (全根尖) | Stereo-seq + 10x Visium (并行) | Aim 1 拟南芥根图谱 | 3/平台 | bin20/50/100 (Stereo); 55μm (Visium) | 平台间比较 + 工具比较 |
| *O. sativa* | 根横切面 | Stereo-seq | Aim 1 水稻根图谱 | 3 | bin20/50/100 | 组织方向对整合的影响 |
| *Z. mays* | 幼叶横切面 (V3) | Stereo-seq | Aim 1 玉米叶图谱 | 3 | bin50 | 叶肉-C4 空间域验证 |
| *S. lycopersicum* | 根横切面 | Stereo-seq | Aim 1 番茄根图谱 | 3 | bin50 | 跨物种基准扩展 |

**整合工具基准测试设计**:

```
测试平台:
  Stereo-seq (高分辨率, 亚细胞 bin) + Visium (标准分辨率, 55μm spots)

测试工具 (v4):
  1. RCTD — 概率模型反卷积, "Reference-free" mode 备选
  2. cell2location — 贝叶斯层次模型, 估计细胞丰度
  3. Tangram — 深度学习, 单细胞→空间映射
  4. Harmony — 跨模态联合嵌入, 共用低维空间

评估指标 (6 维):
  ┌─────────────────────────────────────────────┐
  │ 1. 空间定位精度: 映射细胞类型与已知解剖边界 │
  │    的像素级偏差 (μm)                         │
  │ 2. 反卷积准确性: 模拟混合 spot 的细胞比例    │
  │    恢复精度 (RMSE, Pearson r)                │
  │ 3. 分辨率稳健性: bin20→bin100 性能衰减曲线   │
  │ 4. 运行效率: CPU/GPU 时间 + 内存峰值         │
  │ 5. 批次稳健性: 跨重复的一致性 (ARI)          │
  │ 6. 生物学可用性: 下游梯度检测/通讯推断的      │
  │    结果可重复性                               │
  └─────────────────────────────────────────────┘

实验矩阵:
  4 工具 × 3 组织 (根纵/根横/叶横) × 3 分辨率 × 5 重复
  → 180 次独立整合运行
```

**空间发育梯度分析**:

```
根尖纵切面整合后:
  → 定义空间坐标轴 (根尖分生组织→伸长区→分化区)
  → SPATA / spatialDE: 鉴定沿空间轴显著变化的基因
  → 比较各工具鉴定的空间梯度基因集重叠度
  → 已知发育梯度基因验证 (如 SHR/SCR 从中柱向外梯度)
```

**空间约束细胞通讯推断**:

```
方法:
  1. CellChat / NicheNet: 基于配体-受体共表达的通讯预测
  2. 空间加权: spot 间物理距离作为通讯概率的先验约束
     (邻近 spot 的配体-受体对权重 > 远端)
  3. 植物特异配体-受体库:
     - CLE 肽家族 (CLV1/CLV2/TDR/PXY 受体)
     - EPF/EPFL 家族 (ERECTA 受体)
     - RALF 肽家族 (FERONIA 受体)
     - 经典激素信号 (auxin transport, cytokinin signaling)

验证:
  - 空间邻近连接测定 (proximity ligation assay, PLA)
    对预测的配体-受体空间共定位进行原位验证 (≥5 对)
  - 激光捕获显微切割 (LCM) + RT-qPCR 局部空间域验证
```

**验证方法**:

- 空间定位精度通过已知标记基因的原位表达模式定量评估（每个物种 ≥10 个空间锚定基因）
- 基准测试结果通过"合成 ground truth"交叉验证：将单细胞数据人工混合为已知比例的合成 spots，测试各工具恢复精度
- PLA 空间验证选择拟南芥根尖 CLE-WUS/CLV 经典通路作为阳性对照

**产出**:

- 四种整合工具的植物场景系统基准报告（发表为方法学资源论文）
- 多物种根/叶空间细胞类型图谱
- 植物组织空间整合工具推荐决策树（按组织类型/分辨率/研究问题推荐最优工具）
- 植物特异配体-受体通讯网络（空间约束版）
- 空间梯度基因目录（根发育轴 + 叶 C3/C4 分化轴）

**里程碑**: 填补植物空间整合方法的基准测试空白（空白 #1）；建立空间实验验证的细胞通讯分析体系（空白 #7 部分解决）

## Aim 3: 原生质体法与核基单细胞方法全系统定量比较

**检验假设**: H3 — 原生质体法 (scRNA-seq) 与核基法 (snRNA-seq) 在主要细胞类型鉴定上一致性高（ARI > 0.7），但原生质体法系统性地引入可量化的胁迫转录假象（热激蛋白、ROS 清除基因上调、特定细胞类型选择性丢失），且这些假象在不同物种和不同组织中具有一致的分子特征。核基法则存在转录本覆盖度降低的补偿性偏差。

**背景与假设依据**:

| 共识/空白 | 内容 | 如何驱动本 Aim |
|-----------|------|---------------|
| 共识 #3 | 核基方法可规避原生质体化诱导的胁迫假象 | 提供了替代方案的理论基础，但仅基于拟南芥单一物种的定性观察 |
| 空白 #3 | 原生质体法与核法的转录组差异未完全量化 | 缺乏跨物种、跨组织的系统定量比较——核 RNA 丢失的转录本比例、细胞类型偏向性、胁迫基因诱导幅度均未知 |

**实验设计**:

| 方法对 | 物种 | 组织 | 重复 | 比较维度 |
|--------|------|------|------|---------|
| scRNA-seq (原生质体) vs snRNA-seq (核基) | *A. thaliana* (Col-0) | 根尖 | 各 3 | 双子叶基线比较 |
| scRNA-seq (原生质体) vs snRNA-seq (核基) | *O. sativa* (日本晴) | 根尖 | 各 3 | 单子叶比较 |
| scRNA-seq (原生质体) vs snRNA-seq (核基) | *Z. mays* (B73) | 幼叶 | 各 3 | 不同器官比较 |
| scRNA-seq (原生质体) vs snRNA-seq (核基) | *M. truncatula* (A17) | 根尖 | 各 3 | 豆科比较 |

> **设计逻辑**：同一样本分为两份——一份走完整原生质体流程（细胞壁酶解→FACS→10x），一份走核提取流程（核分离→FACS 或密度梯度→10x）。同一生物学样本的配对设计消除了个体间差异，使方法学比较具有最大统计效力。

**定量比较框架**:

```
维度 1 — 细胞类型鉴定一致性:
  ├── 聚类结果一致性: ARI, NMI, Jaccard (细胞类型对)
  ├── 细胞类型比例: χ² 检验各类型在两方法间的比例差异
  ├── 标记基因重叠: 各方法鉴定的 top 50 标记基因 Jaccard 指数
  └── 细胞类型丢失率: 仅在一种方法中缺失的细胞类型数 / 总类型数

维度 2 — 转录组覆盖度差异:
  ├── 基因检出率: 每个基因在两种方法中的检出细胞比例
  ├── 核 RNA 丢失分析: 仅在原生质体中检出的基因 (nuclear-depleted)
  │   ├── 功能类别: GO 富集 (预计: 细胞质翻译、光合相关、胁迫响应)
  │   └── 是否富含内含子保留转录本
  ├── 核 RNA 富集分析: 仅在核基法中检出的基因 (nucleus-enriched)
  │   └── 功能类别: 染色质调控、转录因子、非编码 RNA
  └── 转录本长度偏差: 长转录本 (>5kb) 在核法中的检出率

维度 3 — 胁迫转录假象量化:
  ├── 胁迫基因评分: 原生质体法中已知胁迫基因 (HSP70/90, ROS scavenging,
  │   ER stress) 的平均表达水平 vs 核基法
  ├── 假象基因集鉴定: 原生质体法中显著上调但核基法中不显著的基因
  │   → 定义为 "protoplasting-induced artifact (PIA) signature"
  ├── 假象时间动态: 不同酶解时间 (30/60/90 min) 的假象累积曲线
  └── 假象可逆性: 原生质体恢复培养 2h/6h/12h 后的假象衰减

维度 4 — 跨物种/跨组织假象保守性:
  ├── PIA signature 在 4 物种间的重叠度 (UpSet / Venn)
  ├── PIA signature 在根 vs 叶之间的一致性
  └── 物种/组织特异性假象基因功能注释
```

**验证方法**:

- 选择 20 个 PIA signature 基因，通过 RNA in situ 在完整组织（未酶解）vs 原生质体（酶解后固定）中比较表达模式
- 选择 10 个核富集基因，通过单分子 FISH (smFISH) 在完整组织中验证其核定位
- 基准数据通过公共数据独立验证: 已发表的拟南芥根原生质体和核基数据集作为外部对照

**产出**:

- 原生质体法 vs 核基法跨物种/跨组织定量比较论文（方法学基准资源）
- PIA signature 基因集（"原生质体化胁迫假象特征基因集"——社区警告标志）
- 核富集基因目录（染色质调控因子、非编码 RNA 等）
- 方法选择决策流程图（按组织类型、研究问题、细胞类型偏向性推荐原生质体法或核基法）
- SOP: 植物组织最优单细胞方法选择指南

**里程碑**: 首次跨物种/跨组织系统量化原生质体-核基方法差异，为植物单细胞社区提供方法选择依据（填补空白 #3）

## Aim 4: 植物单细胞多组学整合与细胞类型特异性基因调控网络推断

**检验假设**: H4 — 同步获取同一细胞核的转录组（snRNA-seq）和染色质可及性（snATAC-seq）可识别细胞类型特异性顺式调控元件和转录因子结合模式，从而将单细胞分析从"哪些基因在哪些细胞中表达"推进到"哪些转录因子通过哪些增强子驱动细胞类型身份"。植物多组学面临的核分离效率和数据稀疏性挑战可通过优化的实验和分析流程克服。

**背景与假设依据**:

| 共识/空白 | 内容 | 如何驱动本 Aim |
|-----------|------|---------------|
| 空白 #5 | 单细胞多组学（同步 RNA + ATAC）在植物中仍处萌芽阶段 | 哺乳动物已成熟的 10x Multiome 技术在植物中仅有零星尝试——核心瓶颈在于植物细胞核分离效率和 snATAC 数据的极端稀疏性 |
| 空白 #6 | 细胞类型特异性调控网络的功能验证几近空白 | 单细胞数据大多停留在描述层面——哪些 TF-靶基因关系是功能必需的完全未知；多组学整合是建立可验证假说的前提 |
| 共识 #6 | 假时间分析揭示了谱系特异性转录动力学 | 内皮层约 800 个动态基因涉及 MYB36/SHR/SCR——这些因子的上下游调控关系可通过多组学重构 |

**实验设计**:

| 方法 | 物种 | 组织 | 重复 | 技术要点 |
|------|------|------|------|---------|
| snRNA-seq + snATAC-seq (Multiome) | *A. thaliana* (Col-0) | 根尖 | 4 | 10x Multiome kit, 核分离优化 (chopping + Percoll 梯度) |
| snRNA-seq + snATAC-seq (Multiome) | *O. sativa* (日本晴) | 根尖 | 4 | 同上, 水稻核分离缓冲液优化 (NP-40/Triton 浓度梯度测试) |
| 独立 snATAC-seq (非 Multiome) | *Z. mays* (B73) | 根尖 + 幼叶 | 各 3 | 作为 Multiome 的补充和成本优化备选 |
| 独立 snATAC-seq (非 Multiome) | *M. truncatula* (A17) | 根尖 | 3 | 豆科根作为双子叶扩展 |

**分析流程**:

```
A. snATAC-seq 处理:
  cellranger-arc count → Signac/ArchR
  → 核质控 (TSS enrichment > 2, unique fragments > 1000)
  → LSI 降维 + UMAP
  → 基于基因活性评分 (gene activity score) 的聚类
  → 与 snRNA-seq 聚类的 label transfer 交叉验证

B. Multiome 整合 (拟南芥 + 水稻):
  WNN (Weighted Nearest Neighbor) 联合聚类
  → RNA 模态权重 + ATAC 模态权重的加权联合嵌入
  → 比较联合聚类 vs 单模态聚类的分辨率增益

C. 顺式调控元件注释:
  每种细胞类型:
  → peak calling (MACS2 per cluster)
  → 差异可及性区域 (DARs, per cell type)
  → DAR 基因组注释: 启动子 (±2kb TSS) / 基因间 / 内含子
  → GREAT / ChIPseeker 功能注释

D. 转录因子调控网络推断 (GRN):
  SCENIC+ (pySCENIC for ATAC):
  1. 从 DAR 中鉴定 TF motif 富集 (cisTarget)
  2. 从 snRNA-seq 中获取 TF-靶基因共表达 (GRNBoost2)
  3. 整合 motif + 共表达 → 细胞类型特异性 regulon
  4. Regulon 活性评分 (AUCell) 在 UMAP 上可视化

  重点分析 TFs:
  - 已知细胞命运主调控因子: SHR, SCR, MYB36, WOX5, PLT1/2
  - 单子叶特异: OsSHR, OsSCR 的同源 regulon 比较
  - 发育动态中的 regulon 活性转换 (拟时序 + regulon 活性)

E. 跨物种调控网络保守性:
  拟南芥 vs 水稻:
  → 同源 TF 的 regulon 靶基因重叠度
  → 同源 DAR 序列保守性 (liftOver / LASTZ 全基因组比对)
  → 细胞类型等同的 regulon 模块保守率
```

**方法学优化子任务**（降低多组学失败风险）:

```
核分离优化:
  - 拟南芥根: chopping 法 + Percoll 梯度 (已有报道, 低风险)
  - 水稻根: 测试 3 种裂解缓冲液 (NP-40%, Triton X-100%) × 3 种梯度
  - 质量指标: 核完整性 (>80%), Tn5 酶切效率, 核聚集率 (<10%)

数据稀疏性应对:
  - 增加测序深度 (snATAC: ≥25K fragments/nucleus)
  - 伪批量 (pseudo-bulk) 聚合增强 peak calling 统计效力
  - Cicero 共可及性分析补充远端调控元件
```

**验证方法**:

- 关键 regulon 的 TF 结合通过已发表的 ChIP-seq 数据交叉验证（拟南芥 SHR/SCR/MYB36）
- 预测的细胞类型特异性增强子选择 5 个进行转基因报告验证 (enhancer:GFP in Arabidopsis)
- 拟南芥 Multiome 数据与公共数据 (ENCODE 植物) 整合验证

**产出**:

- 拟南芥/水稻根尖单细胞多组学整合图谱（Multiome 数据）
- 细胞类型特异性顺式调控元件目录（DARs × cell type）
- 细胞类型特异性基因调控网络 (regulons × cell type)
- 跨物种（拟南芥 vs 水稻）regulon 保守性分析
- 植物多组学实验和分析 SOP

**里程碑**: 实现植物单细胞多组学（snRNA+snATAC）的概念验证和方法标准化；从描述性基因列表推进到调控机制假说生成（填补空白 #5、#6 前半程）

## Aim 5: 细胞类型特异性发育调控因子的 CRISPR 功能验证

**检验假设**: H5 — 从单细胞数据中预测的细胞类型特异性调控因子（如特定细胞类群中高活性的 TF regulon、细胞类型特异性表达的未知功能基因）在发育过程中具有功能必需性，其敲除/敲低将导致特定细胞类型的缺失、分化异常或身份转换，且效应可通过单细胞分辨率的功能基因组学读出。

**背景与假设依据**:

| 共识/空白 | 内容 | 如何驱动本 Aim |
|-----------|------|---------------|
| 空白 #2 | 细胞类型特异性调控网络的功能验证几近空白 | 内皮层 800 个动态基因中，哪些是功能必需的？MYB36 之外的调控回路如何运作？单细胞数据产生大量候选基因，但从未系统地进行功能测试 |
| 共识 #5 | 细胞类型特异性胁迫响应超越经典共享程序 | 玉米 ZmHSP90-ZmWAK2 免疫通讯的发现表明细胞类型特异性调控具有功能重要性——但尚未通过遗传扰动直接验证因果关系。2026-08-24 更新的 Synthesis 同时整合了热胁迫与免疫响应两类细胞类型特异证据（后者含 24/48h 时间动态的 8 种细胞类型分析），进一步强化了"细胞类型特异调控因子驱动胁迫/发育表型"这一 H5 立论的实证面，使 CRISPR 扰动的因果验证更具针对性 |
| 共识 #6 | 假时间分析揭示了谱系特异性转录动力学 | 关键节点（分叉点）的调控因子是功能验证的优先目标 |

**实验设计 — 三阶段功能验证策略**:

**阶段 1: 候选基因优先化** (月 18-22)

```
候选基因来源:
  来源 A (Aim 1): 各物种细胞类型特异性标记基因 (top 5 per cell type)
  来源 B (Aim 4): 细胞类型特异 regulon 的主调控 TF (top 3 per cell type)
  来源 C (Aim 1 拟时序): 发育轨迹分叉点的关键表达转变基因 (branch-point genes)
  来源 D (Aim 2): 空间梯度极值点基因 (spatialDE top hits)

优先化标准:
  1. 功能未知或功能注释不完整 (排除已有详尽研究如 MYB36/SHR/SCR)
  2. 细胞类型特异性高表达 (AUC > 0.85, logFC > 1.5 vs other clusters)
  3. 至少在一对物种间存在直系同源
  4. 编码可靶向的蛋白 (TF, 激酶, 肽激素) → 适合功能扰动

最终筛选: 20-30 个优先候选基因 (每个来源 5-8 个)
```

**阶段 2: CRISPR 扰动库构建** (月 20-26)

| 实验策略 | 物种 | 载体 | 候选基因数 | 靶向方式 |
|---------|------|------|-----------|---------|
| CRISPR-Cas9 敲除 (KO) | *A. thaliana* (Col-0) | pHEE401E (egg cell-specific Cas9) | 10 个候选 | 双 sgRNA (外显子删除) |
| CRISPR-dCas9-KRAB 敲低 (CRISPRi) | *A. thaliana* (稳定转化系) | pMDC系列 (dCas9-KRAB) | 10 个候选 (启动子靶向, 适用于必需基因) | 2 sgRNA/基因 |
| CRISPR-Cas9 敲除 (KO) | *O. sativa* (日本晴) | pCXUN-Cas9 (Ubiquitin 启动子) | 8 个候选 (同源拟南芥基因的水稻直系同源) | 双 sgRNA |

> **物种策略**：以拟南芥为功能验证主力（生命周期短、转化效率高、遗传工具成熟），水稻为跨物种验证（验证单子叶中同源基因的功能保守性）。玉米因转化效率低、周期长不纳入此 Aim 的扰动实验，但可作为 Aim 1/4 数据的预测验证（通过玉米已有突变体资源进行相关性分析）。

**阶段 3: 单细胞分辨率表型读出** (月 24-30)

```
每个 CRISPR 系:
  → 表型初筛: 根长/根形态/根冠发育的宏观表型 (T2 代纯合系, n ≥ 3 lines/gene)
  → 组织学分析: 根尖树脂切片 + 甲苯胺蓝染色 → 细胞层数/排列异常
  → 单细胞读出 (scRNA-seq): 选择 6 个最强表型突变体
      + WT 对照, 各 2 个生物学重复, 10x scRNA-seq 根尖
  → 分析:
      1. 细胞类型比例变化: 突变体中是否特定细胞类型缺失/增加
      2. 差异表达: 突变体 vs WT 在各细胞类型中的 DEG
      3. 发育轨迹改变: 突变体中拟时序分叉点是否消失/偏移
      4. Regulon 活性扰动: 突变体 TF 对其靶基因模块的活性变化
      5. 细胞身份转换: 是否出现混合细胞身份的转录组特征 (score-based)
```

**跨物种验证** (月 26-32):

```
水稻 CRISPR 突变体:
  → 表型分析 (根形态/解剖)
  → 选择 3 个表型最显著的水稻突变体 + WT
  → 水稻根尖 scRNA-seq (含已发表的日本晴野生型数据作为额外参考)
  → 比较: 拟南芥 KO 的细胞类型变化模式 vs 水稻 KO
  → 评估同源基因功能性保守程度
```

**验证方法**:

- 基因编辑通过 Sanger 测序 + T7E1 酶切验证突变
- CRISPRi 的敲低效率通过 RT-qPCR 验证（≥70% 抑制）
- 细胞身份转换通过已知标记基因组合评分定量评估
- 互补实验: 对关键突变体进行野生型基因回补验证表型可恢复性（选择 3 个最强表型基因）

**产出**:

- 20-30 个候选基因的 CRISPR 功能扰动系（拟南芥 + 水稻）
- 6-9 个突变体的单细胞转录组表型图谱（scRNA-seq phenotypic atlas）
- 细胞类型缺失/身份转换的功能验证证据
- 跨物种（拟南芥→水稻）调控因子功能保守性/分歧分析
- 从"单细胞预测"到"功能验证"的完整研究范式（填补空白 #2）

**里程碑**: 首次系统将 CRISPR 功能扰动与单细胞读出结合，验证单细胞预测的细胞类型特异性调控因子（填补空白 #2）；建立从计算预测→遗传扰动→单细胞表型的范式闭环

| 3 | H3 | 原生质体法 vs 核基法细胞类型鉴定一致性 ARI > 0.7；原生质体法诱导 ≥200 个 PIA signature 基因（跨物种保守 >60%）；核基法丢失约 15-25% 的转录本多样性 | 低-中 | 方法比较方案设计成熟；主要不确定因素为各物种核分离效率差异 |
| 4 | H4 | 拟南芥 Multiome 可分辨 ≥8 种细胞类型的差异染色质景观；水稻 Multiome 可能因基因组复杂度而分辨率降低；≥10 个细胞类型特异 regulon 被鉴定；MYB36/SHR 的已知靶基因在 regulon 中显著富集 | 中-高 | 植物 Multiome 技术不成熟，核分离+Tn5 酶切效率是最大瓶颈；水稻基因组大且重复序列多增加分析难度 |
| 5 | H5 | ≥5 个候选基因的 CRISPR 扰动产生可检测的细胞类型特异性表型（比例变化、分化阻滞或身份转换）；≥2 个基因在拟南芥和水稻中都显示功能保守性 | 中-高 | 功能冗余（基因家族）、致死性（必需基因无法获得纯合突变体）和弱表型（需大样本量）为主要挑战 |

### 备选方案与风险缓解

| 风险 | 概率 | 缓解措施 |
|------|------|---------|
| 苜蓿根瘤细胞类型捕获不足 | 中 | 富集策略：FACS 分选共生相关荧光报告系 (ENOD11:GFP)；如不可行则降级为仅使用公共数据做计算比较 |
| Stereo-seq 切片质量不达标 | 中 | 备选 10x Visium (石蜡切片兼容性更优)；或降低通量使用 LCM + Smart-seq3 作为定向空间验证 |
| 水稻 Multiome 核分离失败 | 高 | 设为"高回报探索目标"——成功则论文档次大幅提升，失败则依靠独立 snATAC-seq 数据完成 Aim 4 核心目标；独立 snATAC 为保底方案 |
| CRISPR 功能冗余掩盖表型 | 中 | 优先选择无旁系同源（单拷贝）的候选基因；设计多基因突变体系列 (CRISPR multiplex)；对致死基因使用 CRISPRi 条件性敲低 |
| 必需基因纯合致死 | 中 | 使用 CRISPR-dCas9-KRAB 诱导型敲低（雌二醇诱导）；或使用杂合突变体分析剂量效应 |
| 跨物种同源映射噪声 | 低-中 | 使用 OrthoFinder 严格直系同源鉴定（而非简单 BLAST best hit）；结合共线性 (synteny) 证据提高置信度 |

### 与大豆节间光质项目的边界

本方案为**纯知识推演产物**，不依赖大豆节间光质项目（`soybean-internode-light-quality`）的任何假设或数据。两个方案的关系为：

- **本方案的贡献**：建立跨物种单细胞与空间组学的方法学基础设施（图谱构建→整合分析→方法比较→多组学→功能验证的完整范式），输出标准化的实验和分析流程，为任何后续的植物单细胞研究提供可复用的方法论框架和社区资源。

- **大豆项目的可能受益**：本方案的 Aim 1（跨物种图谱）为大豆提供单子叶/豆科近缘物种的参考注释框架；Aim 3（方法比较）的实验结论可直接指导大豆组织的方法选择（核基法 vs 原生质体法）；Aim 2（空间基准）的推荐工具可用于后续任何大豆组织的空间分析。但本方案不主动触及大豆数据的生成——该工作留给 `soybean-internode-light-quality` 项目自行推进。
