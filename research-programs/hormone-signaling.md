# 📋 Research Program: 激素交叉对话的定量化理解

## Central Question

**植物激素信号如何通过 DELLA 蛋白滴定中枢、染色质预配置和代谢开关实现定量化的交叉对话，从而协调多物种的生长-防御权衡？**

---

## 背景与知识基础

### 知识来源

本方案基于 `hormone-signaling` 合成页面（309 条证据对象、108 篇文献），整合五大共识发现和六项知识空白，采用纯知识推演方式构建。

### 核心共识发现

| # | 共识发现 | 与本方案关联 |
|---|---------|------------|
| 1 | DELLA 蛋白是多激素信号的"物理整合中枢" — GA、JA、auxin、BR、光信号均通过 DELLA 进行交叉对话 | Aim 1 — DELLA 剂量效应直接测试 |
| 2 | 细胞类型特异性激素响应能力由染色质预配置决定 — scRNA-seq 一致表明响应能力是细胞类型固有的 | Aim 5 — 染色质预配置机制 |
| 3 | 激素信号存在"代谢层面"交叉对话 — CK→YUC/NCED、BR→类黄酮合成酶 | Aim 3 — CK-Auxin 代谢开关 |
| 4 | 蛋白滴定（Protein Titration）是激素调控代谢输出的新兴范式 — bHLH-DELLA 三元体系 | Aim 1 — DELLA 蛋白滴定定量 |
| 5 | 光信号与激素信号在多个节点深度耦合 — phyB-PIF-DELLA 三元连接 | Aim 4 — BR 信号整合 |

## Aim 1: DELLA 蛋白剂量依赖的互作组切换与蛋白滴定定量解析

**检验假设**: DELLA 蛋白在不同丰度下存在互作组"切换"行为 — 低浓度优先结合生长促进型转录因子（PIF、BZR1），高浓度转向胁迫响应型因子（JAZ、MYC2），该切换由 GA 水平通过泛素化降解决定。

**科学问题**: DELLA 蛋白浓度如何定量决定其互作组组成？是否存在浓度阈值触发互作伙伴切换？bHLH-DELLA 蛋白滴定网络的动力学参数是什么？

### 实验设计

| 项目 | 详情 |
|------|------|
| **物种** | *Arabidopsis thaliana* Col-0（主系统）、*Solanum lycopersicum*（番茄，验证保守性）、*Oryza sativa*（水稻，单子叶比较） |
| **组织** | 拟南芥下胚轴/根尖；番茄节间；水稻第二节间 |
| **技术** | TurboID 邻近标记 + TMT 定量质谱、FRET-FLIM（活体互作定量）、SPR（表面等离子共振，体外亲和力测定）、GA 梯度处理 |
| **处理** | GA₃ 梯度（0, 0.01, 0.1, 1, 10, 100 μM, 24h）+ PAC（GA 合成抑制剂, 10 μM）± 光质处理（模拟避荫） |
| **重复** | TurboID-MS 每 DELLA 丰度水平 3 个生物学重复；FRET-FLIM 每条件 ≥50 个细胞；SPR 每互作对 3 次独立实验 |

### 分析流程

```
GA₃ 梯度处理（拟南芥/番茄/水稻）
    → Western blot 定量内源 DELLA 蛋白丰度（建立 GA-DELLA 剂量-响应曲线）
    → 选定 5-6 个 DELLA 丰度水平（涵盖从 PAC 完全抑制到 GA 饱和）
    → TurboID-DELLA 邻近标记
        → LC-MS/MS → TMT 定量 → 每个 DELLA 水平的互作组组成

数据整合
    → DELLA 互作组组成 vs DELLA 丰度的定量关系
    → 互作伙伴聚类：
        生长促进组（PIF3/4/5, BZR1/BES1, ARF6）
        胁迫响应组（JAZ1/3/9, MYC2/3/4）
        基础互作组（组成型结合，不依赖 DELLA 丰度）
    → 阈值检测：分段线性回归（segmented regression）鉴定切换拐点
    → 互作伙伴间的竞争结合建模（competitive binding model）
```

### 关键分析

1. **互作组-浓度曲线**: 每个互作伙伴的 TMT 定量信号 vs DELLA 丰度，拟合 Hill 方程或分段线性模型
2. **切换阈值鉴定**: 使用 segmented R package 检测统计显著的拐点；比较拟南芥/番茄/水稻的阈值差异
3. **蛋白滴定动力学**: 针对 MdbHLH162-MdbHLH3-MdRGL2a 同源体系（拟南芥 bHLH-DELLA-MYB），SPR 测定各二元互作的 Kd、kon、koff，数学建模二聚体组成随 DELLA 浓度的动态变化
4. **光信号干扰**: 模拟避荫（低 R/FR）对 DELLA 互作组的扰动 — 通过 phyB-PIF 模块的间接效应

### 产出

- 拟南芥/番茄/水稻 DELLA 浓度梯度下的定量互作组图谱
- PIF/BZR1 与 JAZ/MYC2 互作切换的浓度阈值及物种间保守性
- DELLA-bHLH-MYB 蛋白滴定网络的动力学参数和数学模型
- DELLA 作为"变阻器"（rheostat）而非"开关"（switch）的定量证据

### 里程碑

为"DELLA 剂量-互作组切换"假说提供首个跨物种定量蛋白互作组证据

## Aim 2: JA-ET 时序分工的细胞类型水平验证与空间解析

**检验假设**: 伤口响应中 JA 信号在 0-6h 首先激活（"快速预警"），乙烯信号在 6-24h 延迟激活（"持续防御"），且两类信号的激活时序在细胞类型和空间位置（伤口边缘 vs 远端）上存在异质性。

**科学问题**: JA-ET 时序分工在单细胞/细胞类型水平上如何体现？不同细胞类型是否遵循相同的时序逻辑？伤口边缘与远端组织的时序差异如何？

### 实验设计

| 项目 | 详情 |
|------|------|
| **物种** | *Arabidopsis thaliana* Col-0（主系统）、*Solanum lycopersicum*（番茄，伤口响应模式差异验证） |
| **组织** | 拟南芥莲座叶（机械损伤模型）；番茄叶片（机械损伤 + 昆虫取食模拟） |
| **技术** | scRNA-seq（10x Genomics，时间序列）、空间转录组（Stereo-seq，伤口中心到远端梯度）、smFISH（单分子 FISH，关键基因空间验证）、JA/ET 报告基因系（*JAZ10p::GUS*、*EIN3p::GFP* 等） |
| **处理** | 机械损伤后时间序列：0h（对照）、0.5h、1h、2h、4h、6h、12h、24h、48h |
| **重复** | scRNA-seq 每时间点 2 个生物学重复；Stereo-seq 每时间点 2 个重复；smFISH 每时间点 3 个独立叶片 |

### 分析流程

```
叶片机械损伤 → 时间序列取样（0-48h, 9 个时间点）
    ├── scRNA-seq → 细胞聚类 → 注释表皮/叶肉/维管/保卫细胞
    │   → 每个细胞类型的 JA 响应得分（JAZ/MYC2/LOX 靶基因集）
    │   → 每个细胞类型的 ET 响应得分（ERF/EIN3 靶基因集）
    │   → 时序分析：每个细胞类型的 JA/ET 信号激活延迟时间（latency）
    │
    ├── Stereo-seq → 伤口边缘到远端的空间梯度（0-500-1000-2000 μm）
    │   → JA/ET 响应基因的空间传播速率
    │   → 伤口近端 vs 远端的细胞类型组成变化
    │
    └── smFISH → 关键 JA 基因（*MYC2*, *JAZ10*）和 ET 基因（*EIN3*, *ERF1*）的原位共定位
        → 同一细胞是否同时激活 JA 和 ET 信号？
```

### 关键比较

1. **时序异质性**: 表皮细胞 vs 叶肉细胞 vs 维管细胞的 JA/ET 激活延迟时间差异
2. **空间传播**: JA 信号从伤口边缘向远端传播的速度 vs ET 信号的传播速度
3. **信号重叠**: 哪些细胞类型在中间时间点（4-12h）同时具有 JA 和 ET 活性？是否存在"信号交接区"？
4. **物种差异**: 拟南芥（快速响应）vs 番茄（慢速响应，伤口诱导的 JA 爆发更持久）

### 产出

- 伤口响应的单细胞时序转录图谱（拟南芥 + 番茄）
- JA 和 ET 信号在每个细胞类型的激活延迟时间（latency map）
- 伤口空间梯度上 JA/ET 信号的传播速率和范围
- JA→ET 信号交接的细胞类型和空间节点的鉴定

### 里程碑

为 JA-ET 时序分工假说提供首个细胞类型分辨率和空间分辨率的直接证据

## Aim 3: CK-Auxin-ABA 代谢开关的跨物种保守性与染色质基础

**检验假设**: Type-B RR 转录因子通过直接结合并反向调控 auxin 合成基因（*YUC*）和 ABA 合成基因（*NCED*）的启动子，构成 CK→auxin/ABA 代谢开关——该机制在梨（PbRR9-like）、拟南芥（ARR1/ARR10/ARR12）、番茄（SlRRs）和水稻（OsRRs）中保守，但其靶基因谱和调控方向存在物种特异性微调。

**科学问题**: 梨中发现的 PbRR9-like 双重调控机制在多大程度上跨物种保守？不同物种的 Type-B RR 对 *YUC* 和 *NCED* 启动子的结合是否具有相同的方向性（激活 vs 抑制）？调控的染色质结构基础是什么？

### 实验设计

| 项目 | 详情 |
|------|------|
| **物种** | *Pyrus bretschneideri*（梨，已知参考）、*Arabidopsis thaliana*（拟南芥）、*Solanum lycopersicum*（番茄）、*Oryza sativa*（水稻） |
| **组织** | 各物种的幼果/子房（梨/番茄）或根尖/下胚轴（拟南芥/水稻） |
| **技术** | CUT&Tag（Type-B RR 全基因组结合图谱，跨物种比较）、Dual-LUC（启动子活性验证）、EMSA（体外结合）、CRISPR/Cas9（功能缺失验证）、ATAC-seq（靶基因位点染色质可及性）、LC-MS/MS（激素定量） |
| **处理** | CK 处理（tZ, 1 μM, 3h/24h）+ CK 合成抑制剂（lovastatin）± 光质处理 |
| **重复** | CUT&Tag 每物种每处理 2 个重复；Dual-LUC ≥6 个生物学重复；LC-MS/MS 每处理 5 个生物学重复 |

### 实验流程

```
Step 1: 跨物种 Type-B RR 家族系统发育与表达分析
    → 系统发育树：梨 PbRR9-like、拟南芥 ARR1/10/12、番茄 SlRRs、水稻 OsRRs
    → CK 响应性验证：各物种 Type-B RR 在 CK 处理下的诱导倍数
    → 组织表达特异性比较

Step 2: 全基因组靶基因鉴定（CUT&Tag）
    → 各物种 Type-B RR 的 CUT&Tag（±CK 处理）
    → 差异结合峰分析：CK 依赖的结合和组成型结合
    → 跨物种靶基因保守性：同源 *YUC* 和 *NCED* 基因是否都被结合？
    → 结合的方向性：激活型（启动子近端）vs 抑制型（启动子上游/基因体）

Step 3: 靶基因调控方向验证
    → Dual-LUC：各物种 Type-B RR 效应子 × 各物种 *YUC/NCED* 启动子::LUC
    → EMSA：Type-B RR 重组蛋白 vs 核心结合基序（GATCTT 或变体）
    → 是否为激活（*YUC*）和抑制（*NCED*）的双向调控？

Step 4: 染色质环境分析
    → ATAC-seq（各物种 ± CK 处理）→ *YUC* 和 *NCED* 位点的染色质可及性
    → 结合 CUT&Tag 结果：Type-B RR 的结合是否伴随染色质开放/关闭？
    → 共激活/共抑制因子招募（组蛋白修饰 ChIP-seq：H3K27ac, H3K27me3）

Step 5: 功能验证
    → CRISPR/Cas9 敲除各物种 Type-B RR
    → 检测 auxin/ABA 比率变化
    → 跨物种互补实验：梨 PbRR9-like 能否恢复拟南芥 arr1/10/12 突变体表型？
```

### 关键分析

1. **保守靶基因**: 跨 4 物种的共同 Type-B RR 靶基因集（orthogroup 水平）
2. **调控极性保守性**: *YUC* 激活/*NCED* 抑制是否在所有物种中保持一致？
3. **染色质预配置**: *YUC* 和 *NCED* 基因座的基础染色质状态是否决定了 Type-B RR 的调控方向？
4. **物种特异性调控**: 各物种独有的 Type-B RR 靶基因及其生物学意义（如果实发育、根构型）

### 产出

- 跨 4 物种（梨/拟南芥/番茄/水稻）的 Type-B RR 全基因组靶基因图谱
- CK→auxin/ABA 代谢开关的跨物种保守性定量评估
- Type-B RR 对 *YUC* 和 *NCED* 启动子产生反向调控的染色质结构基础
- 跨物种互补实验验证的功能保守性证据

### 里程碑

从单一物种发现（梨 PbRR9-like）提升为跨真双子叶和单子叶植物的通用激素交叉对话机制

## Aim 4: BR 信号整合与 BES1 代谢阀门的定量化解析

**检验假设**: BR 信号终端转录因子 BES1/BZR1 作为多激素信号的整合节点，通过直接调控细胞壁松弛基因（生长方向）和类黄酮合成酶基因（防御方向）构成"代谢阀门"——BR 水平高时阀门关闭（碳流→生长），BR 水平低时阀门开放（碳流→防御）。该阀门受光信号（HY5）和 GA 信号（DELLA-ACbHLH144 模块）的交叉调制。

**科学问题**: BR 梯度下碳流在初级代谢（纤维素/生长）和次生代谢（类黄酮/UV 防护）之间如何定量分配？BES1 代谢阀门的"开度"如何由多激素输入联合决定？光信号和 GA 信号如何调制该阀门？

### 实验设计

| 项目 | 详情 |
|------|------|
| **物种** | *Arabidopsis thaliana* Col-0（主系统）、*Solanum lycopersicum*（番茄，果实成熟背景）、*Actinidia chinensis*（猕猴桃，ACbHLH144-GA2ox7 模块） |
| **组织** | 拟南芥幼苗/莲座叶；番茄果实（破色期）；猕猴桃果实 |
| **技术** | ¹³C 代谢流分析（¹³C-Glc 标记 + LC-MS/MS）、CUT&Tag（BES1/BZR1 ± BL ± 光质）、非靶向代谢组学、Co-IP（BES1-DELLA/BES1-HY5 互作）、Dual-LUC（BES1 × PFG MYB 启动子 + BES1 × EXP/XTH 启动子） |
| **处理** | BL 梯度（0, 0.01, 0.1, 1, 10 μM）± 光质（WL vs 低蓝光 vs UV-B）± GA₃ ± PAC；多因子设计 |
| **重复** | ¹³C 代谢流 5 个生物学重复；CUT&Tag 每处理 2 个重复；代谢组 5 个重复；Dual-LUC ≥6 个重复 |

### 分析流程

```
Step 1: BES1 代谢阀门的靶基因全景（CUT&Tag）
    BES1-CUT&Tag（拟南芥）± BL ± UV-B
    → 差异结合峰 → 靶基因功能分类：
        生长类：EXP, XTH, CES（纤维素合酶）
        防御类：CHS, CHI, F3H, DFR（类黄酮合成）
        交叉调控类：GA2ox7（GA 失活）、HY5 靶基因
    → BL 梯度下 BES1 结合强度的剂量-响应曲线

Step 2: 碳流定量分配（¹³C 代谢流）
    ¹³C₆-Glc 标记 → BL 梯度处理（0-10 μM, 24h）
    → LC-MS/MS 追踪 ¹³C 在以下代谢池中的富集：
        纤维素前体（UDP-Glc、GDP-Glc）
        类黄酮前体（Phe、4-coumaroyl-CoA、naringenin）
        木质素前体（coniferyl alcohol）
    → 计算"代谢阀门开度指数" = ¹³C-类黄酮 / (¹³C-纤维素 + ¹³C-类黄酮)
    → 阀门开度 vs BL 浓度的定量关系

Step 3: BR-GA 交叉调制（ACbHLH144-GA2ox7 模块保守性）
    → 拟南芥 ACbHLH144 同源基因鉴定
    → Dual-LUC：拟南芥 ACbHLH144-like × GA2ox7 启动子
    → BES1 是否调控 ACbHLH144-like 表达（ChIP-qPCR 验证）
    → GA 水平变化对阀门开度的间接影响

Step 4: BR-光信号交叉调制
    → UV-B 处理下 BES1 靶基因重编程（CUT&Tag 比较 ± UV-B）
    → HY5-BES1 竞争结合 PFG MYB 启动子（EMSA + Dual-LUC 竞争实验）
    → 光质是否通过 HY5→BES1 拮抗作用调节阀门开度？

Step 5: 跨物种验证
    → 番茄 SlBZR1 在果实成熟中的代谢阀门功能（类胡萝卜素 vs 细胞壁代谢）
    → 猕猴桃 ACbHLH144-GA2ox7 模块在 BR-GA 交叉中的作用
```

### 关键分析

1. **阀门开度-浓度曲线**: 拟合 Hill 方程或逻辑函数，鉴定 EC50（半最大效应浓度）
2. **多输入整合**: BL（BR 信号）、GA（GA 信号）、UV-B（光信号）三因子对阀门开度的联合效应 — 使用响应面分析（response surface methodology）
3. **BES1 靶基因的重编程**: UV-B 处理下 BES1 在 PFG MYB 启动子上的结合减少 vs 在细胞壁基因启动子上的结合维持
4. **物种特异性**: 拟南芥（营养组织阀门）vs 番茄（果实成熟阀门）vs 猕猴桃（BR-GA 交叉）

### 产出

- BES1 代谢阀门的全基因组靶基因图谱（拟南芥/番茄）

## Aim 5: 染色质预配置决定细胞激素响应能力的分子机制

**检验假设**: 细胞类型特异性的激素响应能力由发育过程中建立的染色质可及性预配置决定——激素通路基因的启动子/增强子在"有能力响应"的细胞中预先处于开放状态，激素信号的到来仅触发预配置位点上的转录因子激活，而非重塑染色质景观。

**科学问题**: 染色质预配置以何种分子机制决定细胞是否能响应特定激素？预配置图谱在进化上多大程度保守？激素信号是否完全不能改变染色质预配置，还是存在"可塑性窗口"？

### 实验设计

| 项目 | 详情 |
|------|------|
| **物种** | *Arabidopsis thaliana* Col-0（根尖，已有丰富 scRNA-seq 参考）、*Oryza sativa*（水稻根尖，单子叶比较）、*Solanum lycopersicum*（番茄根尖，进化距离更远） |
| **组织** | 根尖（0-5 mm，含所有发育区） |
| **技术** | scATAC-seq + scRNA-seq（多组学单细胞，10x Multiome 或 snATAC-seq + snRNA-seq 配对）、CUT&Tag（激素通路终端转录因子 ± 激素处理）、ChIP-seq（组蛋白修饰：H3K27ac, H3K27me3, H3K4me3） |
| **处理** | ± auxin（IAA, 1 μM, 3h）、± CK（tZ, 1 μM, 3h）、± GA（GA₃, 10 μM, 3h）—仅检测预配置响应，非长期重塑 |
| **重复** | scMultiome 每物种每处理 2 个生物学重复；CUT&Tag 每靶标 2 个重复；ChIP-seq 每修饰 2 个重复 |

### 分析流程

```
Step 1: 单细胞多组学图谱（scATAC-seq + scRNA-seq）
    拟南芥/水稻/番茄根尖（± 激素短期处理）
    → scRNA-seq 聚类 → 细胞类型注释（QC、干细胞、分生组织、伸长区、分化区）
    → scATAC-seq → 每个细胞类型的染色质可及性景观
    → 整合分析：鉴定每个细胞类型中处于开放状态但未转录的激素通路基因
        = 预配置位点（poised loci）

Step 2: 激素响应预配置指数
    对每个细胞类型计算：
    → 预配置得分 = 激素通路基因启动子的 ATAC 信号 / 基因表达水平
    → 响应能力得分 = 激素处理后下游靶基因的诱导倍数
    → 预配置-响应相关性：预配置得分高的细胞类型是否确实响应更强？

Step 3: 预配置的染色质特征
    → 预配置位点的组蛋白修饰特征（H3K27ac, H3K4me3, H3K27me3）
    → 预配置 vs 活跃转录 vs 沉默位点的染色质签名差异
    → 预配置位点是否富集特定转录因子结合基序（如 ARF、ARR、BZR1 等先行结合因子）？

Step 4: 激素信号能否"写入"新的预配置
    → 短期激素处理（3h）：预期仅激活预配置位点，不改变染色质可及性
    → 长期激素处理（24h + CHX 追踪实验）：是否出现新的可及性位点？
    → "可塑性窗口"鉴定：发育阶段（分生组织 vs 分化细胞）对预配置可塑性的影响

Step 5: 跨物种预配置保守性
    → 同源激素通路基因在拟南芥/水稻/番茄中的细胞类型预配置模式比较
    → 保守预配置位点 vs 物种特异性预配置位点的功能分类
```

### 关键分析

1. **预配置-响应耦合**: 每个细胞类型的预配置得分与激素响应得分的相关性（Pearson/Spearman r）
2. **预配置的分子签名**: 预配置位点特有的组蛋白修饰组合（二价修饰 H3K4me3+H3K27me3？）
3. **先驱因子**: 哪些转录因子在预配置位点上先于激素信号结合？使用 motif 富集分析 + CUT&Tag 验证
4. **可塑性边界**: 激素处理是否能在特定发育窗口内改写预配置图谱？
5. **进化保守性**: 跨 3 物种的预配置位点保守/分歧率

### 产出

- 拟南芥/水稻/番茄根尖的单细胞染色质可及性 + 转录组联合图谱
- 细胞类型 × 激素通路的预配置水平定量矩阵
- 预配置-响应耦合的统计检验和分子签名
- 跨物种预配置保守性的系统评估
- 预配置可塑性窗口的鉴定

### 里程碑

从"激素梯度决定响应"模型转向"染色质预配置 × 激素梯度联合决定响应"的两层调控模型

### 备选方案

| 风险场景 | 备选方案 |
|---------|---------|
| DELLA 互作组切换为渐变而非阈值 | 聚焦渐变模型：使用 Hill 竞争结合方程建模，描述"变阻器"行为而非"开关"行为 |
| scATAC-seq 数据质量不足 | 改用 bulk ATAC-seq 结合 FACS 分选特定细胞类型；或使用 INTACT 核纯化方法 |
| 跨物种 Type-B RR 互补实验失败 | 聚焦同源基因的生化特性比较（结合基序偏好、调控极性）而非活体功能互补 |
| 番茄/水稻转基因效率低 | 优先使用拟南芥异源系统验证分子机制，番茄/水稻仅做内源表达和相关分析 |
| ¹³C 代谢流通量不足 | 聚焦关键代谢节点（Phe→类黄酮 vs Glc→纤维素）的靶向代谢流分析，辅以非靶向代谢组 |
| 多物种并行实验资源受限 | 分阶段执行：Phase 1 拟南芥先行 → Phase 2 番茄/水稻跟进 → Phase 3 猕猴桃/梨补充 |

## 方案特色

1. **定量化导向**: 区别于传统激素研究的定性描述（"A 激活 B"），本方案以定量化为核心目标——DELLA 互作组的浓度阈值、JA 激活延迟的毫秒-小时级时间参数、¹³C 代谢流的百分比分配、阀门开度的 EC50——将激素交叉对话从比喻推向可测量的数学框架。

2. **跨物种进化视角**: 5 个 Aims 涵盖 6 个物种（拟南芥/番茄/水稻/梨/猕猴桃/烟草），从模式植物到作物、从真双子叶到单子叶、从草本到木本——系统评估激素交叉对话机制的进化保守性和物种特异性创新。

3. **多组学多维整合**: 单细胞多组学 (scRNA-seq + scATAC-seq)、空间组学 (Stereo-seq)、蛋白互作组学 (TurboID-MS)、代谢流分析 (¹³C tracing)、表观基因组学 (CUT&Tag/ChIP-seq)——五种组学平台在统一框架下的多尺度整合。

4. **从描述到预测**: 每个 Aim 不仅产出数据描述，更构建可验证的数学模型（DELLA 竞争结合模型、JA-ET 传播动力学、阀门开度-Hill 方程、预配置-响应回归模型），使激素交叉对话研究进入定量预测阶段。

5. **纯知识推演**: 方案完全基于已发表的 108 篇文献和 309 条证据对象的逻辑推演生成，未引入任何外部假设或未验证的猜测——每个 Aim 的科学问题和方法策略均可追溯至合成页面中的具体共识发现和知识空白。
